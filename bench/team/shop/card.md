# Service `shop` — Task Card

## Overview

The `shop` service is a REST API for an online store inventory and order management system, built on QAL using `std.route`, `std.json`, `std.http`, and `std.db`.

Initialization function: `setup() -> Unit !db`
Request entrypoint: `handle(req: HttpRequest) -> HttpResponse !db, !time`

## Database Schema

```sql
CREATE TABLE IF NOT EXISTS products (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    sku TEXT UNIQUE NOT NULL,
    name TEXT NOT NULL,
    price_cents INTEGER NOT NULL,
    stock INTEGER NOT NULL
);

CREATE TABLE IF NOT EXISTS orders (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    created_at INTEGER NOT NULL,
    status TEXT NOT NULL,
    total_cents INTEGER NOT NULL
);

CREATE TABLE IF NOT EXISTS order_lines (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    order_id INTEGER NOT NULL,
    product_id INTEGER NOT NULL,
    qty INTEGER NOT NULL,
    unit_price_cents INTEGER NOT NULL
);
```

## Endpoints

### 1. `GET /health`
- Response: `200 OK` with JSON `{"ok": true}`.

### 2. `GET /products` and `GET /products?below=<n>`
- Returns list of products sorted by `id ASC`.
- If `below` query parameter is present (valid integer): filter `WHERE stock < ?`.
- Response: `200 OK` with JSON array:
  `[{"id": 1, "sku": "WIDGET-1", "name": "Widget", "price_cents": 1000, "stock": 50}, ...]`

### 3. `POST /products`
- Request body: `{"sku": Str, "name": Str, "price_cents": Int, "stock": Int}`
- Validation:
  - All 4 fields must be present and well-formed.
  - `sku`: non-empty string.
  - `name`: non-empty string.
  - `price_cents`: non-negative integer (`>= 0`).
  - `stock`: non-negative integer (`>= 0`).
- If `sku` already exists: `409 Conflict` with `{"error": {"code": "sku_exists", "message": "..."}}`.
- Response: `201 Created` with header `Location: /products/<id>` and the created product object.

### 4. `GET /products/:id`
- Path parameter `:id`: positive integer.
- Response: `200 OK` with product object, or `404 Not Found` with `{"error": {"code": "product_not_found", "message": "..."}}`.

### 5. `PATCH /products/:id`
- Request body: optional fields `name`, `price_cents`, `stock`.
- At least one field must be provided, otherwise `400 Bad Request` with `{"error": {"code": "no_updates", "message": "..."}}`.
- If product doesn't exist: `404 Not Found`.
- Response: `200 OK` with updated product object.

### 6. `POST /orders`
- Request body: `{"lines": [{"product_id": Int, "qty": Int}, ...]}`
- Validation:
  - `lines`: non-empty array.
  - Each item: `product_id` positive integer, `qty` positive integer (`>= 1`).
  - If a referenced product does not exist: `404 Not Found` with `{"error": {"code": "product_not_found", "message": "..."}}`.
  - For all lines, check if `product.stock >= qty`. If any line has insufficient stock: `409 Conflict` with `{"error": {"code": "insufficient_stock", "message": "..."}}`.
    - Note: All reservations must roll back atomically on error.
- Processing:
  - Deducts `qty` from each product's `stock`.
  - Creates order with `status: "confirmed"`, `created_at` timestamp, and `total_cents` equal to sum of `(line.qty * product.price_cents)`.
  - Inserts order lines.
- Response: `201 Created` with header `Location: /orders/<id>` and body:
  `{"id": 1, "status": "confirmed", "created_at": 123456789, "total_cents": 2500, "lines": [{"id": 1, "product_id": 1, "qty": 2, "unit_price_cents": 1000}, ...]}`

### 7. `GET /orders/:id`
- Path parameter `:id`: positive integer.
- Response: `200 OK` with order object including `lines`, or `404 Not Found` with `{"error": {"code": "order_not_found", "message": "..."}}`.

### 8. `POST /orders/:id/cancel`
- If order doesn't exist: `404 Not Found`.
- If order is already cancelled: `409 Conflict` with `{"error": {"code": "order_already_cancelled", "message": "..."}}`.
- If confirmed:
  - Sets order status to `"cancelled"`.
  - Restores each line's `qty` back to the corresponding product's `stock`.
  - Response: `200 OK` with `{"id": id, "status": "cancelled"}`.

### 9. `GET /reports/stock`
- Computes inventory and sales summary per product across all products in `products`, ordered by `product_id ASC`.
- Response: `200 OK` with JSON array:
  `[{"product_id": 1, "sku": "...", "name": "...", "current_stock": 48, "reserved_stock": 2, "revenue_cents": 2000}, ...]`
  - `current_stock`: product's current remaining stock in `products.stock`.
  - `reserved_stock`: total quantity sold in confirmed orders.
  - `revenue_cents`: total revenue generated by confirmed orders (`qty * unit_price_cents`).

## Error Format
All errors follow standard format:
`{"error": {"code": "<error_code>", "message": "<human readable message>"}}`
