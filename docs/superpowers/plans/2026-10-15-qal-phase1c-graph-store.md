# QAL Phase 1c — Canonical Form, Hashing and Codebase Store Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn checked programs into a content-addressed program graph: every definition gets a canonical binary form and a SHA-256 hash (locals as De Bruijn indices, references as hashes, mutually recursive groups hashed together), and a SQLite codebase store `.qal/store.db` keeps definitions, dependencies, names and history, with `define` that adds or replaces atomically (same signature: dependents are relinked and re-checked; changed signature: fail with the dependents unless they are included), plus the CLI `qal init | define | view | query | rename | history` and `qal run | call | test` on stored code.

**Architecture:** `qal_core::canon` encodes a definition from its source AST, resolving names exactly as the checker does, and can decode the bytes back into the same AST with the current names (renaming locals that a renamed reference would capture). The new crate `qal-store` never stores anything it has not checked: `define` decodes the whole named codebase, overlays the new definitions by name, enforces the replacement rule, runs the checker on the result, hashes it and writes all changes in one `BEGIN IMMEDIATE` transaction. The CLI opens the store of the current project and runs stored code through the unchanged 1b pipeline (check → compile per entry point → run).

**Tech Stack:** Rust 1.97 (edition 2021); existing `wasm-encoder =0.259.0`, `wasmparser =0.259.0`, `wasmtime =49.0.1`, `serde`/`serde_json` 1; **new:** `sha2 =0.11.0` (2026-03-25) and `rusqlite =0.40.2` with feature `bundled` (2026-08-08, SQLite compiled in, no system library).

**Spec:** `docs/superpowers/specs/2026-10-15-qal-design.md` (§5 Programmgraph und Hashing, §6 Speicher, §9 operations the store API serves, §12 success criterion 4). Roadmap: `docs/superpowers/specs/2026-10-15-qal-roadmap.md` (row 1c and "Pflicht in 1c"). Previous sub-plan: `docs/superpowers/plans/2026-10-15-qal-phase1b-data-memory-effects.md`.

**Sub-plan context:** Phase 1 is delivered as five sub-plans: 1a core pipeline (done), 1b data types + memory + effects (done), **1c canonical form + hashing + SQLite store (this plan)**, 1d MCP server + full CLI operations, 1e benchmark.

**How this plan was made:** every file below was first implemented and tested in a scratch copy of the repository (188 tests passing, zero compiler warnings) and then reviewed by an independent reviewer who probed it adversarially (hash stability under renaming and reformatting, mutual recursion, replacement and relinking, atomicity on failure, SQL injection via names, concurrent `define` from several processes, corrupt store files); its confirmed findings — group hashes that depended on names for symmetric or tied groups (now canonical labelling, symmetric groups rejected), replacing one alias silently redirecting users of the other, quadratic group storage, non-canonical bytes accepted from a tampered store, decoding deeper than the parser allows, and a `Builtin::ALL` that could miss a variant — are fixed and pinned by tests; a second review round of the fixes found three more (a second name for a recursive-group member broke every later `define`, restating an unchanged alias redirected its users, the labelling limit was reported as symmetry), also fixed and pinned. The plan itself was generated by a script that replayed every step below on a fresh copy of the 1b repository, ran each command and recorded its real outcome, and checked that the result after Task 5 is byte-identical to the reviewed code — the code blocks are exactly that code.

- Workspace lives at `qland/qal/`. **The only dependency change of this phase:** add `sha2 = "=0.11.0"` and `rusqlite = { version = "=0.40.2", features = ["bundled"] }` to `[workspace.dependencies]` (both versions are more than two weeks old; `0.11.1` of `sha2` is not). If `cargo` picks a newer version of any of them, pin it back with `cargo update -p <crate> --precise <version>`. Building needs network access to crates.io once.
- Hash = SHA-256 of the canonical binary form (spec §5); shown as 64 lowercase hex digits, as `#<hash>` where a name is expected.
- Renaming never changes a hash; identical logic under two names has one hash; contracts (`req`/`ens`) are part of the hash; effects are a sorted set without duplicates.
- Store file: `.qal/store.db` in the project directory (found from the current directory or a parent). Tables `defs`, `deps`, `names`, `history` as in spec §6 (columns adjusted in Design Decision 10).
- Store invariants (spec §6): only definitions for which the whole codebase parses and checks are stored; every dependency of a stored definition is stored; `define` (and `rename`) is atomic.
- No panic on any store path: SQLite errors, corrupt or tampered files and impossible states are `store_error` diagnostics (`E0601`), a dangling reference is `missing_dep` (`E0402`).
- Diagnostic JSON fields: `code, kind, def, path, message, expected?, found?, hints, dependents?` (`dependents` only for `signature_change`, `E0401`). All messages are English.
- CLI output stays one JSON line on stdout (except `fmt`); exit codes: 0 success, 1 diagnostics / runtime error / failed tests, 2 usage or I/O error including a missing or unreadable store.
- Builds and tests must be warning-free (`cargo build --workspace --all-targets`).

## Design Decisions

Decided here (the user delegates design decisions); each is reflected in the code below.

1. **Canonical form from the source AST, in `qal-core`.** `qal_core::canon` encodes a definition from the parsed AST and resolves every name exactly like the checker (local → function → variant → built-in; types by name), instead of encoding the typed program. Reason: the form must decode back into the same source AST so that `view` can print the stored graph and `parse(print(g)) == g` holds for it; the typed program loses annotations, field names and built-in spelling. Spec §10 places hashing in `qal-core`.
2. **Binary format** (documented at the top of `canon.rs`): magic `QAL\0`, version byte `1`; a definition outside any group is `1 0 member`, a member of a group of two or more is `size index group-hash`, and the group form (`size member*`) is stored once (table `groups`), so a group costs linear, not quadratic, space. In members, locals are De Bruijn indices (parameters are bound in order, `r` is bound for `ens` without being stored), references are `0 + 32-byte hash` or `1 + group index`, field and variant names are kept, a variant records its owner (`Option`, `Result`, or the enum's hash), built-ins are referenced by name, integers are 8 bytes little endian, floats their IEEE bits. Local names are metadata (`local_names`, binding order). Two normalisations: effects are sorted and deduplicated, and `None()` is the same as `None`.
3. **Mutual recursion:** strongly connected components of the reference graph (iterative Tarjan, so long dependency chains cannot overflow the stack) are hashed as one group; `sha256(canonical) == hash` holds for every row. Member positions come from a **canonical labelling**: refinement (a member's class = its old class plus its encoding with in-group references written as classes) until stable, then individualization of each member of the first tied class in turn, recursively, keeping the smallest group form. Names and definition order therefore never matter. A group with a non-trivial automorphism — interchangeable members, which are the same definition under several names, e.g. `f(n) = g(n)`, `g(n) = f(n)` — cannot give its members name-independent hashes and is rejected (`E0209`, kind `duplicate_name`). The search is bounded (1024 search nodes, 2 000 000 member encodings); a group beyond that — only very large groups whose members all look alike — is `group_too_large` (`E0210`). A member of a group has exactly one name (a second name would refer to its siblings through other names and leave the group), so redefining an existing group under other names is `duplicate_name`. Types and functions never share a group (types cannot refer to functions).
4. **Types are structural.** A type's hash covers its fields or variants, not its name (renaming must not change hashes). Because the checker treats records nominally and Phase 1 has no type aliases, defining a second name for an identical type is rejected (`duplicate_name`: "type `B` is identical to type `A`", hint to use or rename `A`). Functions and tests may have several names for one hash. A hash is **replaced** only when every one of its names is redefined in the call; if another name keeps it, its users keep that name and the old version (redefining `uno` does not change what users of the identical `one` compute). When all names are redefined, a name restated unchanged keeps the hash and its users; if they all change, the same way, the users follow; if they change differently while stored users exist, the call fails with `ambiguous_replacement` (`E0403`, with `dependents`). Which case applies is found by a trial hash of the assembled program.
5. **`qal-store` depends on `qal-text` and `qal-check`** (spec §10 lists only `qal-core`): invariant 1 is enforced inside `define` itself, so no caller (CLI now, MCP in 1d) can store unchecked code.
6. **`define` re-checks the whole codebase.** It decodes every named definition with the current names, replaces the ones named in the input, checks the combined program with the existing checker and hashes it. A stored definition that refers to a replaced hash is decoded with the replacing name, so it is relinked by construction; its new hash and a `relinked` history entry are written. Phase 1 codebases are small (hundreds of definitions); restricting the work to the affected part is a later optimisation and does not change the API.
7. **Replacement rule:** the signature is the kind plus the signature text with current names (`fn(Int, P) -> Str !io` for functions — effects included —, the whole body for types, `Bool` for tests). Same signature: dependents are relinked and re-checked automatically (a failing re-check rejects the whole call). Changed signature: `define` fails with one `signature_change` per changed definition, listing its **direct** stored dependents that the call does not redefine (`dependents`), unless there are none. A redefined dependent whose own signature changes needs its dependents in turn.
8. **Capture-free decoding.** A local whose name equals the current name of a definition the text refers to is renamed (`x` → `x_1`, consistently for all binders of that name), so `view` text always means the stored graph and defines back to the same hash. `r` is reserved as a function name (checker), because inside `ens` it is the result and cannot be renamed.
9. **Rename** checks the renamed codebase (built-in and reserved names, `main`'s signature, case rules, keywords) and verifies that every hash stays the same before it writes; the history of the old name moves to the new name and gets a `renamed` entry with `from_name`.
10. **Schema:** hashes are hex `TEXT`, times Unix milliseconds, list columns JSON arrays; there is a `groups (hash, form)` table for group forms; `names` also has `local_names` (two names of one hash may name their locals differently) and `history` has `id`, `action` (`added`, `replaced`, `relinked`, `renamed`) and `from_name`. Foreign keys are on, `PRAGMA user_version = 1` identifies the schema, the journal is WAL (readers never wait for a `define`), writers use `BEGIN IMMEDIATE` with a 10 s busy timeout, so concurrent `define`s from several processes serialize instead of failing or losing updates. Old versions stay in `defs` forever (history; no garbage collection in Phase 1).
11. **Every row is verified when read:** `sha256(canonical) == hash`, the group form matches its hash, a known kind, decodable bytes, matching number of local names. The decoder accepts only canonical bytes (minimal varints, flags and Bools 0/1, effects sorted without duplicates, variant names matching their owner) and only the parser's nesting (256 for expressions/patterns, 256 for types), keeps allocations proportional to the input, and returns errors, never panics. As a last guard, `define` fails with `store_error` if a stored definition would change hash without depending on a replaced one.
12. **`view` takes names or `#<hash>`** (old versions from the history); a definition without a current name is shown with the name it last had. Its result has the text, the signature, the effects and the direct dependencies with their signatures (spec §9). **`query`** filters by name prefix (plain text, no wildcards), signature pattern (`_` stands for one type: `fn(_, Int) -> _`) and direct use of a name or hash; a recursive definition does not "use" itself.
13. **CLI targets:** an argument ending in `.qal` is a file, anything else a store name (names never contain `.`). `qal run <name>` runs any `fn(List[Str]) -> Int` from the store, `qal call <fn> args` and `qal test [names]` work on the store; the file forms of 1b are unchanged. `--agent <name>` (default `cli`) is recorded in the history. A missing or corrupt store exits 2 with a JSON `store_error`.
14. **Printer totality (carried over from 1b):** negative Int literals print as `(-5)` and `i64::MIN` as `(-9223372036854775807 - 1)`; negative, NaN and infinite floats print as `(-2.5)`, `(0.0 / 0.0)`, `(1.0 / 0.0)`; an empty sequence prints `()` (and the checker types it as `Unit`). Empty enums and empty matches got syntax, so they round-trip exactly: `type Never = |` and `match n { }` (only exhaustive for enums without variants). The lexer keeps integer magnitudes as `u64`, so `-9223372036854775808` is now a valid pattern; in expressions it still is not (Decision 14 of 1b). Empty records print as `{}`.
15. **Type size cap (carried over):** besides the depth cap of 256, inferred types are capped at 4096 nodes (`type_too_large`, `E0208`); without it `if c then Ok(a) else Err(a)` repeated doubles the type and the checker hangs.
16. **Known limitations (documented, not fixed):** each `define` re-reads, re-checks and re-hashes the whole codebase (O(codebase)); decoding one member of a group parses the whole group form, so a group of n members costs O(n²) to load (reviewer's measurements, release build: 1000 members — `query` 1.4 s, an unrelated `define` 2.5 s; 2000 members approach the 10 s busy timeout of concurrent writers); a later phase can decode a group in one pass; `Builtin::NAMES` stays a hand-written list (it is a `const` used by the checker) and is tested against the macro-generated `ALL`; the pre-existing `expect` in `Loaded::runner` (huge list literals) is a 1d item.

Carried-over items from the roadmap ("Pflicht in 1c"), and where they are done: type size cap (Task 3, Decision 15); total printer (Task 2, Decision 14); `Builtin::NAMES` ↔ `Builtin::name()` consistency test (Task 1, `builtin_names_match_the_variants`); effects as a sorted set without duplicates (Task 1 encoder, Task 2 parser).

## Review Focus

1. **Two agents run `qal define` at the same time** against one store: both must succeed, neither change may be lost, no `database is locked` error — pinned in Task 4 `concurrent_defines_serialize` and Task 5 `concurrent_define_processes_both_succeed`.
2. **A failure while writing** (any SQLite error after some rows were written): nothing of the call may remain — pinned in Task 4 `a_failure_while_writing_rolls_everything_back`.
3. **A damaged store** (garbage file, tampered bytes, dangling name, other schema version): a `store_error` diagnostic and exit code 2, never a panic, hang or huge allocation — pinned in Task 4 `corrupt_stores_are_errors_not_panics`, Task 1 `corrupt_input_is_an_error_not_a_panic` and Task 5 `missing_or_corrupt_store_is_exit_2_with_json`.
4. **Renaming a function to a name a local variable already uses:** the stored meaning must not change and the view must still define back to the same hash — pinned in Task 4 `renamed_references_never_capture_locals`.
5. **Names, prefixes and patterns containing SQL or wildcard characters** (`%`, `_`, quotes, `'); DROP TABLE`): treated as plain text, never as SQL — pinned in Task 4 `query_by_name_prefix_signature_and_uses` and `rename_rejects_taken_invalid_and_reserved_names`.

```rust
#[cfg(test)]
mod tests {
    use super::*;

    fn var(s: &str) -> Box<Expr> {
        Box::new(Expr::Var(s.into()))
    }

    fn func(name: &str, param: &str, body: Expr) -> Def {
        Def::Fn(FnDef { name: name.into(), params: vec![Param { name: param.into(), ty: Type::Int }], ret: Type::Int, effects: vec![], req: vec![], ens: vec![], body })
    }

    fn by_name(p: &Program) -> HashMap<String, Canon> {
        hash_program(p).unwrap().defs.into_iter().map(|c| (c.name.clone(), c)).collect()
    }

    fn single(c: &Canon) -> Form<'_> {
        Form::new(&c.canonical, None)
    }

    #[test]
    fn hex_roundtrip_and_display() {
        let h = Hash::of(b"abc");
        assert_eq!(h.to_hex(), "ba7816bf8f01cfea414140de5dae2223b00361a396177a9cb410ff61f20015ad");
        assert_eq!(Hash::from_hex(&h.to_hex()), Some(h));
        assert_eq!(Hash::from_hex("xyz"), None);
        assert_eq!(h.short(), "ba7816bf8f01");
    }

    #[test]
    fn local_names_do_not_change_the_hash() {
        let a = Program { defs: vec![func("f", "x", Expr::Bin(BinOp::Add, var("x"), Box::new(Expr::Int(1))))] };
        let b = Program { defs: vec![func("g", "y", Expr::Bin(BinOp::Add, var("y"), Box::new(Expr::Int(1))))] };
        let (ca, cb) = (&by_name(&a)["f"], &by_name(&b)["g"]);
        assert_eq!(ca.hash, cb.hash);
        assert_eq!(ca.canonical, cb.canonical);
        assert_eq!((ca.local_names.clone(), cb.local_names.clone()), (vec!["x".to_string()], vec!["y".to_string()]));
        assert_eq!(Hash::of(&ca.canonical), ca.hash);
    }

        let mk = |effs: &[&str]| {
            let mut f = func("f", "x", Expr::Unit);
            if let Def::Fn(fd) = &mut f {
                fd.effects = effs.iter().map(|s| s.to_string()).collect();
                fd.ret = Type::Unit;
            }
            by_name(&Program { defs: vec![f] })["f"].clone()

        assert_eq!(references_of(single(&c["f"])).unwrap(), vec![g_hash]);
        assert_eq!(c["f"].deps, vec![g_hash]);

    }

        let p = Program { defs: vec![func("f", "x", Expr::Call("helper".into(), vec![Expr::Var("x".into())])), func("helper", "n", Expr::Var("n".into()))] };

        assert_eq!(d, func("f", "x_1", Expr::Call("x".into(), vec![Expr::Var("x_1".into())])));
    }

    fn corrupt_input_is_an_error_not_a_panic() {
        let p = Program { defs: vec![func("f", "x", Expr::Var("x".into()))] };
        let c = &by_name(&p)["f"];
        let dec = |bytes: &[u8], locals: &[String]| decode(Form::new(bytes, None), "f", locals, &mut |_| String::new());
        for cut in 0..c.canonical.len() {
            assert!(dec(&c.canonical[..cut], &c.local_names).is_err(), "cut at {cut}");
        }
        let mut bad = c.canonical.clone();
        *bad.last_mut().unwrap() = 9; // local index out of scope
        assert!(dec(&bad, &c.local_names).is_err());
        assert!(dec(&c.canonical, &[]).is_err());
        let test_form = |body: &[u8]| {
            let mut v = single_form(&[2]);
            v.extend_from_slice(body);
            v
        };
        let deep = test_form(&std::iter::repeat_n([E_UN, 0], 100_000).flatten().collect::<Vec<_>>());
        assert!(dec(&deep, &[]).unwrap_err().contains("nested too deeply"));
        // A deep type (let annotation) and a deep pattern.
        let mut body = vec![E_LET, 1];
        body.extend(std::iter::repeat_n(T_LIST, 100_000));
        assert!(dec(&test_form(&body), &[]).unwrap_err().contains("nested too deeply"));
```

//! Canonical form and content hashes of definitions (spec §5).
//!
//! Every definition is encoded into a canonical binary form in which local variables are De Bruijn
//! indices (their names are kept separately as metadata), references to other definitions are
//! their hashes, and field and variant names stay (they are semantics). The hash of a definition is
//! the SHA-256 of that encoding, so renaming changes no hash and identical logic has one hash.
//!
//! A group of two or more mutually recursive definitions (a strongly connected component of the
//! reference graph) is encoded together: the group form holds all members, references inside the
//! group are member positions, and each member's canonical form is the group's size, the member's
//! position and the group form's hash. The positions come from a canonical labelling of the group
//! (refinement plus a search over all ways to break ties, keeping the smallest group form), so
//! neither the names nor the order of definition matter. A group with interchangeable members
//! (an automorphism: two members that are the same definition) is rejected, since its members
//! could not get name-independent hashes.
//!
//! ```text
//! canonical := "QAL\0" version:u8 1 0 member                      (a definition outside any group)
//!            | "QAL\0" version:u8 size:varint index:varint group-hash[32]   (member of a group, size >= 2)
//! group     := "QAL\0" version:u8 size:varint member{size}        (stored once per group)
//! member    := kind:u8 (0 type | 1 fn | 2 test) body
//! type body := 0 n (field:str type){n}  |  1 n (variant:str k type{k}){n}
//! fn body   := n type{n} ret:type effects req:n expr{n} ens:n expr{n} body:expr   (params bound in order;
//!              `r` is bound for `ens` without being stored)
//! test body := expr
//! ref       := 0 hash[32] | 1 group-index:varint
//! effects   := n str{n}              (sorted, without duplicates)
//! str       := len:varint utf8-bytes; varints are minimal LEB128; ints are 8 bytes little endian;
//!              floats are their IEEE bit pattern; flags and Bools are 0 or 1
//! ```
//!
//! The expression, pattern and type tags are the constants in `tag` below.

/// SHA-256 content hash of a definition's canonical form.
#[derive(Clone, Copy, PartialEq, Eq, Hash, PartialOrd, Ord)]
pub struct Hash(pub [u8; 32]);

impl Hash {
    pub fn of(bytes: &[u8]) -> Hash {
        let digest = Sha256::digest(bytes);
        let mut out = [0u8; 32];
        out.copy_from_slice(digest.as_slice());
        Hash(out)
    }

    pub fn to_hex(&self) -> String {
        self.0.iter().map(|b| format!("{b:02x}")).collect()
    }

    /// Parses exactly 64 hexadecimal digits.
    pub fn from_hex(s: &str) -> Option<Hash> {
        if s.len() != 64 || !s.bytes().all(|b| b.is_ascii_hexdigit()) {
            return None;
        }
        let mut out = [0u8; 32];
        for (i, byte) in out.iter_mut().enumerate() {
            *byte = u8::from_str_radix(&s[2 * i..2 * i + 2], 16).ok()?;
        }
        Some(Hash(out))
    }

    /// The first 12 hex digits, used as a placeholder name for definitions without a name.
    pub fn short(&self) -> String {
        self.to_hex()[..12].to_string()
    }
}

impl fmt::Display for Hash {
    fn fmt(&self, f: &mut fmt::Formatter<'_>) -> fmt::Result {
        f.write_str(&self.to_hex())
    }
}

    fn fmt(&self, f: &mut fmt::Formatter<'_>) -> fmt::Result {
        write!(f, "#{}", self.short())
    }
}

/// What the names of a program refer to (variants and builtins are fixed by the program).
struct Env<'a> {
    fns: HashSet<&'a str>,
    types: HashSet<&'a str>,
    /// Variant name -> owning enum type name.
    variants: HashMap<&'a str, &'a str>,
}

impl<'a> Env<'a> {
    fn new(p: &'a Program) -> Env<'a> {
        let mut env = Env { fns: HashSet::new(), types: HashSet::new(), variants: HashMap::new() };
        for d in &p.defs {
            match d {
                Def::Fn(f) => {
                    env.fns.insert(&f.name);
                }
                Def::Type(t) => {
                    env.types.insert(&t.name);
                    if let TypeBody::Enum(vs) = &t.body {
                        for v in vs {
                            env.variants.insert(&v.name, &t.name);
                        }
                    }
                }
                Def::Test(_) => {}
            }
        }
        env
    }
}

/// Encodes one definition. Names of other definitions go through `refs`; the first unresolvable
/// name is kept in `err`.
struct Enc<'a, 'r> {
    env: &'a Env<'a>,
    refs: &'r mut dyn FnMut(&str) -> Ref,
    out: Vec<u8>,
    /// Visible local names, innermost last.
    scope: Vec<String>,
    /// Every binder's name in binding order.
    locals: Vec<String>,
    err: Option<String>,
}

impl Enc<'_, '_> {
    fn byte(&mut self, b: u8) {
        self.out.push(b);
    }

    fn varint(&mut self, n: u64) {
        put_varint(&mut self.out, n);
    }

    fn len(&mut self, n: usize) {
        self.varint(n as u64);
    }

    fn i64(&mut self, n: i64) {
        self.out.extend_from_slice(&n.to_le_bytes());
    }

    fn str(&mut self, s: &str) {
        self.len(s.len());
        self.out.extend_from_slice(s.as_bytes());
    }

    fn fail(&mut self, msg: String) {
        if self.err.is_none() {
            self.err = Some(msg);
        }
    }

    fn reference(&mut self, name: &str) {
        match (self.refs)(name) {
            Ref::Hash(h) => {
                self.byte(R_HASH);
                self.out.extend_from_slice(&h.0);
            }
            Ref::Group(i) => {
                self.byte(R_GROUP);
                self.varint(i as u64);
            }
        }
    }

    fn effects(&mut self, effs: &[String]) {
        let set: BTreeSet<&String> = effs.iter().collect();
        self.len(set.len());
        for e in set {
            self.str(e);
        }
    }

    fn ty(&mut self, t: &Type) {
        match t {
            Type::Int => self.byte(T_INT),
            Type::Float => self.byte(T_FLOAT),
            Type::Bool => self.byte(T_BOOL),
            Type::Unit => self.byte(T_UNIT),
            Type::Str => self.byte(T_STR),
            Type::List(x) => {
                self.byte(T_LIST);
                self.ty(x);
            }
            Type::Option(x) => {
                self.byte(T_OPTION);
                self.ty(x);
            }
            Type::Result(a, b) => {
                self.byte(T_RESULT);
                self.ty(a);
                self.ty(b);
            }
            Type::Named(n) => {
                if !self.env.types.contains(n.as_str()) {
                    self.fail(format!("unknown type `{n}`"));
                }
                self.byte(T_NAMED);
                self.reference(n);
            }
            Type::Fn(ps, r, effs) => {
                self.byte(T_FN);
                self.len(ps.len());
                for p in ps {
                    self.ty(p);
                }
                self.ty(r);
                self.effects(effs);
            }
            Type::Var(_) => self.fail("inference variable in a written type".into()),
        }
    }

    fn bind(&mut self, name: &str) {
        self.scope.push(name.to_string());
        self.locals.push(name.to_string());
    }

    fn lookup(&self, name: &str) -> Option<usize> {
        self.scope.iter().rev().position(|n| n == name)
    }

    /// `None`/`Some`, `Ok`/`Err`, or a variant of a declared enum.
    fn variant_owner(&mut self, name: &str) -> bool {
        match name {
            "None" | "Some" => self.byte(V_OPTION),
            "Ok" | "Err" => self.byte(V_RESULT),
            _ => match self.env.variants.get(name).copied() {
                Some(owner) => {
                    self.byte(V_ENUM);
                    self.reference(owner);
                }
                None => return false,
            },
        }
        true
    }

    fn is_variant(&self, name: &str) -> bool {
        matches!(name, "None" | "Some" | "Ok" | "Err") || self.env.variants.contains_key(name)
    }

    fn exprs(&mut self, xs: &[Expr]) {
        self.len(xs.len());
        for x in xs {
            self.expr(x);
        }
    }

    fn variant(&mut self, name: &str, args: &[Expr]) {
        self.byte(E_VARIANT);
        self.variant_owner(name);
        self.str(name);
        self.exprs(args);
    }

    fn expr(&mut self, e: &Expr) {
        match e {
            Expr::Int(n) => {
                self.byte(E_INT);
                self.i64(*n);
            }
            Expr::Float(x) => {
                self.byte(E_FLOAT);
                self.out.extend_from_slice(&x.to_bits().to_le_bytes());
            }
            Expr::Bool(b) => {
                self.byte(E_BOOL);
                self.byte(*b as u8);
            }
            Expr::Str(s) => {
                self.byte(E_STR);
                self.str(s);
            }
            Expr::Unit => self.byte(E_UNIT),
            // Resolution order is the checker's: local, function, variant.
            Expr::Var(v) => {
                if let Some(i) = self.lookup(v) {
                    self.byte(E_LOCAL);
                    self.len(i);
                } else if self.env.fns.contains(v.as_str()) {
                    self.byte(E_FN_REF);
                    self.reference(v);
                } else if self.is_variant(v) {
                    self.variant(v, &[]);
                } else {
                    self.fail(format!("unknown name `{v}`"));
                }
            }
            // Resolution order is the checker's: local, function, variant, built-in.
            Expr::Call(name, args) => {
                if let Some(i) = self.lookup(name) {
                    self.byte(E_CALL_LOCAL);
                    self.len(i);
                    self.exprs(args);
                } else if self.env.fns.contains(name.as_str()) {
                    self.byte(E_CALL_FN);
                    self.reference(name);
                    self.exprs(args);
                } else if self.is_variant(name) {
                    self.variant(name, args);
                } else if Builtin::NAMES.contains(&name.as_str()) {
                    self.byte(E_BUILTIN);
                    self.str(name);
                    self.exprs(args);
                } else {
                    self.fail(format!("unknown name `{name}`"));
                }
            }
            Expr::Bin(op, l, r) => {
                self.byte(E_BIN);
                self.byte(binop_tag(*op));
                self.expr(l);
                self.expr(r);
            }
            Expr::Un(op, x) => {
                self.byte(E_UN);
                self.byte(match op {
                    UnOp::Neg => 0,
                    UnOp::Not => 1,
                });
                self.expr(x);
            }
            Expr::If(c, t, f) => {
                self.byte(E_IF);
                self.expr(c);
                self.expr(t);
                self.expr(f);
            }
            Expr::Let(name, ann, v, body) => {
                self.byte(E_LET);
                match ann {
                    Some(t) => {
                        self.byte(1);
                        self.ty(t);
                    }
                    None => self.byte(0),
                }
                self.expr(v);
                self.bind(name);
                self.expr(body);
                self.scope.pop();
            }
            Expr::List(items) => {
                self.byte(E_LIST);
                self.exprs(items);
            }
            Expr::Record(name, fields) => {
                self.byte(E_RECORD);
                if !self.env.types.contains(name.as_str()) {
                    self.fail(format!("unknown type `{name}`"));
                }
                self.reference(name);
                self.len(fields.len());
                for (f, x) in fields {
                    self.str(f);
                    self.expr(x);
                }
            }
            Expr::Field(target, field) => {
                self.byte(E_FIELD);
                self.expr(target);
                self.str(field);
            }
            Expr::Match(s, arms) => {
                self.byte(E_MATCH);
                self.expr(s);
                self.len(arms.len());
                for a in arms {
                    let mark = self.scope.len();
                    self.pat(&a.pat);
                    match &a.guard {
                        Some(g) => {
                            self.byte(1);
                            self.expr(g);
                        }
                        None => self.byte(0),
                    }
                    self.expr(&a.body);
                    self.scope.truncate(mark);
                }
            }
            Expr::Seq(items) => {
                self.byte(E_SEQ);
                self.exprs(items);
            }
        }
    }

    fn pat(&mut self, p: &Pat) {
        match p {
            Pat::Wild => self.byte(P_WILD),
            Pat::Bind(n) => {
                self.byte(P_BIND);
                self.bind(n);
            }
            Pat::Int(n) => {
                self.byte(P_INT);
                self.i64(*n);
            }
            Pat::Str(s) => {
                self.byte(P_STR);
                self.str(s);
            }
            Pat::Bool(b) => {
                self.byte(P_BOOL);
                self.byte(*b as u8);
            }
            Pat::Unit => self.byte(P_UNIT),
            Pat::Variant(name, ps) => {
                self.byte(P_VARIANT);
                if !self.variant_owner(name) {
                    self.fail(format!("unknown variant `{name}`"));
                }
                self.str(name);
                self.len(ps.len());
                for p in ps {
                    self.pat(p);
                }
            }
            Pat::Record(name, fs) => {
                self.byte(P_RECORD);
                if !self.env.types.contains(name.as_str()) {
                    self.fail(format!("unknown type `{name}`"));
                }
                self.reference(name);
                self.len(fs.len());
                for (f, p) in fs {
                    self.str(f);
                    self.pat(p);
                }
            }
        }
    }

    fn member(&mut self, d: &Def) {
        self.byte(Kind::of(d).tag());
        match d {
            Def::Type(t) => match &t.body {
                TypeBody::Record(fields) => {
                    self.byte(0);
                    self.len(fields.len());
                    for (f, ty) in fields {
                        self.str(f);
                        self.ty(ty);
                    }
                }
                TypeBody::Enum(vs) => {
                    self.byte(1);
                    self.len(vs.len());
                    for v in vs {
                        self.str(&v.name);
                        self.len(v.fields.len());
                        for ty in &v.fields {
                            self.ty(ty);
                        }
                    }
                }
            },
            Def::Fn(f) => {
                self.len(f.params.len());
                for p in &f.params {
                    self.ty(&p.ty);
                }
                self.ty(&f.ret);
                self.effects(&f.effects);
                for p in &f.params {
                    self.bind(&p.name);
                }
                self.exprs(&f.req);
                self.len(f.ens.len());
                if !f.ens.is_empty() {
                    // `r` is bound for the postconditions only and is not a stored local name.
                    self.scope.push(RESULT_VAR.to_string());
                    for c in &f.ens {
                        self.expr(c);
                    }
                    self.scope.pop();
                }
                self.expr(&f.body);
            }
            Def::Test(t) => self.expr(&t.body),
        }
    }
}

/// Encodes `d` (its member part only), returning (bytes, local names) or the first unresolved name.
fn encode_member(env: &Env, d: &Def, refs: &mut dyn FnMut(&str) -> Ref) -> Result<(Vec<u8>, Vec<String>), String> {
    let mut enc = Enc { env, refs, out: Vec::new(), scope: Vec::new(), locals: Vec::new(), err: None };
    enc.member(d);
    match enc.err {
        Some(e) => Err(format!("`{}`: {e}", d.name())),
        None => Ok((enc.out, enc.locals)),
    }
}

/// Names of the program's definitions that `d` refers to (as resolved by the encoder).
fn references(env: &Env, d: &Def) -> Result<BTreeSet<String>, String> {
    let mut names = BTreeSet::new();
    let mut record = |n: &str| {
        names.insert(n.to_string());
        Ref::Group(0)
    };
    encode_member(env, d, &mut record)?;
    Ok(names)
}

fn put_varint(out: &mut Vec<u8>, mut n: u64) {
    loop {
        let b = (n & 0x7f) as u8;
        n >>= 7;
        if n == 0 {
            out.push(b);
            return;
        }
        out.push(b | 0x80);
    }
}

fn prefix(size: usize) -> Vec<u8> {
    let mut out = MAGIC.to_vec();
    out.push(VERSION);
    put_varint(&mut out, size as u64);
    out
}

/// Canonical form of a definition outside any group.
fn single_form(member: &[u8]) -> Vec<u8> {
    let mut out = prefix(1);
    out.push(0);
    out.extend_from_slice(member);
    out
}

fn group_form(members: &[Vec<u8>]) -> Vec<u8> {
    let mut out = prefix(members.len());
    for m in members {
        out.extend_from_slice(m);
    }
    out
}

fn member_form(size: usize, index: usize, group: &Hash) -> Vec<u8> {
    let mut out = prefix(size);
    put_varint(&mut out, index as u64);
    out.extend_from_slice(&group.0);
    out
}

/// Strongly connected components of `edges` (indices), each listed after every component it reaches.
fn sccs(n: usize, edges: &[Vec<usize>]) -> Vec<Vec<usize>> {
    // Iterative Tarjan: no recursion, so long dependency chains cannot overflow the stack.
    let mut index = vec![usize::MAX; n];
    let mut low = vec![0; n];
    let mut on_stack = vec![false; n];
    let mut stack = Vec::new();
    let mut out = Vec::new();
    let mut next = 0;
    for root in 0..n {
        if index[root] != usize::MAX {
            continue;
        }
        let mut work: Vec<(usize, usize)> = vec![(root, 0)];
        index[root] = next;
        low[root] = next;
        next += 1;
        stack.push(root);
        on_stack[root] = true;
        while let Some(&mut (v, ref mut i)) = work.last_mut() {
            if *i < edges[v].len() {
                let w = edges[v][*i];
                *i += 1;
                if index[w] == usize::MAX {
                    index[w] = next;
                    low[w] = next;
                    next += 1;
                    stack.push(w);
                    on_stack[w] = true;
                    work.push((w, 0));
                } else if on_stack[w] {
                    low[v] = low[v].min(index[w]);
                }
            } else {
                work.pop();
                if let Some(&(parent, _)) = work.last() {
                    low[parent] = low[parent].min(low[v]);
                }
                if low[v] == index[v] {
                    let mut comp = Vec::new();
                    while let Some(w) = stack.pop() {
                        on_stack[w] = false;
                        comp.push(w);
                        if w == v {
                            break;
                        }
                    }
                    comp.sort_unstable();
                    out.push(comp);
                }
            }
        }
    }
    out
}

/// Computes the canonical form and hash of every definition of `p` (result in `p.defs` order).
/// `p` must have passed the checker; unresolved names are an error, never a panic.
pub fn hash_program(p: &Program) -> Result<Hashed, HashError> {
    let internal = HashError::Internal;
    let env = Env::new(p);
    let mut by_name: HashMap<&str, usize> = HashMap::new();
    for (i, d) in p.defs.iter().enumerate() {
        if by_name.insert(d.name(), i).is_some() {
            return Err(internal(format!("`{}` is defined more than once", d.name())));
        }
    }
    let mut edges = Vec::with_capacity(p.defs.len());
    for d in &p.defs {
        let names = references(&env, d).map_err(internal)?;
        edges.push(names.iter().filter_map(|n| by_name.get(n.as_str()).copied()).collect::<Vec<_>>());
    }
    let mut hashes: Vec<Option<Hash>> = vec![None; p.defs.len()];
    let mut out: Vec<Option<Canon>> = vec![None; p.defs.len()];
    let mut groups = std::collections::BTreeMap::new();
    for comp in sccs(p.defs.len(), &edges) {
        let order = order_group(&env, p, &comp, &by_name, &hashes)?;
        let pos: HashMap<usize, u32> = order.iter().enumerate().map(|(k, &d)| (d, k as u32)).collect();
        let mut members = Vec::new();
        let mut locals = Vec::new();
        for &d in &order {
            let mut refs = |n: &str| resolve(n, &by_name, &pos, &hashes);
            let (bytes, names) = encode_member(&env, &p.defs[d], &mut refs).map_err(internal)?;
            members.push(bytes);
            locals.push(names);
        }
        let (forms, group): (Vec<Vec<u8>>, Option<Hash>) = if order.len() == 1 {
            (vec![single_form(&members[0])], None)
        } else {
            let g = group_form(&members);
            let gh = Hash::of(&g);
            groups.insert(gh, g);
            ((0..order.len()).map(|k| member_form(order.len(), k, &gh)).collect(), Some(gh))
        };
        for (k, &d) in order.iter().enumerate() {
            hashes[d] = Some(Hash::of(&forms[k]));
        }
        for (k, &d) in order.iter().enumerate() {
            let def = &p.defs[d];
            let hash = hashes[d].ok_or_else(|| internal("unhashed member".into()))?;
            let mut deps: Vec<Hash> = edges[d].iter().filter_map(|&w| hashes[w]).filter(|h| *h != hash).collect();
            deps.sort();
            deps.dedup();
            let sig_name = |n: &str| by_name.get(n).and_then(|&i| hashes[i]).map(|h| format!("#{h}")).unwrap_or_else(|| n.to_string());
            out[d] = Some(Canon {
                name: def.name().to_string(),
                kind: Kind::of(def),
                hash,
                canonical: forms[k].clone(),
                group,
                local_names: std::mem::take(&mut locals[k]),
                deps,
                signature: signature_text(def, &sig_name),
                effects: match def {
                    Def::Fn(f) => sorted_effects(&f.effects),
                    _ => Vec::new(),
                },
            });
        }
    }
    let defs = out.into_iter().collect::<Option<Vec<_>>>().ok_or_else(|| internal("a definition is in no component".into()))?;
    Ok(Hashed { defs, groups })
}

fn resolve(n: &str, by_name: &HashMap<&str, usize>, pos: &HashMap<usize, u32>, hashes: &[Option<Hash>]) -> Ref {
    // Every referenced name is a definition of the program (the encoder checked the name first).
    let Some(&i) = by_name.get(n) else { return Ref::Group(u32::MAX) };
    match pos.get(&i) {
        Some(k) => Ref::Group(*k),
        None => Ref::Hash(hashes[i].unwrap_or(Hash([0; 32]))),
    }
}

/// Canonical labelling of a group: positions that depend only on the members' structure.
struct Labeller<'a> {
    env: &'a Env<'a>,
    p: &'a Program,
    comp: &'a [usize],
    by_name: &'a HashMap<&'a str, usize>,
    hashes: &'a [Option<Hash>],
    best: Option<(Vec<u8>, Vec<usize>)>,
    symmetric: bool,
    nodes: usize,
    work: std::cell::Cell<usize>,
}

impl Labeller<'_> {
    /// Definition index -> label, for `encode`.
    fn by_def(&self, labels: &[u32]) -> HashMap<usize, u32> {
        self.comp.iter().enumerate().map(|(j, &d)| (d, labels[j])).collect()
    }

    /// Member `i` encoded with in-group references written as the labels (`lab`) of their targets.
    fn encode(&self, i: usize, lab: &HashMap<usize, u32>) -> Result<Vec<u8>, HashError> {
        self.work.set(self.work.get() + 1);
        if self.work.get() > MAX_LABEL_WORK {
            return Err(HashError::TooLarge(self.names()));
        }
        let mut refs = |n: &str| resolve(n, self.by_name, lab, self.hashes);
        encode_member(self.env, &self.p.defs[self.comp[i]], &mut refs).map(|x| x.0).map_err(HashError::Internal)
    }

    /// Refines labels until stable: the new label ranks (old label, encoding with old labels).
    fn refine(&self, mut labels: Vec<u32>) -> Result<Vec<u32>, HashError> {
        loop {
            let before = labels.iter().collect::<BTreeSet<_>>().len();
            let lab = self.by_def(&labels);
            let mut keys = Vec::with_capacity(labels.len());
            for i in 0..labels.len() {
                keys.push((labels[i], self.encode(i, &lab)?));
            }
            let mut distinct: Vec<&(u32, Vec<u8>)> = keys.iter().collect();
            distinct.sort();
            distinct.dedup();
            labels = keys.iter().map(|k| distinct.binary_search(&k).unwrap_or(0) as u32).collect();
            if distinct.len() == before {
                return Ok(labels);
            }
        }
    }

    /// Individualization–refinement over every choice; keeps the smallest group form.
    fn search(&mut self, labels: Vec<u32>) -> Result<(), HashError> {
        self.nodes += 1;
        if self.nodes > MAX_LABEL_NODES {
            return Err(HashError::TooLarge(self.names()));
        }
        let labels = self.refine(labels)?;
        let k = labels.len();
        let mut count: HashMap<u32, usize> = HashMap::new();
        for l in &labels {
            *count.entry(*l).or_default() += 1;
        }
        let Some(target) = labels.iter().copied().filter(|l| count[l] > 1).min() else {
            // A leaf: labels are the positions 0..k.
            let mut order = vec![0; k];
            for (i, l) in labels.iter().enumerate() {
                order[*l as usize] = self.comp[i];
            }
            let lab = self.by_def(&labels);
            let mut at = vec![0; k];
            for (i, l) in labels.iter().enumerate() {
                at[*l as usize] = i;
            }
            let mut form = Vec::new();
            for i in at {
                form.extend(self.encode(i, &lab)?);
            }
            match &self.best {
                Some((b, o)) if form == *b => self.symmetric |= *o != order,
                Some((b, _)) if form > *b => {}
                _ => {
                    self.best = Some((form, order));
                    self.symmetric = false;
                }
            }
            return Ok(());
        };
        for i in 0..k {
            if labels[i] != target {
                continue;
            }
            let next: Vec<u32> = labels
                .iter()
                .enumerate()
                .map(|(j, &l)| match l.cmp(&target) {
                    std::cmp::Ordering::Less => 2 * l,
                    std::cmp::Ordering::Equal if j == i => 2 * l,
                    _ => 2 * l + 1,
                })
                .collect();
            self.search(next)?;
        }
        Ok(())
    }

    fn names(&self) -> Vec<String> {
        let mut names: Vec<String> = self.comp.iter().map(|&d| self.p.defs[d].name().to_string()).collect();
        names.sort();
        names
    }
}

/// The members of a component in canonical order (see the module documentation).
fn order_group(env: &Env, p: &Program, comp: &[usize], by_name: &HashMap<&str, usize>, hashes: &[Option<Hash>]) -> Result<Vec<usize>, HashError> {
    if comp.len() == 1 {
        return Ok(comp.to_vec());
    }
    let mut l = Labeller { env, p, comp, by_name, hashes, best: None, symmetric: false, nodes: 0, work: std::cell::Cell::new(0) };
    l.search(vec![0; comp.len()])?;
    if l.symmetric {
        return Err(HashError::Symmetric(l.names()));
    }
    l.best.map(|(_, order)| order).ok_or_else(|| HashError::Internal("no labelling".into()))
}

/// Replaces every `Named` type name through `f`.
fn map_named(t: &Type, f: &dyn Fn(&str) -> String) -> Type {
    match t {
        Type::Named(n) => Type::Named(f(n)),
        Type::List(x) => Type::list(map_named(x, f)),
        Type::Option(x) => Type::option(map_named(x, f)),
        Type::Result(a, b) => Type::result(map_named(a, f), map_named(b, f)),
        Type::Fn(ps, r, e) => Type::Fn(ps.iter().map(|p| map_named(p, f)).collect(), Box::new(map_named(r, f)), sorted_effects(e)),
        t => t.clone(),
    }
}

fn sorted_effects(e: &[String]) -> Vec<String> {
    e.iter().collect::<BTreeSet<_>>().into_iter().cloned().collect()
}

/// A definition's signature with type names mapped through `f` (see [`Canon::signature`]).
pub fn signature_text(d: &Def, f: &dyn Fn(&str) -> String) -> String {
    match d {
        Def::Fn(fd) => {
            let t = Type::Fn(fd.params.iter().map(|p| p.ty.clone()).collect(), Box::new(fd.ret.clone()), fd.effects.clone());
            map_named(&t, f).to_string()
        }
        Def::Type(t) => match &t.body {
            TypeBody::Record(fields) => {
                let fs: Vec<String> = fields.iter().map(|(n, ty)| format!("{n}: {}", map_named(ty, f))).collect();
                format!("{{ {} }}", fs.join(", "))
            }
            TypeBody::Enum(vs) if vs.is_empty() => "|".to_string(),
            TypeBody::Enum(vs) => {
                let vs: Vec<String> = vs
                    .iter()
                    .map(|v| {
                        if v.fields.is_empty() {
                            v.name.clone()
                        } else {
                            let fs: Vec<String> = v.fields.iter().map(|t| map_named(t, f).to_string()).collect();
                            format!("{}({})", v.name, fs.join(", "))
                        }
                    })
                    .collect();
                vs.join(" | ")
            }
        },
        Def::Test(_) => "Bool".to_string(),
    }
}

/// Parses the header of a member's canonical form.
pub fn header(canonical: &[u8]) -> Result<Header, String> {
    let mut d = Dec::new(canonical);
    d.header()
}

/// The hashes of the other definitions (including other members of its group) a canonical form
/// refers to, sorted and without duplicates.
pub fn references_of(form: Form) -> Result<Vec<Hash>, String> {
    let locals = vec![String::from("x"); count_binders(form)?];
    let mut seen = Vec::new();
    decode_raw(form, "self", &locals, &mut |h| {
        seen.push(*h);
        String::new()
    })?;
    seen.sort();
    seen.dedup();
    Ok(seen)
}

/// Number of local-variable binders of the member (the length its local names need). Also
/// validates the whole form, including the group form's hash.
pub fn count_binders(form: Form) -> Result<usize, String> {
    let mut d = Dec::new(form.canonical);
    d.open(form)?;
    let mut found = None;
    for k in 0..d.size {
        let before = d.binders;
        d.member_def("x", &mut |_| String::new())?;
        if k == d.index {
            found = Some(d.binders - before);
        }
    }
    if d.pos != d.b.len() {
        return Err("trailing bytes after the last group member".into());
    }
    found.ok_or_else(|| "member index out of range".into())
}

/// Decodes the definition `form` encodes, naming it `name`, its locals from `local_names` (binding
/// order), and every referenced definition through `name_of`. Local names that would capture a
/// referenced definition's name are renamed (`x` -> `x_1`), so the result means what was stored.
pub fn decode(form: Form, name: &str, local_names: &[String], name_of: &mut dyn FnMut(&Hash) -> String) -> Result<Def, String> {
    // First pass: which definition names does the text refer to?
    let mut cache: HashMap<Hash, String> = HashMap::new();
    let mut globals: HashSet<String> = HashSet::new();
    let (_, self_ref) = decode_raw(form, name, local_names, &mut |h| {
        let n = cache.entry(*h).or_insert_with(|| name_of(h)).clone();
        globals.insert(n.clone());
        n
    })?;
    if self_ref {
        globals.insert(name.to_string());
    }
    let locals = avoid_capture(local_names, &globals);
    let (def, _) = decode_raw(form, name, &locals, &mut |h| cache.get(h).cloned().unwrap_or_default())?;
    Ok(def)
}

/// Renames locals whose name equals a referenced definition's name (consistently, so shadowing
/// between locals is kept).
fn avoid_capture(local_names: &[String], globals: &HashSet<String>) -> Vec<String> {
    let mut taken: HashSet<String> = local_names.iter().chain(globals.iter()).cloned().collect();
    let mut renamed: HashMap<String, String> = HashMap::new();
    local_names
        .iter()
        .map(|n| {
            if !globals.contains(n) {
                return n.clone();
            }
            renamed
                .entry(n.clone())
                .or_insert_with(|| {
                    let mut k = 1;
                    while taken.contains(&format!("{n}_{k}")) {
                        k += 1;
                    }
                    let c = format!("{n}_{k}");
                    taken.insert(c.clone());
                    c
                })
                .clone()
        })
        .collect()
}

/// Decodes the member; also returns whether it refers to itself.
fn decode_raw(form: Form, name: &str, local_names: &[String], name_of: &mut dyn FnMut(&Hash) -> String) -> Result<(Def, bool), String> {
    let mut d = Dec::new(form.canonical);
    d.open(form)?;
    let mut result = None;
    for k in 0..d.size {
        if k == d.index {
            d.counting = false;
            d.names = local_names.to_vec();
            d.self_refs = false;
            let def = d.member_def(name, name_of)?;
            if d.next_name != local_names.len() {
                return Err(format!("{} local names stored, {} binders", local_names.len(), d.next_name));
            }
            result = Some((def, d.self_refs));
            d.counting = true;
        } else {
            d.member_def(name, &mut |_| String::new())?;
        }
    }
    if d.pos != d.b.len() {
        return Err("trailing bytes after the last group member".into());
    }
    result.ok_or_else(|| "member index out of range".into())
}

struct Dec<'b> {
    b: &'b [u8],
    pos: usize,
    depth: usize,
    ty_depth: usize,
    size: usize,
    index: usize,
    /// Hashes of the other group members (None for the decoded member itself).
    others: Vec<Option<Hash>>,
    /// Skipping (not building) a member: names are not needed, binders are only counted.
    counting: bool,
    binders: usize,
    self_refs: bool,
    names: Vec<String>,
    next_name: usize,
    scope: Vec<String>,
}

type R<T> = Result<T, String>;

#[cold]
fn bad_tag(what: &str, t: u8) -> String {
    format!("bad {what} tag {t}")
}

impl<'b> Dec<'b> {
    fn new(b: &'b [u8]) -> Dec<'b> {
        Dec {
            b,
            pos: 0,
            depth: 0,
            ty_depth: 0,
            size: 0,
            index: 0,
            others: Vec::new(),
            counting: true,
            binders: 0,
            self_refs: false,
            names: Vec::new(),
            next_name: 0,
            scope: Vec::new(),
        }
    }

    fn prefix(&mut self) -> R<usize> {
        if self.b.len() < 5 || &self.b[..4] != MAGIC {
            return Err("not a QAL canonical form".into());
        }
        if self.b[4] != VERSION {
            return Err(format!("unsupported canonical form version {}", self.b[4]));
        }
        self.pos = 5;
        let size = self.index()?;
        if size == 0 {
            return Err("empty group".into());
        }
        Ok(size)
    }

    fn header(&mut self) -> R<Header> {
        let size = self.prefix()?;
        let index = self.index()?;
        if index >= size {
            return Err(format!("bad header (size {size}, index {index})"));
        }
        let group = if size == 1 {
            None
        } else {
            let bytes = self.b.get(self.pos..self.pos + 32).ok_or("truncated canonical form")?;
            self.pos += 32;
            if self.pos != self.b.len() {
                return Err("trailing bytes after the group hash".into());
            }
            Some(Hash(bytes.try_into().map_err(|_| "bad group hash")?))
        };
        self.size = size;
        self.index = index;
        Ok(Header { size, index, group })
    }

    /// Reads the header and positions the decoder at the first member (of the group form, for a
    /// member of a group).
    fn open(&mut self, form: Form<'b>) -> R<()> {
        let h = self.header()?;
        let Some(gh) = h.group else { return Ok(()) };
        let group = form.group.ok_or("the group form is missing")?;
        if Hash::of(group) != gh {
            return Err("the group form does not match its hash".into());
        }
        self.b = group;
        if self.prefix()? != h.size {
            return Err("the group form has another size".into());
        }
        self.others = (0..h.size).map(|j| if j == h.index { None } else { Some(Hash::of(&member_form(h.size, j, &gh))) }).collect();
        Ok(())
    }

    fn byte(&mut self) -> R<u8> {
        let b = *self.b.get(self.pos).ok_or("truncated canonical form")?;
        self.pos += 1;
        Ok(b)
    }

    fn varint(&mut self) -> R<u64> {
        let mut n: u64 = 0;
        for shift in (0..64).step_by(7) {
            let b = self.byte()?;
            n |= u64::from(b & 0x7f) << shift;
            if b & 0x80 == 0 {
                if b == 0 && shift > 0 {
                    return Err("non-minimal varint".into());
                }
                return Ok(n);
            }
        }
        Err("varint too long".into())
    }

    /// A count of items (each at least one byte) or bytes: bounded by the remaining input, so
    /// corrupt input cannot request huge allocations.
    fn count(&mut self) -> R<usize> {
        let n = self.varint()?;
        if n > (self.b.len() - self.pos) as u64 {
            return Err("count exceeds the canonical form's size".into());
        }
        Ok(n as usize)
    }

    /// An index (De Bruijn or group); the caller checks its range.
    fn index(&mut self) -> R<usize> {
        usize::try_from(self.varint()?).map_err(|_| "index out of range".to_string())
    }

    fn i64(&mut self) -> R<i64> {
        let bytes = self.b.get(self.pos..self.pos + 8).ok_or("truncated canonical form")?;
        self.pos += 8;
        Ok(i64::from_le_bytes(bytes.try_into().expect("8 bytes")))
    }

    fn str(&mut self) -> R<String> {
        let n = self.count()?;
        let bytes = self.b.get(self.pos..self.pos + n).ok_or("truncated canonical form")?;
        self.pos += n;
        String::from_utf8(bytes.to_vec()).map_err(|_| "invalid UTF-8 in canonical form".into())
    }

    fn enter(&mut self) -> R<()> {
        self.depth += 1;
        if self.depth > MAX_DECODE_DEPTH {
            return Err("canonical form nested too deeply".into());
        }
        Ok(())
    }

    fn flag(&mut self) -> R<bool> {
        match self.byte()? {
            0 => Ok(false),
            1 => Ok(true),
            t => Err(bad_tag("flag", t)),
        }
    }

    fn reference(&mut self, own: &str, name_of: &mut dyn FnMut(&Hash) -> String) -> R<String> {
        match self.byte()? {
            R_HASH => {
                let bytes = self.b.get(self.pos..self.pos + 32).ok_or("truncated canonical form")?;
                self.pos += 32;
                let h = Hash(bytes.try_into().expect("32 bytes"));
                Ok(if self.counting { String::new() } else { name_of(&h) })
            }
            R_GROUP => {
                let j = self.index()?;
                if j >= self.size {
                    return Err(format!("group reference {j} out of range"));
                }
                if j == self.index {
                    self.self_refs = true;
                    return Ok(own.to_string());
                }
                if self.counting {
                    return Ok(String::new());
                }
                let h = self.others[j].ok_or("bad group reference")?;
                Ok(name_of(&h))
            }
            t => Err(bad_tag("reference", t)),
        }
    }

    /// Effects must be sorted and without duplicates (the canonical set).
    fn effects(&mut self) -> R<Vec<String>> {
        let n = self.count()?;
        let mut out: Vec<String> = Vec::new();
        for _ in 0..n {
            let e = self.str()?;
            if out.last().is_some_and(|prev| *prev >= e) {
                return Err("effects are not a sorted set".into());
            }
            out.push(e);
        }
        Ok(out)
    }

    fn ty(&mut self, own: &str, name_of: &mut dyn FnMut(&Hash) -> String) -> R<Type> {
        self.ty_depth += 1;
        if self.ty_depth > MAX_DECODE_TYPE_DEPTH {
            return Err("canonical form nested too deeply".into());
        }
        let t = self.ty_inner(own, name_of)?;
        self.ty_depth -= 1;
        Ok(t)
    }

    fn ty_inner(&mut self, own: &str, name_of: &mut dyn FnMut(&Hash) -> String) -> R<Type> {
        Ok(match self.byte()? {
            T_INT => Type::Int,
            T_FLOAT => Type::Float,
            T_BOOL => Type::Bool,
            T_UNIT => Type::Unit,
            T_STR => Type::Str,
            T_LIST => Type::List(Box::new(self.ty(own, name_of)?)),
            T_OPTION => Type::Option(Box::new(self.ty(own, name_of)?)),
            T_RESULT => {
                let a = self.ty(own, name_of)?;
                Type::Result(Box::new(a), Box::new(self.ty(own, name_of)?))
            }
            T_NAMED => Type::Named(self.reference(own, name_of)?),
            T_FN => return self.ty_fn(own, name_of),
            t => return Err(bad_tag("type", t)),
        })
    }

    fn ty_fn(&mut self, own: &str, name_of: &mut dyn FnMut(&Hash) -> String) -> R<Type> {
        let n = self.count()?;
        let mut ps = Vec::with_capacity(n.min(16));
        for _ in 0..n {
            ps.push(self.ty(own, name_of)?);
        }
        let r = self.ty(own, name_of)?;
        Ok(Type::Fn(ps, Box::new(r), self.effects()?))
    }

    fn bind(&mut self) -> R<String> {
        self.binders += 1;
        let n = if self.counting {
            String::new()
        } else {
            let n = self.names.get(self.next_name).cloned().ok_or("fewer local names stored than binders")?;
            self.next_name += 1;
            n
        };
        self.scope.push(n.clone());
        Ok(n)
    }

    fn local(&mut self) -> R<String> {
        let i = self.index()?;
        if i >= self.scope.len() {
            return Err(format!("local index {i} out of scope"));
        }
        Ok(self.scope[self.scope.len() - 1 - i].clone())
    }

    fn exprs(&mut self, own: &str, name_of: &mut dyn FnMut(&Hash) -> String) -> R<Vec<Expr>> {
        let n = self.count()?;
        (0..n).map(|_| self.expr(own, name_of)).collect()
    }

    /// Variant owner (+ reference) and name; the name must belong to a built-in owner, and a
    /// declared enum's variant cannot have a built-in variant's name.
    fn variant_name(&mut self, own: &str, name_of: &mut dyn FnMut(&Hash) -> String) -> R<String> {
        let owner = self.byte()?;
        match owner {
            V_OPTION | V_RESULT => {}
            V_ENUM => {
                self.reference(own, name_of)?;
            }
            t => return Err(bad_tag("variant owner", t)),
        }
        let name = self.str()?;
        let ok = match name.as_str() {
            "None" | "Some" => owner == V_OPTION,
            "Ok" | "Err" => owner == V_RESULT,
            _ => owner == V_ENUM,
        };
        if !ok {
            return Err(format!("variant `{name}` does not belong to its owner"));
        }
        Ok(name)
    }

    fn expr(&mut self, own: &str, name_of: &mut dyn FnMut(&Hash) -> String) -> R<Expr> {
        self.enter()?;
        let e = self.expr_inner(own, name_of)?;
        self.depth -= 1;
        Ok(e)
    }

    // Compound cases live in their own functions so the frames on the recursion path stay small.
    fn expr_inner(&mut self, own: &str, name_of: &mut dyn FnMut(&Hash) -> String) -> R<Expr> {
        Ok(match self.byte()? {
            E_INT => Expr::Int(self.i64()?),
            E_FLOAT => Expr::Float(f64::from_bits(self.i64()? as u64)),
            E_BOOL => Expr::Bool(self.flag()?),
            E_STR => Expr::Str(self.str()?),
            E_UNIT => Expr::Unit,
            E_LOCAL => Expr::Var(self.local()?),
            E_FN_REF => Expr::Var(self.reference(own, name_of)?),
            E_VARIANT => return self.e_variant(own, name_of),
            E_CALL_LOCAL | E_CALL_FN | E_BUILTIN => return self.e_call(own, name_of),
            E_BIN => return self.e_bin(own, name_of),
            E_UN => return self.e_un(own, name_of),
            E_IF => return self.e_if(own, name_of),
            E_LET => return self.e_let(own, name_of),
            E_LIST => Expr::List(self.exprs(own, name_of)?),
            E_RECORD => return self.e_record(own, name_of),
            E_FIELD => return self.e_field(own, name_of),
            E_MATCH => return self.e_match(own, name_of),
            E_SEQ => Expr::Seq(self.exprs(own, name_of)?),
            t => return Err(bad_tag("expression", t)),
        })
    }

    fn e_variant(&mut self, own: &str, name_of: &mut dyn FnMut(&Hash) -> String) -> R<Expr> {
        let name = self.variant_name(own, name_of)?;
        let args = self.exprs(own, name_of)?;
        Ok(if args.is_empty() { Expr::Var(name) } else { Expr::Call(name, args) })
    }

    /// The tag byte was just read.
    fn e_call(&mut self, own: &str, name_of: &mut dyn FnMut(&Hash) -> String) -> R<Expr> {
        let f = match self.b[self.pos - 1] {
            E_CALL_LOCAL => self.local()?,
            E_CALL_FN => self.reference(own, name_of)?,
            _ => {
                let f = self.str()?;
                if !Builtin::NAMES.contains(&f.as_str()) {
                    return Err(format!("unknown built-in `{f}`"));
                }
                f
            }
        };
        Ok(Expr::Call(f, self.exprs(own, name_of)?))
    }

    fn e_bin(&mut self, own: &str, name_of: &mut dyn FnMut(&Hash) -> String) -> R<Expr> {
        let t = self.byte()?;
        let op = *BINOPS.get(t as usize).ok_or_else(|| bad_tag("operator", t))?;
        let l = self.expr(own, name_of)?;
        Ok(Expr::Bin(op, Box::new(l), Box::new(self.expr(own, name_of)?)))
    }

    fn e_un(&mut self, own: &str, name_of: &mut dyn FnMut(&Hash) -> String) -> R<Expr> {
        let op = match self.byte()? {
            0 => UnOp::Neg,
            1 => UnOp::Not,
            t => return Err(bad_tag("unary operator", t)),
        };
        Ok(Expr::Un(op, Box::new(self.expr(own, name_of)?)))
    }

    fn e_if(&mut self, own: &str, name_of: &mut dyn FnMut(&Hash) -> String) -> R<Expr> {
        let c = self.expr(own, name_of)?;
        let t = self.expr(own, name_of)?;
        Ok(Expr::If(Box::new(c), Box::new(t), Box::new(self.expr(own, name_of)?)))
    }

    fn e_let(&mut self, own: &str, name_of: &mut dyn FnMut(&Hash) -> String) -> R<Expr> {
        let ann = if self.flag()? { Some(self.ty(own, name_of)?) } else { None };
        let v = self.expr(own, name_of)?;
        let name = self.bind()?;
        let body = self.expr(own, name_of)?;
        self.scope.pop();
        Ok(Expr::Let(name, ann, Box::new(v), Box::new(body)))
    }

    fn e_record(&mut self, own: &str, name_of: &mut dyn FnMut(&Hash) -> String) -> R<Expr> {
        let name = self.reference(own, name_of)?;
        let n = self.count()?;
        let mut fields = Vec::with_capacity(n.min(16));
        for _ in 0..n {
            let f = self.str()?;
            fields.push((f, self.expr(own, name_of)?));
        }
        Ok(Expr::Record(name, fields))
    }

    fn e_field(&mut self, own: &str, name_of: &mut dyn FnMut(&Hash) -> String) -> R<Expr> {
        let t = self.expr(own, name_of)?;
        Ok(Expr::Field(Box::new(t), self.str()?))
    }

    fn e_match(&mut self, own: &str, name_of: &mut dyn FnMut(&Hash) -> String) -> R<Expr> {
        let s = self.expr(own, name_of)?;
        let n = self.count()?;
        let mut arms = Vec::with_capacity(n.min(16));
        for _ in 0..n {
            let mark = self.scope.len();
            let pat = self.pat(own, name_of)?;
            let guard = if self.flag()? { Some(self.expr(own, name_of)?) } else { None };
            let body = self.expr(own, name_of)?;
            self.scope.truncate(mark);
            arms.push(Arm { pat, guard, body });
        }
        Ok(Expr::Match(Box::new(s), arms))
    }

    fn pat(&mut self, own: &str, name_of: &mut dyn FnMut(&Hash) -> String) -> R<Pat> {
        self.enter()?;
        let p = self.pat_inner(own, name_of)?;
        self.depth -= 1;
        Ok(p)
    }

    fn pat_inner(&mut self, own: &str, name_of: &mut dyn FnMut(&Hash) -> String) -> R<Pat> {
        Ok(match self.byte()? {
            P_WILD => Pat::Wild,
            P_BIND => Pat::Bind(self.bind()?),
            P_INT => Pat::Int(self.i64()?),
            P_STR => Pat::Str(self.str()?),
            P_BOOL => Pat::Bool(self.flag()?),
            P_UNIT => Pat::Unit,
            P_VARIANT => return self.pat_variant(own, name_of),
            P_RECORD => return self.pat_record(own, name_of),
            t => return Err(bad_tag("pattern", t)),
        })
    }

    fn pat_variant(&mut self, own: &str, name_of: &mut dyn FnMut(&Hash) -> String) -> R<Pat> {
        let name = self.variant_name(own, name_of)?;
        let n = self.count()?;
        let mut ps = Vec::with_capacity(n.min(16));
        for _ in 0..n {
            ps.push(self.pat(own, name_of)?);
        }
        Ok(Pat::Variant(name, ps))
    }

    fn pat_record(&mut self, own: &str, name_of: &mut dyn FnMut(&Hash) -> String) -> R<Pat> {
        let name = self.reference(own, name_of)?;
        let n = self.count()?;
        let mut fs = Vec::with_capacity(n.min(16));
        for _ in 0..n {
            let f = self.str()?;
            fs.push((f, self.pat(own, name_of)?));
        }
        Ok(Pat::Record(name, fs))
    }

    fn member_def(&mut self, name: &str, name_of: &mut dyn FnMut(&Hash) -> String) -> R<Def> {
        self.scope.clear();
        Ok(match self.byte()? {
            0 => Def::Type(TypeDef {
                name: name.to_string(),
                body: match self.byte()? {
                    0 => {
                        let n = self.count()?;
                        let mut fields = Vec::with_capacity(n.min(16));
                        for _ in 0..n {
                            let f = self.str()?;
                            fields.push((f, self.ty(name, name_of)?));
                        }
                        TypeBody::Record(fields)
                    }
                    1 => {
                        let n = self.count()?;
                        let mut vs = Vec::with_capacity(n.min(16));
                        for _ in 0..n {
                            let vname = self.str()?;
                            let k = self.count()?;
                            let fields = (0..k).map(|_| self.ty(name, name_of)).collect::<R<Vec<_>>>()?;
                            vs.push(Variant { name: vname, fields });
                        }
                        TypeBody::Enum(vs)
                    }
                    t => return Err(bad_tag("type body", t)),
                },
            }),
            1 => {
                let n = self.count()?;
                let tys = (0..n).map(|_| self.ty(name, name_of)).collect::<R<Vec<_>>>()?;
                let ret = self.ty(name, name_of)?;
                let effects = self.effects()?;
                let mut params = Vec::with_capacity(n.min(16));
                for ty in tys {
                    params.push(Param { name: self.bind()?, ty });
                }
                let req = self.exprs(name, name_of)?;
                let m = self.count()?;
                self.scope.push(RESULT_VAR.to_string());
                let ens = (0..m).map(|_| self.expr(name, name_of)).collect::<R<Vec<_>>>()?;
                self.scope.pop();
                let body = self.expr(name, name_of)?;
                Def::Fn(FnDef { name: name.to_string(), params, ret, effects, req, ens, body })
            }
            2 => Def::Test(TestDef { name: name.to_string(), body: self.expr(name, name_of)? }),
            t => return Err(bad_tag("definition kind", t)),
        })
    }
}

#[cfg(test)]
mod tests {
    use super::*;

    fn var(s: &str) -> Box<Expr> {
        Box::new(Expr::Var(s.into()))
    }

    fn func(name: &str, param: &str, body: Expr) -> Def {
        Def::Fn(FnDef { name: name.into(), params: vec![Param { name: param.into(), ty: Type::Int }], ret: Type::Int, effects: vec![], req: vec![], ens: vec![], body })
    }

    fn by_name(p: &Program) -> HashMap<String, Canon> {
        hash_program(p).unwrap().defs.into_iter().map(|c| (c.name.clone(), c)).collect()
    }

    fn single(c: &Canon) -> Form<'_> {
        Form::new(&c.canonical, None)
    }

    #[test]
    fn hex_roundtrip_and_display() {
        let h = Hash::of(b"abc");
        assert_eq!(h.to_hex(), "ba7816bf8f01cfea414140de5dae2223b00361a396177a9cb410ff61f20015ad");
        assert_eq!(Hash::from_hex(&h.to_hex()), Some(h));
        assert_eq!(Hash::from_hex("xyz"), None);
        assert_eq!(h.short(), "ba7816bf8f01");
    }

    #[test]
    fn local_names_do_not_change_the_hash() {
        let a = Program { defs: vec![func("f", "x", Expr::Bin(BinOp::Add, var("x"), Box::new(Expr::Int(1))))] };
        let b = Program { defs: vec![func("g", "y", Expr::Bin(BinOp::Add, var("y"), Box::new(Expr::Int(1))))] };
        let (ca, cb) = (&by_name(&a)["f"], &by_name(&b)["g"]);
        assert_eq!(ca.hash, cb.hash);
        assert_eq!(ca.canonical, cb.canonical);
        assert_eq!((ca.local_names.clone(), cb.local_names.clone()), (vec!["x".to_string()], vec!["y".to_string()]));
        assert_eq!(Hash::of(&ca.canonical), ca.hash);
    }

    #[test]
    fn effects_are_a_sorted_set() {
        let mk = |effs: &[&str]| {
            let mut f = func("f", "x", Expr::Unit);
            if let Def::Fn(fd) = &mut f {
                fd.effects = effs.iter().map(|s| s.to_string()).collect();
                fd.ret = Type::Unit;
            }
            by_name(&Program { defs: vec![f] })["f"].clone()
        };
        let (a, b) = (mk(&["io", "fs"]), mk(&["fs", "io", "fs"]));
        assert_eq!(a.hash, b.hash);
        assert_eq!(a.effects, vec!["fs".to_string(), "io".to_string()]);
        assert_eq!(a.signature, "fn(Int) -> Unit !fs !io");
    }

    #[test]
    fn decode_restores_the_definition() {
        let body = Expr::Let("y".into(), None, var("x"), Box::new(Expr::Call("g".into(), vec![Expr::Var("y".into())])));
        let p = Program { defs: vec![func("f", "x", body.clone()), func("g", "z", Expr::Var("z".into()))] };
        let c = by_name(&p);
        let g_hash = c["g"].hash;
        let d = decode(single(&c["f"]), "f", &c["f"].local_names, &mut |h| if *h == g_hash { "g".into() } else { "?".into() }).unwrap();
        assert_eq!(d, p.defs[0]);
        assert_eq!(references_of(single(&c["f"])).unwrap(), vec![g_hash]);
        assert_eq!(c["f"].deps, vec![g_hash]);
        assert_eq!(count_binders(single(&c["f"])).unwrap(), 2);
    }

    #[test]
    fn locals_that_would_capture_a_renamed_reference_are_renamed() {
        // f(x) = helper(x); after renaming `helper` to `x` the parameter must not capture it.
        let p = Program { defs: vec![func("f", "x", Expr::Call("helper".into(), vec![Expr::Var("x".into())])), func("helper", "n", Expr::Var("n".into()))] };
        let c = by_name(&p);
        let d = decode(single(&c["f"]), "f", &c["f"].local_names, &mut |_| "x".into()).unwrap();
        assert_eq!(d, func("f", "x_1", Expr::Call("x".into(), vec![Expr::Var("x_1".into())])));
    }

    #[test]
    fn corrupt_input_is_an_error_not_a_panic() {

```rust
    assert_eq!(hash(&mut s, "one"), hash(&mut s, "uno"));
    let before_user = hash(&mut s, "user");
    // `one` keeps the old hash, so nothing that uses that hash changes (whichever name it was written with).
    let d = ok(&mut s, "fn uno() -> Int = 10");
    assert_eq!(statuses(&d), vec![("uno", "replaced")]);
    assert_eq!(hash(&mut s, "user"), before_user);
    assert_eq!(text(&mut s, "user2"), "fn user2() -> Int\n= one() * 2");
    // Now `one` is the only name of that hash: replacing it moves the users, so the rule applies.
    let d = err(&mut s, "fn one(s: Str) -> Int = len(s)");
    assert_eq!((d[0].kind, d[0].dependents.clone()), ("signature_change", vec!["user".to_string(), "user2".to_string()]));
    // A different signature for one name of a shared hash is not a change for the users of the hash.
    let mut s = store();
    ok(&mut s, "fn one() -> Int = 1\nfn uno() -> Int = 1\nfn user() -> Int = one() + 1");
    assert_eq!(statuses(&ok(&mut s, "fn uno(s: Str) -> Int = len(s)")), vec![("uno", "replaced")]);
    // Once every name of a hash is redefined, its users follow (and need a compatible signature).
    let mut s = store();
    ok(&mut s, "fn one() -> Int = 1\nfn uno() -> Int = 1\nfn user() -> Int = one() + 1");
    let d = ok(&mut s, "fn one() -> Int = 5\nfn uno() -> Int = 5");
    assert_eq!(statuses(&d), vec![("one", "replaced"), ("uno", "replaced"), ("user", "relinked")]);
    assert_eq!(text(&mut s, "user"), "fn user() -> Int\n= one() + 1");
}

fn interchangeable_recursive_definitions_are_rejected() {
```

```rust
//! QAL codebase store (spec §5, §6): content-addressed, checked definitions in `.qal/store.db`.
//!
//! The store keeps definitions by hash (`defs`), what they refer to (`deps`), the readable names
//! (`names`, name -> hash) and every change of a name (`history`). Invariants:
//! 1. A definition is stored only if the whole codebase including it parses and checks.
//! 2. Every dependency of a stored definition is stored; every dependency of a named definition is named.
//! 3. `define` and `rename` are atomic: all their changes are written in one transaction, or none.
//!
//! Every operation reports problems as diagnostics (store failures are `store_error`).

mod define;
mod ops;
mod pattern;
mod schema;
mod snapshot;

pub use ops::{DepView, Entry, HistoryEntry, Query, Renamed, View};
pub use pattern::matches as signature_matches;

use qal_core::ast::Program;
use qal_core::diag::Diagnostic;
use rusqlite::Connection;
use serde::Serialize;
use snapshot::Snapshot;
use std::collections::HashMap;
use std::path::{Path, PathBuf};

/// The store directory and file inside a project.
pub const STORE_DIR: &str = ".qal";
pub const STORE_FILE: &str = "store.db";

/// The result of `define` for one name.
#[derive(Debug, Clone, PartialEq, Serialize)]
pub struct Defined {
    pub name: String,
    /// `type`, `fn` or `test`.
    pub kind: &'static str,
    pub hash: String,
    /// `added` (new name), `replaced` (new version), `unchanged` (same hash), or `relinked`
    /// (a stored dependent that now refers to the new versions).
    pub status: &'static str,
    #[serde(skip_serializing_if = "Option::is_none")]
    pub old_hash: Option<String>,
}

pub struct Store {
    conn: Connection,
    path: PathBuf,
}

pub(crate) fn sql(e: rusqlite::Error) -> Vec<Diagnostic> {
    vec![Diagnostic::store_error(format!("store database error: {e}"))]
}

pub(crate) fn now_ms() -> i64 {
    std::time::SystemTime::now().duration_since(std::time::UNIX_EPOCH).map(|d| d.as_millis() as i64).unwrap_or(0)
}

impl Store {
    /// Creates `<project>/.qal/store.db` if it does not exist yet, and opens it.
    pub fn init(project: &Path) -> Result<Store, Vec<Diagnostic>> {
        let dir = project.join(STORE_DIR);
        std::fs::create_dir_all(&dir).map_err(|e| vec![Diagnostic::store_error(format!("cannot create {}: {e}", dir.display()))])?;
        let path = dir.join(STORE_FILE);
        let mut conn = Connection::open(&path).map_err(sql)?;
        schema::configure(&conn).map_err(sql)?;
        schema::create(&mut conn).map_err(sql)?;
        Store::checked(conn, path)
    }

    /// Opens an existing store file.
    pub fn open(path: &Path) -> Result<Store, Vec<Diagnostic>> {
        if !path.is_file() {
            return Err(vec![Diagnostic::store_error(format!("no QAL store at {}", path.display())).hint("create one with `qal init`")]);
        }
        let conn = Connection::open_with_flags(path, rusqlite::OpenFlags::SQLITE_OPEN_READ_WRITE).map_err(sql)?;
        schema::configure(&conn).map_err(sql)?;
        Store::checked(conn, path.to_path_buf())
    }

    /// Opens the store of the project containing `start`: the nearest `.qal/store.db` in `start` or
    /// one of its ancestors.
    pub fn discover(start: &Path) -> Result<Store, Vec<Diagnostic>> {
        for dir in start.ancestors() {
            let candidate = dir.join(STORE_DIR).join(STORE_FILE);
            if candidate.is_file() {
                return Store::open(&candidate);
            }
        }
        Err(vec![Diagnostic::store_error(format!("no QAL store in {} or its parents", start.display())).hint("create one with `qal init`")])
    }

    fn checked(conn: Connection, path: PathBuf) -> Result<Store, Vec<Diagnostic>> {
        let version: i64 = conn.query_row("PRAGMA user_version", [], |r| r.get(0)).map_err(sql)?;
        if version != schema::SCHEMA_VERSION {
            return Err(vec![Diagnostic::store_error(format!(
                "{} is not a QAL store of version {} (found version {version})",
                path.display(),
                schema::SCHEMA_VERSION
            ))]);
        }
        Ok(Store { conn, path })
    }

    pub fn path(&self) -> &Path {
        &self.path
    }

    /// The whole named codebase as a program (checked when it was stored).
    pub fn program(&mut self) -> Result<Program, Vec<Diagnostic>> {
        let tx = self.conn.transaction().map_err(sql)?;
        let snap = Snapshot::load(&tx)?;
        snap.program(&tx, &HashMap::new(), &|_| false)
    }

    /// Adds or replaces the definitions in `src` (spec §6). Either everything is stored and the
    /// result lists every name that changed or was given, or nothing is stored and the diagnostics
    /// say why. `agent` is recorded in the history.
    pub fn define(&mut self, src: &str, agent: &str) -> Result<Vec<Defined>, Vec<Diagnostic>> {
        define::define(&mut self.conn, src, agent)
    }

    /// Renames a definition. No hash changes; the history of `old` moves to `new`.
    pub fn rename(&mut self, old: &str, new: &str, agent: &str) -> Result<Renamed, Vec<Diagnostic>> {
        ops::rename(&mut self.conn, old, new, agent)
    }

    /// Text, signature and direct dependencies of each name (or `#<hash>`).
    pub fn view(&mut self, names: &[String]) -> Result<Vec<View>, Vec<Diagnostic>> {
        ops::view(&mut self.conn, names)
    }

    /// Named definitions matching every given filter, sorted by name.
    pub fn query(&mut self, q: &Query) -> Result<Vec<Entry>, Vec<Diagnostic>> {
        ops::query(&mut self.conn, q)
    }

    /// Every recorded change of `name`, oldest first.
    pub fn history(&mut self, name: &str) -> Result<Vec<HistoryEntry>, Vec<Diagnostic>> {
        ops::history(&mut self.conn, name)
    }
}
```

```rust
//! SQLite schema of `.qal/store.db` (spec §6) and connection setup.

use rusqlite::Connection;
use std::time::Duration;

/// `PRAGMA user_version` of stores this code reads and writes.
pub const SCHEMA_VERSION: i64 = 1;

/// How long a writer waits for another process's `define`/`rename` to finish.
pub const BUSY_TIMEOUT: Duration = Duration::from_secs(10);

/// Hashes are lowercase hex (`TEXT`); times are Unix milliseconds; list columns are JSON arrays.
/// A member of a mutually recursive group stores a short canonical form that names its group;
/// the group form itself is stored once in `groups`.
/// `names.local_names` is the local-variable naming of that name's latest text (two names can share
/// a hash but name their locals differently); `defs.local_names` is the one it was first stored with.
pub const SCHEMA: &str = "
CREATE TABLE groups (
    hash TEXT PRIMARY KEY,
    form BLOB NOT NULL
);
CREATE TABLE defs (
    hash        TEXT PRIMARY KEY,
    kind        TEXT NOT NULL CHECK (kind IN ('type', 'fn', 'test')),
    canonical   BLOB NOT NULL,
    signature   TEXT NOT NULL,
    effects     TEXT NOT NULL,
    local_names TEXT NOT NULL,
    created_at  INTEGER NOT NULL
);
CREATE TABLE deps (
    hash     TEXT NOT NULL REFERENCES defs(hash),
    dep_hash TEXT NOT NULL REFERENCES defs(hash),
    PRIMARY KEY (hash, dep_hash)
);
CREATE INDEX deps_by_dep ON deps(dep_hash);
CREATE TABLE names (
    name        TEXT PRIMARY KEY,
    hash        TEXT NOT NULL REFERENCES defs(hash),
    local_names TEXT NOT NULL,
    updated_at  INTEGER NOT NULL
);
CREATE INDEX names_by_hash ON names(hash);
CREATE TABLE history (
    id        INTEGER PRIMARY KEY,
    name      TEXT NOT NULL,
    action    TEXT NOT NULL CHECK (action IN ('added', 'replaced', 'relinked', 'renamed')),
    old_hash  TEXT,
    new_hash  TEXT NOT NULL,
    from_name TEXT,
    agent     TEXT NOT NULL,
    at        INTEGER NOT NULL
);
CREATE INDEX history_by_name ON history(name);
";

/// Per-connection settings: wait for other writers, enforce references.
pub fn configure(conn: &Connection) -> rusqlite::Result<()> {
    conn.busy_timeout(BUSY_TIMEOUT)?;
    conn.pragma_update(None, "foreign_keys", true)?;
    Ok(())
}

/// Creates the tables in an empty database (one transaction) and switches it to WAL mode, so
/// readers (`view`, `query`, `run`) are not blocked by a running `define`.
pub fn create(conn: &mut Connection) -> rusqlite::Result<()> {
    conn.pragma_update(None, "journal_mode", "WAL")?;
    let tx = conn.transaction_with_behavior(rusqlite::TransactionBehavior::Immediate)?;
    let version: i64 = tx.query_row("PRAGMA user_version", [], |r| r.get(0))?;
    if version == 0 {
        tx.execute_batch(SCHEMA)?;
        tx.pragma_update(None, "user_version", SCHEMA_VERSION)?;
    }
```

```rust
//! A consistent, verified view of the store's contents (read inside one transaction), and decoding
//! of stored definitions back into source ASTs with the current names.

use crate::sql;
use qal_core::ast::{Def, Program};
use qal_core::canon::{self, Hash, Kind};
use qal_core::diag::Diagnostic;
use rusqlite::{params, Connection, OptionalExtension};
use std::cell::RefCell;
use std::rc::Rc;
use std::collections::{BTreeMap, HashMap};

/// One row of `defs`, verified: `sha256(canonical) == hash`, and the canonical form decodes.
#[derive(Debug, Clone)]
pub struct Row {
    pub kind: Kind,
    pub canonical: Vec<u8>,
    /// The group form, for a member of a group (shared by all members).
    pub group: Option<Rc<Vec<u8>>>,
    pub local_names: Vec<String>,
}

impl Row {
    pub fn form(&self) -> canon::Form<'_> {
        canon::Form::new(&self.canonical, self.group.as_ref().map(|g| g.as_slice()))
    }
}

pub struct Snapshot {
    /// name -> (hash, local names of that name's text)
    pub names: BTreeMap<String, (Hash, Vec<String>)>,
    /// hash -> its names, sorted (the first one is the primary name used in texts)
    pub by_hash: HashMap<Hash, Vec<String>>,
    rows: RefCell<HashMap<Hash, Row>>,
    groups: RefCell<HashMap<Hash, Rc<Vec<u8>>>>,
}

fn corrupt(what: impl std::fmt::Display) -> Vec<Diagnostic> {
    vec![Diagnostic::store_error(format!("the store is corrupt: {what}"))]
}

fn json_list(s: &str, what: &str) -> Result<Vec<String>, Vec<Diagnostic>> {
    serde_json::from_str(s).map_err(|e| corrupt(format!("{what} is not a JSON list of strings ({e})")))
}

fn parse_hash(s: &str) -> Result<Hash, Vec<Diagnostic>> {
    Hash::from_hex(s).ok_or_else(|| corrupt(format!("`{s}` is not a hash")))
}

impl Snapshot {
    /// Reads all names and the definitions they point to.
    pub fn load(conn: &Connection) -> Result<Snapshot, Vec<Diagnostic>> {
        let mut names = BTreeMap::new();
        let mut by_hash: HashMap<Hash, Vec<String>> = HashMap::new();
        let mut stmt = conn.prepare("SELECT name, hash, local_names FROM names ORDER BY name").map_err(sql)?;
        let rows = stmt.query_map([], |r| Ok((r.get::<_, String>(0)?, r.get::<_, String>(1)?, r.get::<_, String>(2)?))).map_err(sql)?;
        for row in rows {
            let (name, hash, locals) = row.map_err(sql)?;
            let hash = parse_hash(&hash)?;
            by_hash.entry(hash).or_default().push(name.clone());
            names.insert(name, (hash, json_list(&locals, "names.local_names")?));
        }
        let snap = Snapshot { names, by_hash, rows: RefCell::new(HashMap::new()), groups: RefCell::new(HashMap::new()) };
        let hashes: Vec<Hash> = snap.by_hash.keys().copied().collect();
        for h in hashes {
            snap.row(conn, &h)?.ok_or_else(|| corrupt(format!("name(s) {} point to the missing definition #{h}", snap.by_hash[&h].join(", "))))?;
        }
        Ok(snap)
    }

    /// The same contents with `old` named `new` (for checking a rename before writing it).
    pub fn renamed(&self, old: &str, new: &str) -> Snapshot {
        let mut names = self.names.clone();
        if let Some(entry) = names.remove(old) {
            names.insert(new.to_string(), entry);
        }
        let mut by_hash: HashMap<Hash, Vec<String>> = HashMap::new();
        for (n, (h, _)) in &names {
            by_hash.entry(*h).or_default().push(n.clone());
        }
        Snapshot { names, by_hash, rows: RefCell::new(self.rows.borrow().clone()), groups: RefCell::new(self.groups.borrow().clone()) }
    }

    /// The verified definition with hash `h` (cached), or None if the store has none.
    pub fn row(&self, conn: &Connection, h: &Hash) -> Result<Option<Row>, Vec<Diagnostic>> {
        if let Some(r) = self.rows.borrow().get(h) {
            return Ok(Some(r.clone()));
        }
        let found = conn
            .query_row("SELECT kind, canonical, local_names FROM defs WHERE hash = ?1", params![h.to_hex()], |r| {
                Ok((r.get::<_, String>(0)?, r.get::<_, Vec<u8>>(1)?, r.get::<_, String>(2)?))
            })
            .optional()
            .map_err(sql)?;
        let Some((kind, canonical, locals)) = found else { return Ok(None) };
        if Hash::of(&canonical) != *h {
            return Err(corrupt(format!("definition #{h} does not match its hash")));
        }
        let kind = Kind::parse(&kind).ok_or_else(|| corrupt(format!("definition #{h} has the unknown kind `{kind}`")))?;
        let local_names = json_list(&locals, "defs.local_names")?;
        let header = canon::header(&canonical).map_err(|e| corrupt(format!("definition #{h}: {e}")))?;
        let group = match header.group {
            None => None,
            Some(g) => Some(self.group(conn, h, &g)?),
        };
        let binders = canon::count_binders(canon::Form::new(&canonical, group.as_ref().map(|g| g.as_slice()))).map_err(|e| corrupt(format!("definition #{h}: {e}")))?;
        if binders != local_names.len() {
            return Err(corrupt(format!("definition #{h} has {binders} locals but {} local names", local_names.len())));
        }
        let row = Row { kind, canonical, group, local_names };
        self.rows.borrow_mut().insert(*h, row.clone());
        Ok(Some(row))
    }

    /// The name texts use for `h`: the first of its names, if it has any.
    pub fn primary(&self, h: &Hash) -> Option<&str> {
        self.by_hash.get(h).and_then(|ns| ns.first()).map(|s| s.as_str())
    }

    /// Decodes the definition stored under `name`. References are named through `overrides` first,
    /// then by their primary name; a reference without a name is a `missing_dep` diagnostic.
    pub fn decode_name(&self, conn: &Connection, name: &str, overrides: &HashMap<Hash, String>) -> Result<Def, Vec<Diagnostic>> {
        let (hash, locals) = self.names.get(name).ok_or_else(|| vec![Diagnostic::unknown_name(name, "", name)])?;
        let row = self.row(conn, hash)?.ok_or_else(|| corrupt(format!("`{name}` points to the missing definition #{hash}")))?;
        let locals = if locals.len() == row.local_names.len() { locals.clone() } else { row.local_names.clone() };
        let mut missing = None;
        let def = canon::decode(row.form(), name, &locals, &mut |h| match overrides.get(h).map(|s| s.as_str()).or_else(|| self.primary(h)) {
            Some(n) => n.to_string(),
            None => {
                missing.get_or_insert(*h);
                format!("#{}", h.short())
            }
        })
        .map_err(|e| corrupt(format!("`{name}` (#{hash}): {e}")))?;
        if Kind::of(&def) != row.kind {
            return Err(corrupt(format!("definition #{hash} is stored as a {} but encodes a {}", row.kind.as_str(), Kind::of(&def).as_str())));
        }
        if let Some(h) = missing {
            return Err(vec![Diagnostic::missing_dep(name, &h.to_hex())]);
        }
        Ok(def)
    }

    /// The group form with hash `g` (cached; verified by the decoder against `g`).
    fn group(&self, conn: &Connection, member: &Hash, g: &Hash) -> Result<Rc<Vec<u8>>, Vec<Diagnostic>> {
        if let Some(f) = self.groups.borrow().get(g) {
            return Ok(f.clone());
        }
        let form = conn
            .query_row("SELECT form FROM groups WHERE hash = ?1", params![g.to_hex()], |r| r.get::<_, Vec<u8>>(0))
            .optional()
            .map_err(sql)?
            .ok_or_else(|| corrupt(format!("definition #{member} belongs to the missing group #{g}")))?;
        let form = Rc::new(form);
        self.groups.borrow_mut().insert(*g, form.clone());
        Ok(form)
    }

    /// The name a hash is shown with: its primary name, else the last name it had (history), else
    /// `#<hash prefix>`.
    fn display_name(&self, conn: &Connection, h: &Hash) -> Result<String, Vec<Diagnostic>> {
        if let Some(n) = self.primary(h) {
            return Ok(n.to_string());
        }
        let last: Option<String> = conn
            .query_row("SELECT name FROM history WHERE new_hash = ?1 ORDER BY id DESC LIMIT 1", params![h.to_hex()], |r| r.get(0))
            .optional()
            .map_err(sql)?;
        Ok(last.unwrap_or_else(|| format!("#{}", h.short())))
    }

    /// Decodes any stored definition by hash for display (old versions included): definitions
    /// without a current name are shown with the name they last had.
    pub fn decode_hash(&self, conn: &Connection, h: &Hash) -> Result<Option<Def>, Vec<Diagnostic>> {
        let Some(row) = self.row(conn, h)? else { return Ok(None) };
        let own = self.display_name(conn, h)?;
        let mut names: HashMap<Hash, String> = HashMap::new();
        for r in canon::references_of(row.form()).map_err(|e| corrupt(format!("#{h}: {e}")))? {
            names.insert(r, self.display_name(conn, &r)?);
        }
        let def = canon::decode(row.form(), &own, &row.local_names, &mut |r| names.get(r).cloned().unwrap_or_else(|| format!("#{}", r.short())))
            .map_err(|e| corrupt(format!("#{h}: {e}")))?;
        Ok(Some(def))
    }

    /// The whole named codebase as a program, except the names in `skip`: types, then functions,
    /// then tests, each sorted by name.
    pub fn program(&self, conn: &Connection, overrides: &HashMap<Hash, String>, skip: &dyn Fn(&str) -> bool) -> Result<Program, Vec<Diagnostic>> {
        let mut defs = Vec::new();
        let mut diags = Vec::new();
        for name in self.names.keys() {
            if skip(name) {
                continue;
            }
            match self.decode_name(conn, name, overrides) {
                Ok(d) => defs.push(d),
                Err(d) => diags.extend(d),
            }
        }
        if !diags.is_empty() {
            return Err(diags);
        }
        defs.sort_by_key(|d| match d {
            Def::Type(_) => 0,
            Def::Fn(_) => 1,
            Def::Test(_) => 2,
        });
        Ok(Program { defs })
    }

    /// Names of the stored definitions that refer to `h` directly.
    pub fn dependents(&self, conn: &Connection, h: &Hash) -> Result<Vec<String>, Vec<Diagnostic>> {
        let mut stmt = conn
            .prepare("SELECT DISTINCT n.name FROM deps d JOIN names n ON n.hash = d.hash WHERE d.dep_hash = ?1 ORDER BY n.name")
            .map_err(sql)?;
        let rows = stmt.query_map(params![h.to_hex()], |r| r.get::<_, String>(0)).map_err(sql)?;
        rows.collect::<Result<Vec<_>, _>>().map_err(sql)
    }
}
```

```rust
//! `define`: parse, assemble with the stored codebase, enforce the replacement rule, check, hash,
//! and write everything in one transaction (spec §6).

use crate::snapshot::Snapshot;
use crate::{now_ms, sql, Defined};
use qal_core::ast::{Def, Program};
use qal_core::canon::{self, Canon, Hash, HashError, Hashed, Kind};
use qal_core::diag::Diagnostic;
use rusqlite::{params, Connection, Transaction, TransactionBehavior};
use std::collections::{BTreeMap, HashMap, HashSet};

/// A definition's signature as the replacement rule compares it: kind plus the signature text
/// with current names (so a replaced type keeps its name in the signatures that use it).
fn signature(d: &Def) -> (Kind, String) {
    (Kind::of(d), canon::signature_text(d, &|n| n.to_string()))
}

fn show(sig: &(Kind, String)) -> String {
    match sig.0 {
        Kind::Fn => sig.1.clone(),
        Kind::Type => format!("type = {}", sig.1),
        Kind::Test => "test".to_string(),
    }
}

/// Hashes a checked program; interchangeable recursive definitions are a diagnostic.
pub(crate) fn hash(p: &Program) -> Result<Hashed, Vec<Diagnostic>> {
    canon::hash_program(p).map_err(|e| match e {
        HashError::Symmetric(names) => vec![Diagnostic::symmetric_group(&names)],
        HashError::TooLarge(names) => vec![Diagnostic::group_too_large(&names)],
        HashError::Internal(m) => vec![Diagnostic::store_error(format!("cannot hash a checked program: {m}"))],
    })
}

pub fn define(conn: &mut Connection, src: &str, agent: &str) -> Result<Vec<Defined>, Vec<Diagnostic>> {
    let input = qal_text::parse_program(src).map_err(|d| vec![d])?;
    // IMMEDIATE takes the write lock before reading, so two concurrent `define`s serialize instead of
    // both deciding on the same old state.
    let tx = conn.transaction_with_behavior(TransactionBehavior::Immediate).map_err(sql)?;
    let snap = Snapshot::load(&tx)?;

    let input_names: HashSet<&str> = input.defs.iter().map(|d| d.name()).collect();
    // Hashes with several names, all redefined, where one name is restated unchanged: that name
    // keeps the hash (and its users). Found by a trial hash of the assembled program.
    let mut keep: HashMap<Hash, String> = HashMap::new();
    let (mut overrides, mut replaced) = plan_overrides(&snap, &input_names, &keep);
    let shared: Vec<Hash> = replaced.iter().filter(|h| snap.by_hash.get(h).is_some_and(|ns| ns.len() > 1)).copied().collect();
    if !shared.is_empty() {
        let mut trial = snap.program(&tx, &overrides, &|n| input_names.contains(n))?;
        trial.defs.extend(input.defs.iter().cloned());
        if let Ok(t) = canon::hash_program(&trial) {
            let new_of: HashMap<&str, Hash> = t.defs.iter().map(|c| (c.name.as_str(), c.hash)).collect();
            let mut diags = Vec::new();
            for h in &shared {
                let names = &snap.by_hash[h];
                if let Some(same) = names.iter().find(|n| new_of.get(n.as_str()) == Some(h)) {
                    keep.insert(*h, same.clone());
                    continue;
                }
                let news: HashSet<Hash> = names.iter().filter_map(|n| new_of.get(n.as_str()).copied()).collect();
                let users: Vec<String> = snap.dependents(&tx, h)?.into_iter().filter(|n| !input_names.contains(n.as_str())).collect();
                if news.len() > 1 && !users.is_empty() {
                    let mut d = Diagnostic::new(
                        "E0403",
                        "ambiguous_replacement",
                        &names[0],
                        "",
                        format!("{} were the same definition and now differ; its stored users cannot follow both", names.iter().map(|n| format!("`{n}`")).collect::<Vec<_>>().join(", ")),
                    )
                    .hint(format!("redefine {} in the same call, or keep one of the names unchanged", users.join(", ")));
                    d.dependents = users;
                    diags.push(d);
                }
            }
            if !diags.is_empty() {
                return Err(diags);
            }
        }
        (overrides, replaced) = plan_overrides(&snap, &input_names, &keep);
    }

    replacement_rule(&tx, &snap, &input, &input_names, &overrides, &replaced)?;

    let stored = snap.program(&tx, &overrides, &|n| input_names.contains(n))?;
    let mut combined = stored;
    combined.defs.extend(input.defs.iter().cloned());
    qal_check::check(&combined)?;

    let hashed = hash(&combined)?;
    identical_types(&hashed.defs)?;
    group_aliases(&hashed.defs)?;
    canonical_check(&tx, &snap, &input_names, &replaced, &hashed.defs)?;

    let out = write(&tx, &snap, &input, &hashed, agent)?;
    tx.commit().map_err(sql)?;
    Ok(out)
}

/// Which stored hashes the input replaces, and the names their users are decoded with. A hash is
/// replaced only if all its names are redefined (and none is kept unchanged, `keep`); otherwise its
/// users keep a name that still has it.
fn plan_overrides(snap: &Snapshot, input_names: &HashSet<&str>, keep: &HashMap<Hash, String>) -> (HashMap<Hash, String>, HashSet<Hash>) {
    let mut overrides = HashMap::new();
    let mut replaced = HashSet::new();
    for (h, names) in &snap.by_hash {
        let (redefined, kept): (Vec<&String>, Vec<&String>) = names.iter().partition(|n| input_names.contains(n.as_str()));
        let Some(first) = redefined.first() else { continue };
        if let Some(k) = keep.get(h).or(kept.first().copied()) {
            overrides.insert(*h, k.clone());
        } else {
            overrides.insert(*h, (*first).clone());
            replaced.insert(*h);
        }
    }
    (overrides, replaced)
}

/// A member of a recursive group can have only one name: a second name would decode its sibling
/// references through another name and leave the group.
fn group_aliases(canons: &[Canon]) -> Result<(), Vec<Diagnostic>> {
    let mut by_hash: BTreeMap<Hash, Vec<&str>> = BTreeMap::new();
    for c in canons.iter().filter(|c| c.group.is_some()) {
        by_hash.entry(c.hash).or_default().push(&c.name);
    }
    let mut diags = Vec::new();
    for names in by_hash.values_mut().filter(|ns| ns.len() > 1) {
        names.sort_unstable();
        for dup in &names[1..] {
            diags.push(
                Diagnostic::new("E0202", "duplicate_name", dup, "", format!("`{dup}` is identical to the recursive definition `{}`", names[0]))
                    .hint(format!("a member of a mutually recursive group has one name: use `{}`, or rename it", names[0])),
            );
        }
    }
    if diags.is_empty() {
        Ok(())
    } else {
        Err(diags)
    }
}

/// A stored definition may only get a new hash if it (transitively) uses a replaced one; anything
/// else means its stored bytes were not in canonical form.
fn canonical_check(tx: &Transaction, snap: &Snapshot, input_names: &HashSet<&str>, replaced: &HashSet<Hash>, canons: &[Canon]) -> Result<(), Vec<Diagnostic>> {
    let mut affected = replaced.clone();
    let mut refs: HashMap<Hash, Vec<Hash>> = HashMap::new();
    for (name, (h, _)) in &snap.names {
        if !input_names.contains(name.as_str()) && !refs.contains_key(h) {
            let row = snap.row(tx, h)?.ok_or_else(|| vec![Diagnostic::store_error(format!("the store is corrupt: definition #{h} is missing"))])?;
            refs.insert(*h, canon::references_of(row.form()).map_err(|e| vec![Diagnostic::store_error(e)])?);
        }
    }
    loop {
        let before = affected.len();
        for (h, rs) in &refs {
            if !affected.contains(h) && rs.iter().any(|r| affected.contains(r)) {
                affected.insert(*h);
            }
        }
        if affected.len() == before {
            break;
        }
    }
    for c in canons {
        if input_names.contains(c.name.as_str()) {
            continue;
        }
        if let Some((old, _)) = snap.names.get(&c.name) {
            if *old != c.hash && !affected.contains(old) {
                return Err(vec![Diagnostic::store_error(format!(
                    "the store is corrupt: the stored definition `{}` (#{old}) is not in canonical form",
                    c.name
                ))]);
            }
        }
    }
    Ok(())
}

/// Replacing a definition with a different signature fails unless the call also redefines every
/// stored definition that refers to it.
fn replacement_rule(
    tx: &Transaction,
    snap: &Snapshot,
    input: &Program,
    input_names: &HashSet<&str>,
    overrides: &HashMap<Hash, String>,
    replaced: &HashSet<Hash>,
) -> Result<(), Vec<Diagnostic>> {
    let mut diags = Vec::new();
    let mut seen = HashSet::new();
    for d in &input.defs {
        let Some((old_hash, _)) = snap.names.get(d.name()) else { continue };
        // A hash that keeps another name is not replaced: nothing refers to the new version yet.
        if !replaced.contains(old_hash) || !seen.insert(d.name()) {
            continue;
        }
        let old = snap.decode_name(tx, d.name(), overrides)?;
        let (before, after) = (signature(&old), signature(d));
        if before == after {
            continue;
        }
        let dependents: Vec<String> = snap.dependents(tx, old_hash)?.into_iter().filter(|n| !input_names.contains(n.as_str())).collect();
        if !dependents.is_empty() {
            diags.push(Diagnostic::signature_change(d.name(), &show(&before), &show(&after), &dependents));
        }
    }
    if diags.is_empty() {
        Ok(())
    } else {
        Err(diags)
    }
}

/// Types are identified by their structure: a second name for the same type would need type
/// aliases, which Phase 1 does not have.
fn identical_types(canons: &[Canon]) -> Result<(), Vec<Diagnostic>> {
    let mut by_hash: BTreeMap<Hash, Vec<&str>> = BTreeMap::new();
    for c in canons.iter().filter(|c| c.kind == Kind::Type) {
        by_hash.entry(c.hash).or_default().push(&c.name);
    }
    let mut diags = Vec::new();
    for names in by_hash.values_mut().filter(|ns| ns.len() > 1) {
        names.sort_unstable();
        for dup in &names[1..] {
            diags.push(
                Diagnostic::new("E0202", "duplicate_name", dup, "", format!("type `{dup}` is identical to type `{}`", names[0]))
                    .hint(format!("types with the same fields or variants are the same type: use `{}`, or rename it with `qal rename {} {dup}`", names[0], names[0])),
            );
        }
    }
    if diags.is_empty() {
        Ok(())
    } else {
        Err(diags)
    }
}

fn json(list: &[String]) -> String {
    serde_json::Value::from(list.to_vec()).to_string()
}

/// Writes new definitions, dependencies, names and history; returns the per-name results:
/// the input definitions in input order, then relinked dependents by name.
fn write(tx: &Transaction, snap: &Snapshot, input: &Program, hashed: &Hashed, agent: &str) -> Result<Vec<Defined>, Vec<Diagnostic>> {
    let now = now_ms();
    let canons = &hashed.defs;
    for (h, form) in &hashed.groups {
        tx.execute("INSERT OR IGNORE INTO groups (hash, form) VALUES (?1, ?2)", params![h.to_hex(), form]).map_err(sql)?;
    }
    let input_names: HashSet<&str> = input.defs.iter().map(|d| d.name()).collect();
    for c in canons {
        tx.execute(
            "INSERT OR IGNORE INTO defs (hash, kind, canonical, signature, effects, local_names, created_at) VALUES (?1, ?2, ?3, ?4, ?5, ?6, ?7)",
            params![c.hash.to_hex(), c.kind.as_str(), c.canonical, c.signature, json(&c.effects), json(&c.local_names), now],
        )
        .map_err(sql)?;
    }
    for c in canons {
        for d in &c.deps {
            tx.execute("INSERT OR IGNORE INTO deps (hash, dep_hash) VALUES (?1, ?2)", params![c.hash.to_hex(), d.to_hex()]).map_err(sql)?;
        }
    }
    let mut results: HashMap<&str, Defined> = HashMap::new();
    for c in canons {
        let old = snap.names.get(&c.name);
        let is_input = input_names.contains(c.name.as_str());
        let status = match old {
            None => "added",
            Some((h, _)) if *h == c.hash => "unchanged",
            Some(_) if is_input => "replaced",
            Some(_) => "relinked",
        };
        if status == "unchanged" && !is_input {
            continue;
        }
        if status != "unchanged" || old.is_some_and(|(_, l)| *l != c.local_names) {
            tx.execute(
                "INSERT INTO names (name, hash, local_names, updated_at) VALUES (?1, ?2, ?3, ?4) \
                 ON CONFLICT(name) DO UPDATE SET hash = excluded.hash, local_names = excluded.local_names, updated_at = excluded.updated_at",
                params![c.name, c.hash.to_hex(), json(&c.local_names), now],
            )
            .map_err(sql)?;
        }
        let old_hash = old.map(|(h, _)| h.to_hex());
        if status != "unchanged" {
            tx.execute(
                "INSERT INTO history (name, action, old_hash, new_hash, agent, at) VALUES (?1, ?2, ?3, ?4, ?5, ?6)",
                params![c.name, status, old_hash, c.hash.to_hex(), agent, now],
            )
            .map_err(sql)?;
        }
        results.insert(&c.name, Defined { name: c.name.clone(), kind: c.kind.as_str(), hash: c.hash.to_hex(), status, old_hash: if matches!(status, "replaced" | "relinked") { old_hash } else { None } });
    }
    let mut out = Vec::new();
    for d in &input.defs {
```

```rust
fn missing_row(h: &Hash) -> Vec<Diagnostic> {
    vec![Diagnostic::store_error(format!("the store is corrupt: definition #{h} is missing"))]

/// A name or `#<64 hex digits>` -> the hash it stands for.
fn resolve(snap: &Snapshot, conn: &Connection, s: &str) -> Result<Hash, Vec<Diagnostic>> {
    if let Some(hex) = s.strip_prefix('#') {
        if let Some(h) = Hash::from_hex(hex) {
            if snap.row(conn, &h)?.is_some() {
                return Ok(h);
            }
        }
        return Err(vec![Diagnostic::unknown_name("", "", s).hint("give a stored name or `#` followed by a full 64-digit hash")]);
    }
    snap.names.get(s).map(|(h, _)| *h).ok_or_else(|| vec![Diagnostic::unknown_name(s, "", s)])
}

/// Names follow the text form's rules: types start uppercase, functions and tests lowercase.
fn valid_name(name: &str, kind: Kind) -> Result<(), Vec<Diagnostic>> {
    let what = match kind {
        Kind::Type => "type",
        Kind::Fn => "function",
        Kind::Test => "test",
    };
    let chars_ok = name.chars().all(|c| c.is_ascii_alphanumeric() || c == '_') && !name.starts_with(|c: char| c.is_ascii_digit()) && name != "_";
    let case_ok = !name.is_empty() && name.starts_with(|c: char| c.is_ascii_uppercase()) == (kind == Kind::Type);
    if chars_ok && case_ok && !KEYWORDS.contains(&name) {
        return Ok(());
    }
    let rule = if kind == Kind::Type { "start with an uppercase letter" } else { "start with a lowercase letter or `_`" };
    Err(vec![Diagnostic::new("E0100", "parse", name, "", format!("`{name}` is not a valid {what} name"))
        .hint(format!("{what} names {rule} and contain only ASCII letters, digits and `_` (no keywords)"))])
}

pub fn rename(conn: &mut Connection, old: &str, new: &str, agent: &str) -> Result<Renamed, Vec<Diagnostic>> {
    let tx = conn.transaction_with_behavior(TransactionBehavior::Immediate).map_err(sql)?;
    let snap = Snapshot::load(&tx)?;
    let Some((hash, _)) = snap.names.get(old).cloned() else {
        return Err(vec![Diagnostic::unknown_name(old, "", old)]);
    };
    let kind = snap.row(&tx, &hash)?.map(|r| r.kind).ok_or_else(|| vec![Diagnostic::store_error(format!("`{old}` has no definition"))])?;
    if snap.names.contains_key(new) {
        return Err(vec![Diagnostic::duplicate_name(new, "", new).hint(format!("`{new}` is already taken; rename or replace it first"))]);
    }
    valid_name(new, kind)?;
    // The renamed codebase must still check (built-in and reserved names, `main`'s signature) and
    // hash exactly as before.
    let renamed = snap.renamed(old, new);
    let program = renamed.program(&tx, &HashMap::new(), &|_| false)?;
    qal_check::check(&program)?;
    let canons = crate::define::hash(&program)?.defs;
    for c in &canons {
        if renamed.names.get(&c.name).map(|(h, _)| *h) != Some(c.hash) {
            return Err(vec![Diagnostic::store_error(format!("renaming would change the hash of `{}`; nothing was changed", c.name))]);
        }
    }
    let now = now_ms();
    tx.execute("UPDATE names SET name = ?1, updated_at = ?2 WHERE name = ?3", params![new, now, old]).map_err(sql)?;
    tx.execute("UPDATE history SET name = ?1 WHERE name = ?2", params![new, old]).map_err(sql)?;
    tx.execute(
        "INSERT INTO history (name, action, old_hash, new_hash, from_name, agent, at) VALUES (?1, 'renamed', ?2, ?2, ?3, ?4, ?5)",
        params![new, hash.to_hex(), old, agent, now],
    )
    .map_err(sql)?;
    tx.commit().map_err(sql)?;
    Ok(Renamed { name: new.to_string(), kind: kind.as_str(), hash: hash.to_hex() })
}

pub fn view(conn: &mut Connection, names: &[String]) -> Result<Vec<View>, Vec<Diagnostic>> {
    let tx = conn.transaction().map_err(sql)?;
    let snap = Snapshot::load(&tx)?;
    let mut out = Vec::new();
    let mut diags = Vec::new();
    for n in names {
        let hash = match resolve(&snap, &tx, n) {
            Ok(h) => h,
            Err(d) => {
                diags.extend(d);
                continue;
            }
        };
        let def = if n.starts_with('#') { snap.decode_hash(&tx, &hash)?.ok_or_else(|| missing_row(&hash))? } else { snap.decode_name(&tx, n, &HashMap::new())? };
        let row = snap.row(&tx, &hash)?.ok_or_else(|| missing_row(&hash))?;
        let mut deps = Vec::new();
        for d in canon::references_of(row.form()).map_err(|e| vec![Diagnostic::store_error(e)])? {
            let dep = snap.decode_hash(&tx, &d)?.ok_or_else(|| vec![Diagnostic::missing_dep(def.name(), &d.to_hex())])?;
            deps.push(DepView { name: dep.name().to_string(), kind: Kind::of(&dep).as_str(), hash: d.to_hex(), signature: signature(&dep) });
        }
        deps.sort_by(|a, b| a.name.cmp(&b.name));
        out.push(View {
            name: def.name().to_string(),
            kind: Kind::of(&def).as_str(),
            hash: hash.to_hex(),
            signature: signature(&def),
            effects: effects(&def),
            text: text(&def),
            deps,
        });
    }
    if diags.is_empty() {
        Ok(out)
    } else {
        Err(diags)
    }
}

pub fn query(conn: &mut Connection, q: &Query) -> Result<Vec<Entry>, Vec<Diagnostic>> {
    let tx = conn.transaction().map_err(sql)?;
    let snap = Snapshot::load(&tx)?;
    let uses = q.uses.as_deref().map(|u| resolve(&snap, &tx, u)).transpose()?;
    let mut out = Vec::new();
    for (name, (hash, _)) in &snap.names {
        if q.name.as_deref().is_some_and(|p| !name.starts_with(p)) {
            continue;
        }
        if let Some(target) = &uses {
            let row = snap.row(&tx, hash)?.ok_or_else(|| missing_row(hash))?;
            if !canon::references_of(row.form()).map_err(|e| vec![Diagnostic::store_error(e)])?.contains(target) {
                continue;
            }
        }
        let def = snap.decode_name(&tx, name, &HashMap::new())?;
        let sig = signature(&def);
        if q.type_pattern.as_deref().is_some_and(|p| !pattern::matches(p, &sig)) {
            continue;
        }
        out.push(Entry { name: name.clone(), kind: Kind::of(&def).as_str(), hash: hash.to_hex(), signature: sig, effects: effects(&def) });
    }
    Ok(out)
}

pub fn history(conn: &mut Connection, name: &str) -> Result<Vec<HistoryEntry>, Vec<Diagnostic>> {
    let tx = conn.transaction().map_err(sql)?;
    let mut stmt = tx.prepare("SELECT action, name, from_name, old_hash, new_hash, agent, at FROM history WHERE name = ?1 ORDER BY id").map_err(sql)?;
    let rows = stmt
        .query_map(params![name], |r| {
            Ok(HistoryEntry { action: r.get(0)?, name: r.get(1)?, from_name: r.get(2)?, old_hash: r.get(3)?, new_hash: r.get(4)?, agent: r.get(5)?, at: r.get(6)? })
        })
        .map_err(sql)?;
    let out = rows.collect::<Result<Vec<_>, _>>().map_err(sql)?;
    if out.is_empty() {
        return Err(vec![Diagnostic::unknown_name(name, "", name)]);
    }
    Ok(out)
}
```

```rust
//! Signature patterns for `query --type`: the signature text with `_` standing for any one type.
//!
//! Spaces do not matter. `_` matches a non-empty, bracket-balanced run of tokens without a
//! top-level `,` or `|`, e.g. `fn(_, Int) -> _` matches `fn(List[Str], Int) -> Option[Int] !io`.

/// Longest pattern accepted, in tokens; longer patterns match nothing.
const MAX_PATTERN_TOKENS: usize = 256;

fn tokens(s: &str) -> Vec<String> {
    let chars: Vec<char> = s.chars().collect();
    let mut out = Vec::new();
    let mut i = 0;
    while i < chars.len() {
        let c = chars[i];
        if c.is_whitespace() {
            i += 1;
        } else if c.is_alphanumeric() || c == '_' || c == '#' {
            let start = i;
            while i < chars.len() && (chars[i].is_alphanumeric() || chars[i] == '_' || chars[i] == '#') {
                i += 1;
            }
            out.push(chars[start..i].iter().collect());
        } else if c == '-' && chars.get(i + 1) == Some(&'>') {
            out.push("->".into());
            i += 2;
        } else {
            out.push(c.to_string());
            i += 1;
        }
    }
    out
}

/// True if `signature` matches `pattern`.
pub fn matches(pattern: &str, signature: &str) -> bool {
    let p = tokens(pattern);
    if p.is_empty() || p.len() > MAX_PATTERN_TOKENS {
        return false;
    }
    let s = tokens(signature);
    let mut memo = std::collections::HashMap::new();
    go(&p, &s, 0, 0, &mut memo)
}

fn go(p: &[String], s: &[String], mut pi: usize, mut si: usize, memo: &mut std::collections::HashMap<(usize, usize), bool>) -> bool {
    // Plain tokens are compared in a loop; only `_` recurses (at most MAX_PATTERN_TOKENS deep).
    while pi < p.len() && p[pi] != "_" {
        if si >= s.len() || p[pi] != s[si] {
            return false;
        }
        pi += 1;
        si += 1;
    }
    if pi == p.len() {
        return si == s.len();
    }
    if let Some(&r) = memo.get(&(pi, si)) {
        return r;
    }
    let mut depth = 0usize;
    let mut result = false;
    for e in si..s.len() {
        match s[e].as_str() {
            "(" | "[" | "{" => depth += 1,
            ")" | "]" | "}" => {
                if depth == 0 {
                    break;
                }
                depth -= 1;
            }
            "," | "|" if depth == 0 => break,
            _ => {}
        }
        if depth == 0 && go(p, s, pi + 1, e + 1, memo) {
            result = true;
            break;
        }
    }
    memo.insert((pi, si), result);
    result
}
```

```rust
/// Splits `--flag value` options (only those in `flags`, anywhere in `args`) from positional
/// arguments. Unknown `--options` are an error.
pub fn take_flags(args: &[String], flags: &[&str]) -> Result<(HashMap<String, String>, Vec<String>), String> {
    let mut found = HashMap::new();
    let mut rest = Vec::new();
    let mut i = 0;
    while i < args.len() {
        let a = &args[i];
        if let Some(flag) = a.strip_prefix("--") {
            if !flags.contains(&flag) {
                return Err(format!("unknown option `{a}`"));
            }
            let value = args.get(i + 1).ok_or_else(|| format!("`{a}` needs a value"))?;
            if found.insert(flag.to_string(), value.clone()).is_some() {
                return Err(format!("`{a}` given twice"));
            }
            i += 2;
        } else {
            rest.push(a.clone());
            i += 1;
        }
    }
    Ok((found, rest))
}
```

```rust
//! Files (`<file>` ends in `.qal`):
//!   qal check <file>                                 -> {"ok":true} | {"diagnostics":[...]}
//!   qal fmt <file>                                   -> canonical text
//! The project's store (`.qal/store.db` in the current directory or a parent):
//!   qal init                                         -> {"ok":true,"store":"<path>"}
//!   qal define <file> [--agent <name>]               -> {"defined":[{name,kind,hash,status,old_hash?}]} | {"diagnostics":[...]}
//!   qal view <name|#hash>...                         -> {"views":[{name,kind,hash,signature,effects,text,deps}]}
//!   qal query [--name <prefix>] [--type <pattern>] [--uses <name|#hash>]

/// Diagnostics; exit 2 if the store itself failed (missing, unreadable, corrupt), else 1.
fn diagnostics(d: &[Diagnostic]) -> ExitCode {

fn main() -> ExitCode {
    // Arguments that are not valid UTF-8 are converted lossily instead of panicking.
    let args: Vec<String> = std::env::args_os().skip(1).map(|a| a.to_string_lossy().into_owned()).collect();
    let Some(cmd) = args.first() else {
        return usage();
    };
    match cmd.as_str() {
        "check" | "fmt" => file_command(cmd, &args[1..]),
        "init" | "define" | "view" | "query" | "rename" | "history" => store_command(cmd, &args[1..]),
        "call" | "test" | "run" => run_command(cmd, &args[1..]),
        _ => usage(),
    }
}

fn read(file: &str) -> Result<String, ExitCode> {
    std::fs::read_to_string(file).map_err(|e| bad_usage(&format!("cannot read {file}: {e}")))
}

fn file_command(cmd: &str, args: &[String]) -> ExitCode {
    let [file] = args else {
        return usage();
    };
    let src = match read(file) {
        Ok(s) => s,
        Err(code) => return code,
    };
    if cmd == "fmt" {
        return match qal_text::parse_program(&src) {
            Ok(p) => {
                print!("{}", qal_text::print_program(&p));
                ExitCode::SUCCESS
            }
            Err(d) => diagnostics(&[d]),
        };
    }
    match load(&src) {
        Ok(_) => emit(Out { ok: Some(&Value::Bool(true)), ..Out::default() }, 0),
        Err(d) => diagnostics(&d),
    }
}

fn store_command(cmd: &str, args: &[String]) -> ExitCode {
    let flags: &[&str] = match cmd {
        "define" | "rename" => &["agent"],
        "query" => &["name", "type", "uses"],
        _ => &[],
    };
    let (flags, rest) = match take_flags(args, flags) {
        Ok(x) => x,
        Err(e) => return bad_usage(&e),
    };
    let agent = flags.get("agent").map(String::as_str).unwrap_or("cli");
    if cmd == "init" {
        if !rest.is_empty() {
            return usage();
        }
        let cwd = match std::env::current_dir() {
            Ok(d) => d,
            Err(e) => return bad_usage(&format!("no current directory: {e}")),
        };
        return match Store::init(&cwd) {
            Ok(s) => emit(Out { ok: Some(&Value::Bool(true)), store: Some(&s.path().display().to_string()), ..Out::default() }, 0),
            Err(d) => diagnostics(&d),
        };
    }
    // Validate the arguments before touching the store.
    let src = match (cmd, rest.as_slice()) {
        ("define", [file]) => match read(file) {
            Ok(s) => Some(s),
            Err(code) => return code,
        },
        ("view", names) if !names.is_empty() => None,
        ("query", []) | ("rename", [_, _]) | ("history", [_]) => None,
        _ => return usage(),
    };
    let mut store = match open_store() {
        Ok(s) => s,
        Err(d) => return diagnostics(&d),
    };
    match cmd {
        "define" => match store.define(src.as_deref().unwrap_or_default(), agent) {
            Ok(d) => emit(Out { defined: Some(&d), ..Out::default() }, 0),
            Err(d) => diagnostics(&d),
        },
        "view" => match store.view(&rest) {
            Ok(v) => emit(Out { views: Some(&v), ..Out::default() }, 0),
            Err(d) => diagnostics(&d),
        },
        "query" => {
            let q = Query { name: flags.get("name").cloned(), type_pattern: flags.get("type").cloned(), uses: flags.get("uses").cloned() };
            match store.query(&q) {
                Ok(r) => emit(Out { results: Some(&r), ..Out::default() }, 0),
                Err(d) => diagnostics(&d),
            }
        }
        "rename" => match store.rename(&rest[0], &rest[1], agent) {
            Ok(r) => emit(Out { renamed: Some(&r), ..Out::default() }, 0),
            Err(d) => diagnostics(&d),
        },
        _ => match store.history(&rest[0]) {
            Ok(h) => emit(Out { history: Some(&h), ..Out::default() }, 0),
            Err(d) => diagnostics(&d),
        },
    }
}

fn run_command(cmd: &str, args: &[String]) -> ExitCode {
    // `<target>` is a `.qal` file, or (store) the function to call/run or the first test name.
    let from_file = args.first().is_some_and(|t| is_file(t));
    let loaded = if from_file {
        match read(&args[0]) {
            Ok(src) => load(&src),
            Err(code) => return code,
        }
    } else {
        if cmd != "test" && args.is_empty() {
            return usage();
        }
        load_store()
    };
    let opts_from = match (cmd, from_file) {
        ("test", true) => 1,
        ("test", false) => 0,
        (_, _) => 1,
    };
    let (perms, rest) = match take_options(&args[opts_from.min(args.len())..]) {
        Ok(x) => x,
        Err(e) => return bad_usage(&e),
    };
    let loaded = match loaded {
        Ok(l) => l,
        Err(d) => return diagnostics(&d),
    };
    match cmd {
        "test" => {
            if from_file && !rest.is_empty() {
                return usage();
            }
            test(&loaded, perms, &rest)
        }
        "call" => {
            let (name, raw) = if from_file {
                let Some(name) = rest.first() else {
                    return usage();
                };
                (name.clone(), &rest[1..])
            } else {
                (args[0].clone(), &rest[..])
            };
            call(&loaded, perms, &name, raw)
        }
        _ => {
            let name = if from_file { "main".to_string() } else { args[0].clone() };
            run(&loaded, perms, &name, &rest)
        }
    }
}

fn test(loaded: &Loaded, perms: qal_run::Permissions, names: &[String]) -> ExitCode {
    let unknown: Vec<Diagnostic> = names.iter().filter(|n| !loaded.typed.tests.iter().any(|t| &t.name == *n)).map(|n| Diagnostic::unknown_name(n, "", n)).collect();
    if !unknown.is_empty() {
        return diagnostics(&unknown);
    }
    let tests: Vec<TestResult> = loaded.runner(&Entry::Tests, perms).run_tests().into_iter().filter(|t| names.is_empty() || names.contains(&t.name)).collect();
    let passed = tests.iter().filter(|t| t.passed).count();
    let failed = tests.len() - passed;
    emit(Out { tests: Some(&tests), passed: Some(passed), failed: Some(failed), ..Out::default() }, u8::from(failed > 0))
}

fn call(loaded: &Loaded, perms: qal_run::Permissions, name: &str, raw: &[String]) -> ExitCode {
    let vals = match parse_args(&loaded.typed, name, raw) {
        Ok(v) => v,
        Err(e) => return emit(Out { error: Some(&e), ..Out::default() }, 1),
    };
    let out = loaded.runner(&Entry::Fn(name.to_string()), perms).invoke(name, &vals);
    match &out.result {
        Ok(v) => emit(Out { ok: Some(v), stdout: Some(&out.stdout), ..Out::default() }, 0),
        Err(e) => emit(Out { error: Some(e), stdout: Some(&out.stdout), ..Out::default() }, 1),
    }
}

fn run(loaded: &Loaded, perms: qal_run::Permissions, name: &str, args: &[String]) -> ExitCode {
    if !is_entry_point(&loaded.typed, name) {
        let e = if loaded.typed.fn_index(name).is_some() {
            let mut e = RunError::new("bad_args", name, format!("`{name}` is not an entry point"));
            e.hints.push("`qal run` needs a function `fn(List[Str]) -> Int`; use `qal call` for others".into());
            e
        } else {
            RunError::new("unknown_function", name, format!("no entry point `{name}`"))
        };
        return emit(Out { error: Some(&e), ..Out::default() }, 1);
    }
    let list = Value::List(args.iter().map(|a| Value::Str(a.clone())).collect());
    let out = loaded.runner(&Entry::Fn(name.to_string()), perms).invoke(name, &[list]);
    match &out.result {
        Ok(Value::Int(code)) => emit(Out { exit_code: Some(*code), stdout: Some(&out.stdout), ..Out::default() }, u8::try_from(*code).unwrap_or(1)),
        Ok(other) => {
            let e = RunError::new("trap", name, format!("entry point returned {other:?} instead of Int"));
            emit(Out { error: Some(&e), stdout: Some(&out.stdout), ..Out::default() }, 1)
        }
        Err(e) => emit(Out { error: Some(e), stdout: Some(&out.stdout), ..Out::default() }, 1),
    }
}
```
