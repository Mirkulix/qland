# QAL Phase 1d — MCP Server for AI Agents and Full CLI Operations Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Agents work with QAL only through operations: `qal mcp` is a Model Context Protocol server on stdio with the tools `qal_define, qal_test, qal_run, qal_call, qal_view, qal_query, qal_rename, qal_history, qal_build`, a one-page language reference in the tool descriptions, results and diagnostics as JSON data, no panic and no hang on any path a client can reach, registered for this repository in `.mcp.json`; the CLI offers the same operations (`qal build` is new) and fixes the argument and message issues carried over from 1b/1c.

**Architecture:** A new module `qal_cli::ops` holds every operation once (`define, view, query, rename, history, test, call, run, build`) and returns a `Reply` (the JSON object of spec §9 plus the CLI exit code); `main.rs` (CLI) and `qal_cli::mcp` (JSON-RPC 2.0 over newline-delimited stdio, implemented directly on `serde_json`) are thin front ends over it. Below them the compiler pipeline becomes fail-closed (`qal_wasm::compile` returns `Result`, `canon::resolve` never encodes placeholders, no `unwrap/expect/unreachable/panic` outside tests, enforced by clippy restriction lints), and the runtime gains a wall-clock timeout (wasmtime epoch interruption), non-blocking regular-file-only `fs`, and project-confined permissions for agents.

**Tech Stack:** Rust 1.97 (edition 2021); existing `serde`/`serde_json` 1, `wasm-encoder =0.259.0`, `wasmparser =0.259.0`, `wasmtime =49.0.1`, `sha2 =0.11.0`, `rusqlite =0.40.2`. **No new dependency** (no MCP SDK: the protocol subset is small, and an SDK would pull an async runtime into a synchronous compiler); `qal/Cargo.lock` does not change.

**Spec:** `docs/superpowers/specs/2026-10-15-qal-design.md` (§9 Agenten-Schnittstelle, §7 diagnostics as data, §8 `qal build`, §1 thesis). Roadmap: `docs/superpowers/specs/2026-10-15-qal-roadmap.md` (row 1d and "Pflicht in 1d"). MCP: revisions 2026-07-28 (stateless, per-request `_meta`) and 2025-11-25 … 2024-11-05 (initialize handshake), read on modelcontextprotocol.io on 2026-10-15. Previous sub-plan: `docs/superpowers/plans/2026-10-15-qal-phase1c-graph-store.md`.

**Sub-plan context:** Phase 1 is delivered as five sub-plans: 1a core pipeline (done), 1b data types + memory + effects (done), 1c canonical form + hashing + SQLite store (done), **1d MCP server + full CLI operations (this plan)**, 1e benchmark.

**How this plan was made:** every file below was first implemented and tested in a scratch copy of the repository (232 tests passing, zero compiler warnings, clippy restriction lints clean), then reviewed by an independent reviewer who attacked it (malformed and huge JSON-RPC, pipelined requests, path traversal and symlinks in `fs` grants, FIFOs, runaway programs, deep sources, panics); the confirmed findings are fixed and pinned by tests (see Review Focus). Then an agent with no QAL knowledge solved three tasks using only the MCP server (see Agent Trial); what it stumbled over went into the reference and the diagnostics. The plan was generated by a script that replayed every step on a fresh copy of the repository HEAD, ran each command and recorded its real outcome, and checked that the result after Task 5 is byte-identical to the reviewed code — the code blocks are exactly that code.

## Global Constraints

- Workspace `qland/qal/`, branch `Mac`. No dependency changes; `qal/Cargo.lock` (tracked) must stay unchanged — `git diff --stat qal/Cargo.lock` is empty after every task.
- **No panic on any path a CLI user or MCP client can reach:** no `unwrap()`, `expect()`, `panic!`, `unreachable!`, `todo!`, `unimplemented!` outside test code in any crate (checked in Task 5 with `cargo clippy --workspace --lib --bins -- -A clippy::all -D clippy::unwrap_used -D clippy::expect_used -D clippy::panic -D clippy::unreachable -D clippy::todo -D clippy::unimplemented`). Broken internal invariants are errors (`internal compiler error`, `store_error`, `trap`), never placeholders.
- The MCP server writes nothing but JSON-RPC messages to stdout, one per line; programs never read the protocol channel (their `read_line` input is the `stdin` argument).
- Every program an agent runs is bounded: 10 s wall clock, 2·10⁹ fuel, 256 MiB memory; `qal_test` as a whole 30 s; output to the agent 64 KiB, decoded strings 256 KiB per value, a runtime error's values 64 KiB, a tool result 4 MiB.
- Diagnostic JSON fields unchanged (`code, kind, def, path, message, expected?, found?, hints, dependents?`); all messages English. New codes: `E0102 bad_pattern`, `E0405 kind_change`, `E0511 compile_error` (runtime), `E0701 bad_arguments` and `E0702 result_too_large` (MCP tool results).
- CLI output stays one JSON line on stdout (except `fmt`); exit codes: 0 success, 1 diagnostics / runtime error / failed tests, 2 usage or I/O error including a missing or unreadable store.
- Builds and tests must be warning-free (`cargo build --workspace --all-targets`).
- Stage only the paths named in each commit step (never `git add -A`; the user's uncommitted `qlang/web/index.html` stays untouched). Do not push.

## Design Decisions

Decided here (the user delegates design decisions); each is reflected in the code below.

1. **Protocol implemented directly, dual-era.** `qal_cli::mcp` speaks JSON-RPC 2.0 over newline-delimited stdio with `serde_json` only. It serves both MCP eras: the `initialize` handshake (versions `2025-11-25`, `2025-06-18`, `2025-03-26`, `2024-11-05`; the requested one is echoed if supported, else `2025-11-25`) and the stateless `2026-07-28` revision (every request carries `_meta["io.modelcontextprotocol/protocolVersion"]` and `…/clientCapabilities`; `server/discover`; results carry `resultType: "complete"` and `_meta` server info; an unknown version is `-32022` with `data.supported`/`requested`; a missing capability object is `-32602`). Reason: the Claude Code version that will use the server may speak either era; the spec allows a dual-era server and the cost is a few branches. Methods: `initialize`, `server/discover`, `ping`, `tools/list`, `tools/call`; notifications (`notifications/initialized`, `notifications/cancelled`, anything else) and responses are ignored; other methods `-32601`.
2. **One request at a time, in order.** Requests are answered sequentially by one thread (with a 256 MiB stack: checker and code generator recurse up to the parser's nesting limit). Cancellation is not implemented (allowed by the spec): every request is bounded instead (Decision 9). Store writes serialize anyway (`BEGIN IMMEDIATE`), and ordered answers make the server deterministic to test.
3. **Tools:** the eight of spec §9 plus `qal_call` (call any function with JSON arguments — agents check helpers without writing an entry point). `qal_run` takes `entry` (default `main`), `args`, `stdin`, `allow`; `qal_build` takes `entry`. No separate `qal_check`: a failing `qal_define` stores nothing, so it already is a check.
4. **Results:** a tool result has the operation's JSON (exactly the CLI's output object) as text content and as `structuredContent`. `isError` is true iff the result has `diagnostics`, a runtime `error`, or failed tests; a program that runs and returns a non-zero exit code is data, not a tool failure. Protocol errors (`-32700` parse, `-32600` invalid request — also batches, ids that are not a string or 64-bit integer (they could not be echoed exactly), oversized messages —, `-32602` unknown tool or malformed `params`, `-32603` internal) are only for malformed requests. Wrong tool arguments (unknown keys, wrong types, missing required ones, oversized `source`) are tool errors with a `bad_arguments` diagnostic (`E0701`), so the agent can correct them.
5. **Shared operations.** `qal_cli::ops` implements each operation once for CLI and MCP; a `Ctx` says where the store is (`Discover` from the current directory for the CLI, `Root` for the server, where only `define` creates the store — reading tools on a project without code answer "there is no QAL code in … yet" and leave nothing behind), where `read_line` reads from, and the limits. The MCP agent name defaults to `mcp:<clientInfo.name>` (`agent` argument overrides it, 1–64 characters, no control or Unicode format characters).
6. **Agent permissions are confined to the project** (`Permissions::parse_in`): `fs:<dir>` is relative to the project root, must resolve inside it, and no path component below a granted directory may start with `.` — neither grantable nor reachable. This keeps `.git` (hooks would execute outside the sandbox), `.qal` (the store), `.claude`/`.mcp.json` (agent permissions) and `.env` out of reach even with `fs:.`. Relative guest paths resolve against the root (a `base` in `Permissions`, not `chdir`, so nothing global changes). The CLI keeps `Permissions::parse` (the user's own working directory, no hidden-entry rule).
7. **Non-blocking files** (carried over): every `fs` open uses `O_NOFOLLOW | O_NONBLOCK` and requires a regular file after opening (`fstat`); a FIFO or device is `<path>: not a regular file`. `fs` is refused on platforms where either flag value is unknown.
8. **Fail-closed compiler** (carried over): `qal_wasm::compile` returns `Result<CompiledModule, String>`; the module builder records the first broken invariant (`Mb::bug`) and `finish` returns `internal compiler error: …` instead of a module; `canon::resolve` returns `None` instead of a zero hash or group index `u32::MAX`, and the encoder fails; operator tags come from an exhaustive `match`; `TProgram::{variant_fields, record_fields}` return empty lists for misuse; the runtime turns every impossible state (no memory export, unknown failure site, non-Bool test) into a `trap` error; a module that cannot be compiled is a `compile_error` (`E0511`) runtime error. `catch_unwind` around every request and every tool is the last line of defence (answered as `-32603`), not the mechanism. `debug_assert!`s stay (they are compiled out of the release binary the server runs). Indexing panics are not linted; they are covered by `catch_unwind`.
9. **Limits:** messages longer than 4 MiB are skipped up to the next newline without being buffered and answered with `-32600`; `source` ≤ 1 MiB; serde_json's recursion limit (128) bounds JSON nesting; each run has a 10 s wall-clock timeout (wasmtime epoch interruption; a watchdog thread increments the epoch, and `set_epoch_deadline(1)` per call makes earlier ticks harmless), the existing fuel budget and 256 MiB memory limit; `qal_test` stops starting tests after 30 s and lists the rest as `skipped`; printed output beyond 64 KiB is counted but not kept (`stdout_truncated` = full size; no `out_of_memory` for it); decoded values carry at most 256 KiB of strings (cut strings end in `...(+N bytes)`); the `values` of a runtime error over 64 KiB of JSON are dropped with a hint; a tool response over 4 MiB of JSON (text and `structuredContent` together) becomes `result_too_large`. Compilation runs without optimization passes and with single-pass register allocation, so its time is linear in the module size (the optimizing defaults needed minutes for a 150 000-element list literal; Phase 1 programs are bounded by fuel, not judged by speed).
10. **Unknown entries are rejected before compiling** (carried over): `run`, `call`, `test` and `build` look the name up in the checked program first; a test given to `call` is "`x` is a test, not a function", a function given to `test` is "`x` is a function, not a test", a name that was renamed gets the hint "`x` was renamed to `y`" (`Store::renamed_to`, following chains of renames).
11. **CLI arguments** (carried over): `split_args` accepts `--options` anywhere before the program arguments start (after `--`, or — once the command has its targets: `call <file> <fn>` = two, `call <fn>`/`run` = one, `test` = all — at the first argument that is not a known option, so `run f.qal --verbose` passes `--verbose` on as in 1c), validates everything before touching the store, and rejects unknown options and extra arguments (`check`, `fmt`, `test <file>`, `init`, `mcp`). A target is a **file if it ends in `.qal` or contains `/` or `\`** (`./foo`, `dir/foo`), otherwise a store name (names never contain `.` or `/`). Output is written with `writeln!` and write errors are ignored, so a closed stdout is not a panic.
12. **`qal build <name>` / `qal_build`** (spec §8): compiles a stored function to `<project>/.qal/build/<name>.wasm` and writes `<name>.manifest.json` (`format: "qal-build/1"`, `name`, `hash` of the definition, `signature`, `entry_point`, required `effects`, `qal_host` `imports`, `exports`, `wasm_sha256`, `bytes`), both atomically (temp file + rename). The module imports the QAL host functions; a stand-alone runner for built modules is not part of Phase 1.
13. **Store additions** (carried over from 1c): redefining a name as another kind (fn → test, …) is `kind_change` (`E0405`) instead of a silent replacement; an invalid `query --type` pattern (empty, too long, unbalanced brackets) is `bad_pattern` (`E0102`) instead of an empty result; `view`, `history`, `rename` and `query --uses` of a renamed name hint at the new name (following the chain of renames, also back and forth); identifiers are at most 128 characters (they become file names in `qal build`).
14. **Language reference** (`qal-cli/src/reference.md`, 37 lines ≈ 4 KB, included with `include_str!`) is part of `qal_define`'s description — the tool an agent must use first — and explains definitions, types, expressions, effects, contracts, every built-in, the store rules (relinking, `signature_change`, kinds, name binding, `E0404 alias_reference`) and the workflow; the other tools have short descriptions, and `initialize`/`server/discover` give a three-sentence `instructions`. Over MCP, the runtime's permission hint (`grant them with --allow io`) is rewritten to the tool argument (`pass "allow": ["io"] to qal_run or qal_call`).
15. **Registration:** `.mcp.json` in the repository root starts `sh qal/mcp.sh`; the script rebuilds the release binary quietly (output to stderr, so stdout stays protocol-only) and `exec`s `qal mcp --root "$PWD"` (Claude Code starts project servers in the project directory; `QAL_ROOT` overrides). The store of this repository is therefore `qland/.qal/store.db`; `.qal/` is added to `.gitignore`.
16. **Known limitations (documented, not fixed):** no deletion of definitions (Phase 1 has none; a probe stays in the store under its name); a test cannot assert an expected runtime error; no read-all-of-stdin built-in, so a last line without a newline is indistinguishable (`wc` exactness); requests are not cancellable mid-run (bounded by Decision 9); the per-run limits are constants, not tool arguments.

Carried-over items ("Pflicht in 1d", roadmap) and where they are done: options before the name and file-vs-name rule, store loaded only after option validation, `check`/`test` reject extra arguments, options before the file name (Task 4, Decision 11); `qal test <fn>` message, unknown entry rejected before `compile` (Task 4, Decision 10); `query --type` invalid pattern (Task 3, Decision 13); `canon::resolve` fail-closed, no `expect/unwrap/unreachable!` on reachable paths (Tasks 1–2, Decision 8, clippy check in Task 5); closed stdout without panic (Task 4); "renamed to X" hints (Task 3, Task 4); name binding and E0404 in the tool reference (Task 5, Decision 14); `define` across kinds (Task 3, Decision 13); FIFOs/devices (Task 2, Decision 7); `qal build` (Task 4, Decision 12).

## Review Focus

These are the attacks the scratch implementation was reviewed against; each is pinned by a test that must keep passing:

1. **A malicious or buggy client** (garbage, invalid UTF-8, batches, `null` ids, wrong `jsonrpc`, `params` arrays, unknown methods and tools, 5 MiB lines, 200 pipelined requests): error responses in order, the server keeps serving and exits 0 on EOF — Task 5 `malformed_messages_get_error_responses_and_the_server_keeps_going`, `many_requests_written_at_once_are_answered_in_order`.
2. **Runaway programs** (infinite tail recursion with unlimited fuel, endless printing, exponential memory, a hanging test): `timeout` / `out_of_memory` errors within bounded time, output capped, server alive — Task 2 `wall_clock_timeout_interrupts_and_the_runner_stays_usable`, Task 5 `runaway_programs_time_out_and_the_server_survives`.
3. **Escaping the project through `fs`** (`fs:..`, `fs:/`, `fs:.qal`, `data/../..`, `.git/...`, `data/.env`, absolute paths outside): refused — Task 2 `confined_permissions_resolve_against_the_root_and_hide_dot_entries`, Task 5 `file_access_is_confined_to_the_project_without_hidden_entries`; FIFOs do not block — Task 2 `fifos_in_granted_directories_do_not_block`.
4. **The protocol channel**: a program reading stdin gets the `stdin` argument, never protocol bytes — Task 5 `programs_read_the_given_stdin_never_the_protocol_channel`.
5. **Broken invariants** become errors, not panics — Task 1 `compile_reports_internal_errors_instead_of_panicking`, `unresolvable_references_fail_closed`; the clippy command of Task 5.

Confirmed findings of the independent review, fixed in the code below:

1. **Important — compilation had no time bound:** a 939 KB `main` with a 150 000-element list literal (under the 1 MiB source limit) took 131 s in wasmtime's optimizing compiler, blocking the server (a pipelined `ping` waited as long). Fix: `Runner::new` compiles with `cranelift_opt_level(None)` and single-pass register allocation (150 000 elements: 0.6 s; a 40 000-arm `match`: 23 s → 0.24 s). Pinned: Task 2 `large_functions_compile_in_linear_time`.
2. **Important — return values were not size-capped:** `qal_call` of a function returning a 2²⁵-character string produced a 637 MB response line (986 MB server RSS). Fix: decoded values have a string budget of 256 KiB (`MAX_STR_BYTES`; longer strings end in `...(+N bytes)`), and a tool result over 4 MiB of JSON is replaced by `result_too_large` (`E0702`). Pinned: Task 2 `strings_share_one_byte_budget_per_value`, Task 5 `runaway_programs_time_out_and_the_server_survives`.
3. **Minor — output was buffered up to 256 MB and then reported as `out_of_memory`** although the agent gets 64 KiB. Fix: `Runner::with_stdout_limit` keeps the first bytes and counts the rest (`Outcome::stdout_bytes`); a program that prints a lot and returns 0 succeeds with `stdout_truncated`. Pinned: Task 2 `output_beyond_the_stdout_limit_is_counted_not_kept`, Task 5 (`chatty`).
4. **Minor — CLI regression:** `qal run f.qal --verbose` became "unknown option". Fix: once a command has its targets, the first argument that is not a known option starts the program arguments (as in 1c). Pinned: Task 4 `options_are_accepted_before_and_after_the_target`, `options_may_come_before_the_file_or_name`.
5. **Minor — renaming back and forth lost the "renamed to" hint** (64 steps alternating, ending on a gone name). Fix: a visited set; the answer is the last existing name on the chain. Pinned: Task 3 `old_names_point_to_the_new_name`.
6. **Minor — `fs:` with an empty directory granted the whole root** (hidden entries stayed protected). Fix: rejected like `fs`. Pinned: Task 2 `confined_permissions_…`, Task 5 `file_access_…`.
7. **Minor — names had no length limit** (a 10 000-character rename succeeded; building it failed with "File name too long" as a `store_error`). Fix: identifiers are at most 128 characters (lexer and rename). Pinned: Task 3 `identifiers_have_a_length_limit`, `old_names_point_to_the_new_name`.
8. **Minor — reading tools created the store** (and failed on a read-only root). Fix: only `define` creates it; the others answer "there is no QAL code in … yet" with a hint. Pinned: Task 5 `reading_tools_do_not_create_a_store`.
9. **Minor — ids were not echoed exactly** (`123456789012345678901234567890` came back as a float; `1.5` was accepted) and agent names could contain bidi overrides. Fix: ids must be strings or 64-bit integers (`-32600` otherwise); agent names reject zero-width and bidi formatting characters. Pinned: Task 5 `malformed_messages_…`.

A second review round of these fixes confirmed all nine and found three more, also fixed: the 4 MiB result cap now measures the whole response line (text and `structuredContent` together; a 5.2 MB line slipped through before), agent names reject the whole Unicode format category (`U+061C`, tag characters, …, not only a few ranges), and a runtime error's `values` over 64 KiB of JSON are dropped with a hint, so one huge contract argument no longer replaces a whole `qal_test` report with `result_too_large`. Pinned: Task 5 `runaway_programs_time_out_and_the_server_survives` (`many`, `big_value`), `malformed_messages_…` (agent names).

Held up under attack (no change needed): every `fs` escape tried (symlinks to outside and to `.git`, case variants `.GIT`/`.MCP.json` on the case-insensitive file system, `..` chains, absolute paths, `/dev/*` links, writes into `.qal`/`.git`), FIFOs, CRLF, BOM, NUL, invalid UTF-8, lone surrogates, 100 000-deep JSON, exactly-4-MiB lines, 2 000 pipelined pings (answered in order in 13 ms), stdout pollution (none), deep and large sources at the parser limits, the fuel and wall-clock limits, the test budget, `qal_build` names.

## Agent Trial

Before this plan was written, a general-purpose subagent with no QAL knowledge got the scratch server and a 40-line stdio client (`initialize`, then one `tools/call` per invocation; `--list` printed `tools/list` as an MCP client sees it). It was told to learn QAL only from the tool list and the tool results, to write no files, and to solve three tasks with tests and an entry point each.

| Task | Tool calls | Failed attempts | Result |
|---|---|---|---|
| Word count of stdin (`wc_main`, `lines words chars`) | 7 (4 of them probes of `read_line`) | 0 | solved; matches `wc` for newline-terminated input |
| Roman numerals `to_roman` (1..3999, `req`), strict `from_roman -> Option[Int]`, entry point | 6 | 0 | solved; 12 tests incl. a round trip over 1..3999 |
| Bank account state machine (record state, command and error enums, `step -> Result`, argument parser) | 15 (6 deliberate error probes) | 0 | solved; 13 tests |

Every `qal_define`, `qal_test` and `qal_run` of the real solutions passed on the first try; all diagnostics it saw came from deliberate probes, and it rated them sufficient to fix the code (`contract_violation` with values, `int_overflow` with the path to the record field, `non_exhaustive_match`, `effect_violation`, discarded non-Unit values). What it found, and what changed because of it:

- The permission hint named the CLI flag (`grant them with --allow io`), which is wrong over MCP → the server rewrites it to `pass "allow": ["io"] to qal_run or qal_call` (Decision 14; pinned in `an_agent_defines_tests_runs_and_inspects_code`).
- `map(xs, len)` said "unknown name `len`" although `len` is known → the message is now "built-in `len` is not a value" with a wrapping example (Task 1 `builtins_used_as_values_say_so`).
- Undocumented semantics it had to discover by probing → added to the reference: `print` appends a newline; `read_line` drops `\n`/`\r\n` and returns `None` at the end; string escapes; `to_int` accepts a sign and digits only; a `let` inside a sequence item ends at its `;` (bind before the sequence); deep non-tail recursion can overflow the stack.
- Limitations it hit, kept for later phases (Decision 16): no deletion of definitions (its probes stay stored), no way to test for an expected runtime error, no read-all-of-stdin built-in (a last line without `\n` cannot be detected, so `wc` differs for such input), `split` on a single separator only.

pub(crate) fn renamed_to(conn: &Connection, names: &dyn Fn(&str) -> bool, old: &str) -> Result<Option<String>, Vec<Diagnostic>> {

    // seen (renames back and forth); the answer is the last name on the way that still exists.
    let mut seen = std::collections::HashSet::from([old.to_string()]);

pub mod ops;

use qal_core::diag::Diagnostic;

use qal_run::{Permissions, RunError, Runner, Value};

pub struct Loaded {
    pub program: Program,
    pub typed: TProgram,
}

/// Parses and checks `src`. Any diagnostic means nothing can be compiled.
pub fn load(src: &str) -> Result<Loaded, Vec<Diagnostic>> {
    let program = qal_text::parse_program(src).map_err(|d| vec![d])?;
    load_program(program)
}

/// Checks an already parsed (or stored) program.
pub fn load_program(program: Program) -> Result<Loaded, Vec<Diagnostic>> {
    let typed = qal_check::check(&program)?;
    Ok(Loaded { program, typed })
}

/// A command's target is a source file if it ends in `.qal` or contains a path separator
/// (`./foo`, `dir/foo`), otherwise a name in the store (names never contain `.` or `/`).
pub fn is_file(target: &str) -> bool {
    target.ends_with(".qal") || target.contains('/') || target.contains('\\')
}

/// The store of the project around the current directory.
pub fn open_store() -> Result<Store, Vec<Diagnostic>> {
    let cwd = std::env::current_dir().map_err(|e| vec![Diagnostic::store_error(format!("no current directory: {e}"))])?;
    Store::discover(&cwd)
}

/// Loads the whole codebase of the project's store.
pub fn load_store() -> Result<Loaded, Vec<Diagnostic>> {
    load_program(open_store()?.program()?)
}

/// True if `name` is a function `fn(List[Str]) -> Int` (with any effects), i.e. runnable by `qal run`.
pub fn is_entry_point(typed: &TProgram, name: &str) -> bool {
    typed.fns.iter().any(|f| f.def.name == name && f.def.ret == Type::Int && f.def.params.len() == 1 && f.def.params[0].ty == Type::list(Type::Str))
}

impl Loaded {
    /// Compiles only the code reachable from `entry` and prepares a runner with `perms`.
    /// The caller has checked that `entry` names an existing function.
    pub fn runner(&self, entry: &Entry, perms: Permissions) -> Result<Runner, RunError> {
        let def = match entry {
            Entry::Fn(name) => name.as_str(),
            Entry::Tests | Entry::All => "",
        };
        let compile_error = |m: String| {
            let mut e = RunError::new("compile_error", def, format!("the program cannot be compiled to WebAssembly: {m}"));
            e.hints.push("this is a limitation of the compiler, not an error in the program; try splitting very large functions or list literals".into());
            e
        };
        let module = qal_wasm::compile(&self.typed, entry).map_err(compile_error)?;
        Ok(Runner::new(module).map_err(compile_error)?.with_permissions(perms))
    }
}

/// Command-line arguments split into options, targets and program arguments.
#[derive(Debug, Default, PartialEq)]
pub struct Split {
    /// Values of each `--option` (in order; repeatable options have several).
    pub options: HashMap<String, Vec<String>>,
    /// Positional arguments that name what to work on (files, names).
    pub targets: Vec<String>,
    /// Everything after the targets: arguments for the program (`run`, `call`).
    pub rest: Vec<String>,
}

impl Split {
    /// The single value of `--name`, if given.
    pub fn one(&self, name: &str) -> Option<&str> {
        self.options.get(name).and_then(|v| v.first()).map(String::as_str)
    }
}

/// Splits `args` into `--option value` pairs (only the ones in `options`; `repeatable` ones may
/// occur several times), targets and program arguments. Options are accepted anywhere before the
/// program arguments start: those start after `--`, or once `targets(&targets_so_far)` targets
/// have been collected, at the first argument that is not a known option (so `run f.qal --verbose`
/// passes `--verbose` to the program). An unknown option before that is an error.
pub fn split_args(args: &[String], options: &[&str], repeatable: &[&str], targets: &dyn Fn(&[String]) -> usize) -> Result<Split, String> {
    let mut out = Split::default();
    let mut i = 0;
    while i < args.len() {
        let a = &args[i];
        if a == "--" {
            out.rest = args[i + 1..].to_vec();
            return Ok(out);
        }
        let complete = out.targets.len() >= targets(&out.targets);
        if let Some(name) = a.strip_prefix("--").filter(|n| options.contains(n) || !complete) {
            if !options.contains(&name) {
                return Err(format!("unknown option `{a}`"));
            }
            let value = args.get(i + 1).ok_or_else(|| format!("`{a}` needs a value"))?;
            let values = out.options.entry(name.to_string()).or_default();
            if !values.is_empty() && !repeatable.contains(&name) {
                return Err(format!("`{a}` given twice"));
            }
            values.push(value.clone());
            i += 2;
            continue;
        }
        if !complete {
            out.targets.push(a.clone());
            i += 1;
            continue;
        }
        out.rest = args[i..].to_vec();
        return Ok(out);
    }
    Ok(out)
}

/// Parses `--allow` values (each a comma-separated list) into permissions.
pub fn permissions(split: &Split) -> Result<Permissions, String> {
    let spec = split.options.get("allow").map(|v| v.join(",")).unwrap_or_default();
    Permissions::parse(&spec)
}

/// Converts CLI strings to values according to the signature of fn `name` (Int, Float, Bool, Unit, Str).
pub fn parse_args(typed: &TProgram, name: &str, raw: &[String]) -> Result<Vec<Value>, RunError> {
    let bad = |message: String| RunError::new("bad_args", name, message);
    let f = typed.fns.iter().find(|f| f.def.name == name).ok_or_else(|| RunError::new("unknown_function", name, format!("no function `{name}`")))?;
    if f.def.params.len() != raw.len() {
        return Err(bad(format!("`{name}` takes {} argument(s), {} given", f.def.params.len(), raw.len())));
    }
    f.def
        .params
        .iter()
        .zip(raw)
        .map(|(p, s)| match &p.ty {
            Type::Int => s.parse::<i64>().map(Value::Int).map_err(|_| bad(format!("`{}` must be Int, got `{s}`", p.name))),
            Type::Float => s.parse::<f64>().map(Value::Float).map_err(|_| bad(format!("`{}` must be Float, got `{s}`", p.name))),
            Type::Bool => match s.as_str() {
                "true" => Ok(Value::Bool(true)),
                "false" => Ok(Value::Bool(false)),
                _ => Err(bad(format!("`{}` must be Bool (true/false), got `{s}`", p.name))),
            },
            Type::Unit => match s.as_str() {
                "()" => Ok(Value::Unit),
                _ => Err(bad(format!("`{}` must be Unit `()`, got `{s}`", p.name))),
            },
            Type::Str => Ok(Value::Str(s.clone())),
            t => Err(bad(format!("`{}` has type {t}, which cannot be passed on the command line", p.name))),
        })
        .collect()
}

/// Converts JSON arguments to values according to the signature of fn `name`: Int, Float, Bool,
/// Unit (`null`), Str and lists of those.
pub fn json_args(typed: &TProgram, name: &str, raw: &[serde_json::Value]) -> Result<Vec<Value>, RunError> {
    let f = typed.fns.iter().find(|f| f.def.name == name).ok_or_else(|| RunError::new("unknown_function", name, format!("no function `{name}`")))?;
    if f.def.params.len() != raw.len() {
        return Err(RunError::new("bad_args", name, format!("`{name}` takes {} argument(s), {} given", f.def.params.len(), raw.len())));
    }
    f.def
        .params
        .iter()
        .zip(raw)
        .map(|(p, v)| json_value(&p.ty, v).map_err(|m| RunError::new("bad_args", name, format!("`{}`: {m}", p.name))))
        .collect()
}

fn json_value(ty: &Type, v: &serde_json::Value) -> Result<Value, String> {
    use serde_json::Value as J;
    Ok(match (ty, v) {
        (Type::Int, J::Number(n)) => Value::Int(n.as_i64().ok_or_else(|| format!("expected Int, got {n}"))?),
        (Type::Float, J::Number(n)) => Value::Float(n.as_f64().ok_or_else(|| format!("expected Float, got {n}"))?),
        (Type::Bool, J::Bool(b)) => Value::Bool(*b),
        (Type::Unit, J::Null) => Value::Unit,
        (Type::Str, J::String(s)) => Value::Str(s.clone()),
        (Type::List(elem), J::Array(xs)) => Value::List(xs.iter().map(|x| json_value(elem, x)).collect::<Result<_, _>>()?),
        (Type::Int | Type::Float | Type::Bool | Type::Unit | Type::Str | Type::List(_), other) => {
            let shown: String = other.to_string().chars().take(40).collect();
            return Err(format!("expected {ty}, got {shown}"));
        }
        (t, _) => return Err(format!("has type {t}, which cannot be passed as an argument (only Int, Float, Bool, Unit, Str and lists of them)")),
    })
}

/// An operation's output and the CLI exit code that goes with it.

impl Reply {
    fn new(out: Output, code: u8) -> Reply {
        Reply { out, code }
    }

    /// Diagnostics; exit 2 if the store itself failed (missing, unreadable, corrupt), else 1.
    pub fn diagnostics(d: Vec<Diagnostic>) -> Reply {
        let code = if !d.is_empty() && d.iter().all(|d| d.kind == "store_error") { 2 } else { 1 };
        Reply::new(Output { diagnostics: Some(d), ..Output::default() }, code)

    Discover(PathBuf),

    Root(PathBuf),

/// What `test`, `call` and `run` work on.

    Text(&'a str),

impl Ctx {
    /// The CLI context: the store around the current directory, no limits beyond the runtime's.
    pub fn cli() -> Result<Ctx, Vec<Diagnostic>> {
        let cwd = std::env::current_dir().map_err(|e| vec![Diagnostic::store_error(format!("no current directory: {e}"))])?;
        Ok(Ctx { store: StoreAt::Discover(cwd), stdin: None, timeout: None, test_budget: None, max_stdout: None })
    }

    /// The store; `create` makes it under `Root` if it does not exist yet (only `define` does,
    /// so reading never leaves a store behind).
    pub fn open_store(&self, create: bool) -> Result<Store, Vec<Diagnostic>> {
        match &self.store {
            StoreAt::Discover(dir) => Store::discover(dir),
            StoreAt::Root(root) if create => Store::init(root),
            StoreAt::Root(root) => {
                let path = root.join(qal_store::STORE_DIR).join(qal_store::STORE_FILE);
                if !path.exists() {
                    return Err(vec![Diagnostic::store_error(format!("there is no QAL code in {} yet", root.display())).hint("define code with qal_define first; it creates the store")]);
                }
                Store::open(&path)
            }
        }
    }

    /// The existing store.
    pub fn open(&self) -> Result<Store, Vec<Diagnostic>> {
        self.open_store(false)
    }

    fn load(&self, source: &Source) -> Result<Loaded, Vec<Diagnostic>> {
        match source {
            Source::Text(src) => load(src),
            Source::Store => load_program(self.open()?.program()?),
        }
    }

    fn runner(&self, loaded: &Loaded, entry: &Entry, perms: Permissions) -> Result<qal_run::Runner, RunError> {
        let mut r = loaded.runner(entry, perms)?;
        if let Some(t) = self.timeout {
            r = r.with_timeout(t);
        }
        if let Some(input) = &self.stdin {
            r = r.with_stdin(input.clone());
        }
        if let Some(max) = self.max_stdout {
            r = r.with_stdout_limit(max);
        }
        Ok(r)
    }

    /// Sets `stdout` (cut to `max_stdout` at a character boundary) on `out`; `total` is the
    /// number of bytes the program printed.
    fn stdout(&self, out: &mut Output, stdout: String, total: usize) {
        let Some(max) = self.max_stdout else {
            out.stdout = Some(stdout);
            return;
        };
        let mut end = stdout.len().min(max);
        while !stdout.is_char_boundary(end) {
            end -= 1;
        }
        if end < stdout.len() || total > max {
            out.stdout_truncated = Some(total.max(stdout.len()));
        }
        out.stdout = Some(stdout[..end].to_string());
    }

    /// A hint for a name that is not in the codebase but was renamed in the store.
    fn renamed_hint(&self, source: &Source, name: &str) -> Option<String> {
        match source {
            Source::Store => self.open().ok()?.renamed_to(name).ok()?.map(|new| format!("`{name}` was renamed to `{new}`")),
            Source::Text(_) => None,
        }
    }
}

/// Runs the named tests (all if `names` is empty).
pub fn test(ctx: &Ctx, source: &Source, perms: Permissions, names: &[String]) -> Reply {
    let loaded = match ctx.load(source) {
        Ok(l) => l,
        Err(d) => return Reply::diagnostics(d),
    };
    let mut unknown = Vec::new();
    for n in names {
        if loaded.typed.tests.iter().any(|t| &t.name == n) {
            continue;
        }
        let mut d = Diagnostic::unknown_name(n, "", n);
        if loaded.typed.fn_index(n).is_some() {
            d.message = format!("`{n}` is a function, not a test");
            d = d.hint(format!("call it with `qal call {n} ...`, or write a test: `test {n}_works = {n}(...) == ...`"));
        } else if let Some(h) = ctx.renamed_hint(source, n) {
            d = d.hint(h);
        }
        unknown.push(d);
    }
    if !unknown.is_empty() {
        return Reply::diagnostics(unknown);
    }
    let runner = match ctx.runner(&loaded, &Entry::Tests, perms) {
        Ok(r) => r,
        Err(e) => return Reply::error(e),
    };
    let start = Instant::now();
    let mut tests = Vec::new();
    let mut skipped = Vec::new();
    for t in loaded.typed.tests.iter().filter(|t| names.is_empty() || names.contains(&t.name)) {
        if ctx.test_budget.is_some_and(|b| start.elapsed() > b) {
            skipped.push(t.name.clone());
            continue;
        }
        let mut r = runner.run_test(&format!("test:{}", t.name));
        r.error = r.error.map(capped);
        tests.push(r);
    }
    let passed = tests.iter().filter(|t| t.passed).count();
    let failed = tests.len() - passed;
    let out = Output { tests: Some(tests), passed: Some(passed), failed: Some(failed), skipped: (!skipped.is_empty()).then_some(skipped), ..Output::default() };
    Reply::new(out, u8::from(failed > 0))
}

/// The function `name` of `loaded`, or why it cannot be called (checked before compiling).
fn find_fn(ctx: &Ctx, source: &Source, loaded: &Loaded, name: &str) -> Result<(), RunError> {
    if loaded.typed.fn_index(name).is_some() {
        return Ok(());
    }
    let mut e = RunError::new("unknown_function", name, format!("no function `{name}`"));
    if loaded.typed.tests.iter().any(|t| t.name == name) {
        e.message = format!("`{name}` is a test, not a function");
        e.hints.push(format!("run it with `qal test {name}`"));
    } else if let Some(h) = ctx.renamed_hint(source, name) {
        e.hints.push(h);
    }
    Err(e)
}

/// Calls any function with arguments converted by its signature.
pub fn call(ctx: &Ctx, source: &Source, perms: Permissions, name: &str, args: CallArgs) -> Reply {
    let loaded = match ctx.load(source) {
        Ok(l) => l,
        Err(d) => return Reply::diagnostics(d),
    };
    if let Err(e) = find_fn(ctx, source, &loaded, name) {
        return Reply::error(e);
    }
    let vals = match args {
        CallArgs::Strings(raw) => parse_args(&loaded.typed, name, raw),
        CallArgs::Json(raw) => json_args(&loaded.typed, name, raw),
    };
    let vals = match vals {
        Ok(v) => v,
        Err(e) => return Reply::error(e),
    };
    let runner = match ctx.runner(&loaded, &Entry::Fn(name.to_string()), perms) {
        Ok(r) => r,
        Err(e) => return Reply::error(e),
    };
    let outcome = runner.invoke(name, &vals);
    let mut out = Output::default();
    ctx.stdout(&mut out, outcome.stdout, outcome.stdout_bytes);
    match outcome.result {
        Ok(v) => {
            out.ok = Some(v);
            Reply::new(out, 0)
        }
        Err(e) => {
            out.error = Some(capped(e));
            Reply::new(out, 1)
        }
    }
}

/// Runs an entry point `fn(List[Str]) -> Int`; the exit code is the program's (1 if outside 0..=255).
pub fn run(ctx: &Ctx, source: &Source, perms: Permissions, name: &str, args: &[String]) -> Reply {
    let loaded = match ctx.load(source) {
        Ok(l) => l,
        Err(d) => return Reply::diagnostics(d),
    };
    if let Err(mut e) = find_fn(ctx, source, &loaded, name) {
        if e.message.starts_with("no function") {
            e.message = format!("no entry point `{name}`");
        }
        return Reply::error(e);
    }
    if !is_entry_point(&loaded.typed, name) {
        let mut e = RunError::new("bad_args", name, format!("`{name}` is not an entry point"));
        e.hints.push("`run` needs a function `fn(List[Str]) -> Int`; use `call` for others".into());
        return Reply::error(e);
    }
    let runner = match ctx.runner(&loaded, &Entry::Fn(name.to_string()), perms) {
        Ok(r) => r,
        Err(e) => return Reply::error(e),
    };
    let list = Value::List(args.iter().map(|a| Value::Str(a.clone())).collect());
    let outcome = runner.invoke(name, &[list]);
    let mut out = Output::default();
    ctx.stdout(&mut out, outcome.stdout, outcome.stdout_bytes);
    match outcome.result {
        Ok(Value::Int(code)) => {
            out.exit_code = Some(code);
            Reply::new(out, u8::try_from(code).unwrap_or(1))
        }
        Ok(other) => {
            out.error = Some(RunError::new("trap", name, format!("entry point returned {other:?} instead of Int")));
            Reply::new(out, 1)
        }
        Err(e) => {
            out.error = Some(capped(e));
            Reply::new(out, 1)
        }
    }
}

/// Compiles the stored function `name` into `<project>/.qal/build/<name>.wasm` plus
/// `<name>.manifest.json` (required effects, imports, hash).
pub fn build(ctx: &Ctx, name: &str) -> Reply {
    let mut store = match ctx.open() {
        Ok(s) => s,
        Err(d) => return Reply::diagnostics(d),
    };
    let loaded = match store.program().and_then(load_program) {
        Ok(l) => l,
        Err(d) => return Reply::diagnostics(d),
    };
    if let Err(e) = find_fn(ctx, &Source::Store, &loaded, name) {
        return Reply::error(e);
    }
    let entry = match store.query(&Query { name: Some(name.to_string()), ..Query::default() }) {
        Ok(rs) => rs.into_iter().find(|e| e.name == name),
        Err(d) => return Reply::diagnostics(d),
    };
    let Some(entry) = entry else {
        return Reply::diagnostics(vec![Diagnostic::store_error(format!("`{name}` is in the codebase but has no stored entry"))]);
    };
    let module = match qal_wasm::compile(&loaded.typed, &Entry::Fn(name.to_string())) {
        Ok(m) => m,
        Err(m) => return Reply::error(RunError::new("compile_error", name, format!("the program cannot be compiled to WebAssembly: {m}"))),
    };
    let Some(meta) = module.func(name) else {
        return Reply::error(RunError::new("compile_error", name, format!("`{name}` is missing from its own module")));
    };
    // .qal/store.db -> the project root
    let Some(project) = store.path().parent().and_then(Path::parent) else {
        return Reply::diagnostics(vec![Diagnostic::store_error("the store has no project directory")]);
    };
    let dir = project.join(qal_store::STORE_DIR).join("build");
    let manifest = Manifest {
        format: "qal-build/1",
        name,
        hash: &entry.hash,
        signature: entry.signature.clone(),
        entry_point: is_entry_point(&loaded.typed, name),
        effects: &meta.effects,
        imports: &module.imports,
        exports: module.funcs.iter().filter(|f| !f.is_test).map(|f| f.export.clone()).collect(),
        wasm_sha256: Hash::of(&module.wasm).to_hex(),
        bytes: module.wasm.len(),
    };
    let json = match serde_json::to_string_pretty(&manifest) {
        Ok(j) => j + "\n",
        Err(e) => return Reply::diagnostics(vec![Diagnostic::store_error(format!("cannot write the manifest: {e}"))]),
    };
    let (wasm_rel, manifest_rel) = (format!(".qal/build/{name}.wasm"), format!(".qal/build/{name}.manifest.json"));
    let written = std::fs::create_dir_all(&dir)
        .and_then(|_| write_atomic(&project.join(&wasm_rel), &module.wasm))
        .and_then(|_| write_atomic(&project.join(&manifest_rel), json.as_bytes()));
    if let Err(e) = written {
        return Reply::diagnostics(vec![Diagnostic::store_error(format!("cannot write {}: {e}", dir.display()))]);
    }
    let built = Built { name: name.to_string(), hash: entry.hash, wasm: wasm_rel, manifest: manifest_rel, effects: meta.effects.clone(), bytes: module.wasm.len() };
    Reply::new(Output { built: Some(built), ..Output::default() }, 0)
}

/// Largest JSON of the values of one runtime error; larger values are dropped (with a hint), so a
/// single huge contract argument cannot crowd out the rest of a report.
pub const MAX_ERROR_VALUES_BYTES: usize = 64 << 10;

fn capped(mut e: RunError) -> RunError {
    let size = serde_json::to_string(&e.values).map_or(usize::MAX, |s| s.len());
    if size > MAX_ERROR_VALUES_BYTES {
        e.values = qal_run::Values::default();
        e.hints.push(format!("the values involved ({size} bytes of JSON) are too large to show"));
    }
    e
}

/// Writes `bytes` to a temporary file next to `path`, then renames it into place.
fn write_atomic(path: &Path, bytes: &[u8]) -> std::io::Result<()> {
    let tmp = path.with_extension(format!("tmp-{}", std::process::id()));
    std::fs::write(&tmp, bytes)?;
    std::fs::rename(&tmp, path)
}

//! `qal` command line. Every output is JSON on stdout, except `fmt` which prints canonical text.
//! Options may come before or after the file or name they apply to.
//!
//! Files (`<file>` ends in `.qal` or contains a `/`):
//!   qal check <file>                                 -> {"ok":true} | {"diagnostics":[...]}
//!   qal fmt <file>                                   -> canonical text
//! The project's store (`.qal/store.db` in the current directory or a parent):
//!   qal init                                         -> {"ok":true,"store":"<path>"}
//!   qal define <file> [--agent <name>]               -> {"defined":[{name,kind,hash,status,old_hash?}]} | {"diagnostics":[...]}
//!   qal view <name|#hash>...                         -> {"views":[{name,kind,hash,signature,effects,text,deps}]}
//!   qal query [--name <prefix>] [--type <pattern>] [--uses <name|#hash>]
//!                                                    -> {"results":[{name,kind,hash,signature,effects}]}
//!   qal rename <old> <new> [--agent <name>]          -> {"renamed":{name,kind,hash}}
//!   qal history <name>                               -> {"history":[{action,name,from_name?,to_name?,old_hash?,new_hash,agent,at}]}
//!   qal build <name>                                 -> {"built":{name,hash,wasm,manifest,effects,bytes}} (paths relative to the project)
//! Running code from a file or from the store (`<target>` is a file or a name):
//!   qal call <file> [--allow <spec>] <fn> [args..]   -> {"ok":<value>,"stdout":".."} | {"error":{...},"stdout":".."} | {"diagnostics":[...]}
//!   qal call <fn> [--allow <spec>] [args..]          (store)
//!   qal test <file> | qal test [<name>...]           -> {"tests":[...],"passed":n,"failed":m}
//!   qal run <file> [--allow <spec>] [--] [args..]    -> {"exit_code":n,"stdout":".."} | {"error":{...},"stdout":".."} | {"diagnostics":[...]}
//!   qal run <name> [--allow <spec>] [--] [args..]    (store; `<name>` is any `fn(List[Str]) -> Int`)
//!
//! `<spec>` grants effects: `io`, `time`, `rand`, `fs:<dir>` (comma-separated, `--allow` repeatable).
//! `--agent` names who made a change in the history (default `cli`).
//! Exit codes: 0 success; for `run` the program's exit code (1 if outside 0..=255);
//! 1 diagnostics / runtime error / failed tests; 2 usage or I/O error (also: no or unreadable store).

use qal_cli::ops::{self, CallArgs, Ctx, Reply, Source};
use qal_cli::{is_file, permissions, split_args, Split};
use qal_store::Query;
use std::io::Write;
use std::process::ExitCode;

const USAGE: &str = "usage: qal <check|fmt> <file>\n       \
                     qal init | define <file> [--agent <name>] | view <name>... | rename <old> <new> [--agent <name>] | history <name> | build <name>\n       \
                     qal query [--name <prefix>] [--type <pattern>] [--uses <name>]\n       \
                     qal call <file> [--allow <spec>] <fn> [args...] | call <fn> [--allow <spec>] [args...]\n       \
                     qal test [--allow <spec>] [<file> | <name>...]\n       \
                     qal run <file|name> [--allow <spec>] [--] [args...]";

fn usage() -> ExitCode {
    bad_usage(USAGE)
}

fn bad_usage(message: &str) -> ExitCode {
    let _ = writeln!(std::io::stderr(), "{message}");
    ExitCode::from(2)
}

/// Prints the reply as one JSON line. A closed or failing stdout is not an error worth a panic:
/// the exit code still tells the result.
fn emit(reply: Reply) -> ExitCode {
    let line = serde_json::to_string(&reply.out).unwrap_or_else(|e| format!("{{\"diagnostics\":[{{\"code\":\"E0601\",\"kind\":\"store_error\",\"def\":\"\",\"path\":\"\",\"message\":\"cannot serialize the output: {e}\",\"hints\":[]}}]}}"));
    let mut out = std::io::stdout().lock();
    let _ = writeln!(out, "{line}").and_then(|_| out.flush());
    ExitCode::from(reply.code)
}

fn main() -> ExitCode {
    // Arguments that are not valid UTF-8 are converted lossily instead of panicking.
    let args: Vec<String> = std::env::args_os().skip(1).map(|a| a.to_string_lossy().into_owned()).collect();
    let Some(cmd) = args.first() else {
        return usage();
    };
    let rest = &args[1..];
    match cmd.as_str() {
        "check" | "fmt" => file_command(cmd, rest),
        "init" | "define" | "view" | "query" | "rename" | "history" | "build" => store_command(cmd, rest),
        "call" | "test" | "run" => run_command(cmd, rest),
        _ => usage(),
    }
}

fn read(file: &str) -> Result<String, ExitCode> {
    std::fs::read_to_string(file).map_err(|e| bad_usage(&format!("cannot read {file}: {e}")))
}

fn split(args: &[String], options: &[&str], repeatable: &[&str], targets: &dyn Fn(&[String]) -> usize) -> Result<Split, ExitCode> {
    split_args(args, options, repeatable, targets).map_err(|e| bad_usage(&e))
}

fn all(_: &[String]) -> usize {
    usize::MAX
}

fn ctx() -> Result<Ctx, ExitCode> {
    Ctx::cli().map_err(|d| emit(Reply::diagnostics(d)))
}

fn file_command(cmd: &str, args: &[String]) -> ExitCode {
    let s = match split(args, &[], &[], &all) {
        Ok(s) => s,
        Err(code) => return code,
    };
    let [file] = s.targets.as_slice() else {
        return usage();
    };
    let src = match read(file) {
        Ok(s) => s,
        Err(code) => return code,
    };
    if cmd == "check" {
        return emit(ops::check(&src));
    }
    match qal_text::parse_program(&src) {
        Ok(p) => {
            let mut out = std::io::stdout().lock();
            let _ = write!(out, "{}", qal_text::print_program(&p)).and_then(|_| out.flush());
            ExitCode::SUCCESS
        }
        Err(d) => emit(Reply::diagnostics(vec![d])),
    }
}

fn store_command(cmd: &str, args: &[String]) -> ExitCode {
    let options: &[&str] = match cmd {
        "define" | "rename" => &["agent"],
        "query" => &["name", "type", "uses"],
        _ => &[],
    };
    // Validate the arguments before touching the store.
    let s = match split(args, options, &[], &all) {
        Ok(s) => s,
        Err(code) => return code,
    };
    let agent = s.one("agent").unwrap_or("cli");
    let targets = s.targets.as_slice();
    match (cmd, targets) {
        ("init", []) => match std::env::current_dir() {
            Ok(dir) => emit(ops::init(&dir)),
            Err(e) => bad_usage(&format!("no current directory: {e}")),
        },
        ("define", [file]) => {
            let src = match read(file) {
                Ok(s) => s,
                Err(code) => return code,
            };
            match ctx() {
                Ok(c) => emit(ops::define(&c, &src, agent)),
                Err(code) => code,
            }
        }
        ("view", names) if !names.is_empty() => with_ctx(|c| ops::view(c, names)),
        ("query", []) => {
            let q = Query { name: s.one("name").map(str::to_string), type_pattern: s.one("type").map(str::to_string), uses: s.one("uses").map(str::to_string) };
            with_ctx(|c| ops::query(c, &q))
        }
        ("rename", [old, new]) => with_ctx(|c| ops::rename(c, old, new, agent)),
        ("history", [name]) => with_ctx(|c| ops::history(c, name)),
        ("build", [name]) => with_ctx(|c| ops::build(c, name)),
        _ => usage(),
    }
}

fn with_ctx(f: impl FnOnce(&Ctx) -> Reply) -> ExitCode {
    match ctx() {
        Ok(c) => emit(f(&c)),
        Err(code) => code,
    }
}

fn run_command(cmd: &str, args: &[String]) -> ExitCode {
    // Targets: `call` needs a file and a function, or a stored function; `run` one file or name;
    // `test` one file or any number of names (and no program arguments).
    let targets = |t: &[String]| match cmd {
        "call" if t.first().is_some_and(|f| is_file(f)) => 2,
        "test" => usize::MAX,
        _ => 1,
    };
    let s = match split(args, &["allow"], &["allow"], &targets) {
        Ok(s) => s,
        Err(code) => return code,
    };
    let perms = match permissions(&s) {
        Ok(p) => p,
        Err(e) => return bad_usage(&e),
    };
    let from_file = s.targets.first().is_some_and(|t| is_file(t));
    if cmd == "test" && (!s.rest.is_empty() || (from_file && s.targets.len() > 1) || s.targets.iter().skip(1).any(|t| is_file(t))) {
        return usage();
    }
    if cmd != "test" && s.targets.len() < targets(&s.targets) {
        return usage();
    }
    let text = if from_file {
        match read(&s.targets[0]) {
            Ok(src) => Some(src),
            Err(code) => return code,
        }
    } else {
        None
    };
    let source = match &text {
        Some(src) => Source::Text(src),
        None => Source::Store,
    };
    let c = match ctx() {
        Ok(c) => c,
        Err(code) => return code,
    };
    emit(match cmd {
        "test" => ops::test(&c, &source, perms, if from_file { &[] } else { &s.targets }),
        "call" => {
            let name = if from_file { &s.targets[1] } else { &s.targets[0] };
            ops::call(&c, &source, perms, name, CallArgs::Strings(&s.rest))
        }
        _ => {
            let name = if from_file { "main" } else { s.targets[0].as_str() };
            ops::run(&c, &source, perms, name, &s.rest)
        }
    })
}

    stdout: BufReader<ChildStdout>,

    fn start() -> Client {
        let root = std::env::temp_dir().join(format!("qal-mcp-test-{}-{}", std::process::id(), NEXT.fetch_add(1, Ordering::SeqCst)));
        let _ = std::fs::remove_dir_all(&root);

        stdin.write_all(line).unwrap();
        stdin.write_all(b"\n").unwrap();

    let r = c.read();

    c.send_raw(br#"{"jsonrpc":"2.0","id":8,"method":"ping","params":[1]}"#);
    assert_eq!(c.read()["error"]["code"], -32602);
    // Unknown notifications and responses are ignored; blank lines too.
    c.send_raw(br#"{"jsonrpc":"2.0","method":"notifications/whatever","params":{}}"#);
    c.send_raw(br#"{"jsonrpc":"2.0","id":99,"result":{}}"#);

    let r = c.request("tools/call", json!({"name": "qal_view", "arguments": "x"}));

QAL language reference. Code lives in a checked, content-addressed store: you add or replace definitions with qal_define (never files). Only code that parses and type-checks is stored; every error is a JSON diagnostic with `path` (place in the definition) and `hints`.

  type Point = { x: Int, y: Int }                  record: Point { x: 1, y: 2 }, p.x
  type Shape = Circle(Int) | Rect(Int, Int) | Dot   enum: Circle(3), Dot
  fn area(s: Shape) -> Int = match s { Circle(r) => 3 * r * r, Rect(w, h) => w * h, Dot => 0 }
  test area_rect = area(Rect(2, 3)) == 6           test: pure Bool expression
  fn main(args: List[Str]) -> Int !io = { print("hi"); 0 }   entry point; result = exit code
Every parameter and result is typed. fn/test names start lowercase, type and variant names uppercase.

Types: Int (64-bit; overflow and division by zero are runtime errors), Float, Bool, Unit (value `()`), Str, List[T], Option[T] = Some(x) | None, Result[T, E] = Ok(x) | Err(e), fn(A) -> B !e. No null, exceptions, implicit conversions, user generics, closures or loops: recurse (a call in tail position is a loop; a fn with `ens` makes no tail calls), and pass named functions as values: map(xs, double). Built-ins are not values: wrap them (fn show(n: Int) -> Str = from_int(n)).

Expressions (everything is an expression, there are no statements):
  let x = e in body     let x: T = e in body     if c then a else b   (else is required)

  { a; b; c }   sequence: a and b must be Unit (e.g. print(..)); the value is c. A `let` inside one item ends at

  "text"  escapes \n \t \r \0 \\ \" \u{1F600}

  / truncates toward zero; % has the sign of the left operand.
Effects: a fn that uses the system declares it after the result type and callers declare the union:
  !io print, read_line   !fs read_file, write_file   !time now_ms   !rand rand_int.  Tests and contracts are pure.
Contracts: fn sqrt_floor(n: Int) -> Int req n >= 0 ens r * r <= n = ...   (`r` is the result; checked at run time)

Built-ins (indices count characters; ranges are half-open):

  Sys  print(s) !io (writes s and a newline)  read_line() -> Option[Str] !io (next line without its `\n` or `\r\n`; None at end)

  to_int accepts an optional sign and digits only (no spaces: trim first). Deep non-tail recursion can overflow the stack.

Store rules: defining an existing name replaces it. Same signature: everything using it is relinked and re-checked automatically. Changed signature: rejected (`signature_change`, lists `dependents`) unless the same call also redefines those dependents. A name keeps its kind (fn, test, type). //! `qal mcp`: a Model Context Protocol server over stdio (spec §9), implemented directly on
//! JSON-RPC 2.0 with serde_json.
//!
//! Transport: one JSON-RPC message per line on stdin, one response per line on stdout (nothing
//! else is ever written to stdout; diagnostics of the server itself go to stderr). Requests are
//! answered one at a time, in order.
//!
//! Protocol eras (both served by one process):
//! - legacy (`initialize` handshake, versions in [`LEGACY_VERSIONS`]): `initialize`,
//!   `notifications/initialized`, `ping`, `tools/list`, `tools/call`;
//! - modern ([`MODERN_VERSION`], stateless): every request carries
//!   `_meta["io.modelcontextprotocol/protocolVersion"]` and `.../clientCapabilities`;
//!   `server/discover`, `ping`, `tools/list`, `tools/call`; results carry `resultType`.
//!
//! Robustness: messages over [`MAX_MESSAGE_BYTES`] are rejected without being buffered, malformed
//! JSON or JSON-RPC is an error response (never a crash), every program run has a wall-clock
//! timeout, a fuel budget and a memory limit, captured output is cut to [`MAX_STDOUT_BYTES`], and a
//! panic inside a tool (a bug) is caught and answered as an internal error.

use crate::ops::{self, CallArgs, Ctx, Reply, Source, StoreAt};
use qal_core::diag::Diagnostic;
use qal_run::Permissions;
use qal_store::Query;
use serde::Serialize;
use serde_json::{json, Map, Value as J};
use std::io::{BufRead, Write};
use std::panic::{catch_unwind, AssertUnwindSafe};
use std::path::{Path, PathBuf};
use std::time::Duration;

/// Initialization-based protocol versions, newest first.
pub const LEGACY_VERSIONS: [&str; 4] = ["2025-11-25", "2025-06-18", "2025-03-26", "2024-11-05"];
/// The stateless protocol version (per-request `_meta`).
pub const MODERN_VERSION: &str = "2026-07-28";
/// Longest accepted message (one line), in bytes.
pub const MAX_MESSAGE_BYTES: usize = 4 << 20;
/// Longest accepted `source` of `qal_define`, in bytes.
pub const MAX_SOURCE_BYTES: usize = 1 << 20;
/// Wall-clock limit of one program execution.
pub const RUN_TIMEOUT: Duration = Duration::from_secs(10);
/// Wall-clock budget for the tests of one `qal_test` call.
pub const TEST_BUDGET: Duration = Duration::from_secs(30);
/// Captured program output returned to the agent, in bytes.
pub const MAX_STDOUT_BYTES: usize = 64 << 10;
/// Largest tool result (its JSON text), in bytes; a larger one is replaced by `result_too_large`.
pub const MAX_RESULT_BYTES: usize = 4 << 20;

const META_VERSION: &str = "io.modelcontextprotocol/protocolVersion";
const META_CAPABILITIES: &str = "io.modelcontextprotocol/clientCapabilities";
const META_CLIENT: &str = "io.modelcontextprotocol/clientInfo";
const META_SERVER: &str = "io.modelcontextprotocol/serverInfo";

const PARSE_ERROR: i64 = -32700;
const INVALID_REQUEST: i64 = -32600;
const METHOD_NOT_FOUND: i64 = -32601;
const INVALID_PARAMS: i64 = -32602;
const INTERNAL_ERROR: i64 = -32603;
const UNSUPPORTED_VERSION: i64 = -32022;

/// The compact language reference (≤ 1 page), part of `qal_define`'s description.
pub const REFERENCE: &str = include_str!("reference.md");

const INSTRUCTIONS: &str = "QAL is a programming language for AI agents. Code lives in a checked, content-addressed store in this project \
(.qal/store.db), not in files: write it with qal_define (its description is the language reference), test it with qal_test, run it with \
qal_run (entry point main(args: List[Str]) -> Int) or qal_call (any function). Every result is JSON; errors are diagnostics with a path and hints.";

/// A JSON-RPC error.
struct RpcError {
    code: i64,
    message: String,
    data: Option<J>,
}

fn rpc(code: i64, message: impl Into<String>) -> RpcError {
    RpcError { code, message: message.into(), data: None }
}

/// How a request is served: the legacy (session) or the modern (stateless) protocol.
#[derive(Clone, Copy, PartialEq)]
enum Era {
    Legacy,
    Modern,
}

pub struct Server {
    root: PathBuf,
    /// Client name from `initialize` (legacy), used as the default agent name.
    client: Option<String>,
}

#[derive(Serialize)]
struct Response<'a, R: Serialize> {
    jsonrpc: &'static str,
    id: &'a J,
    result: R,
}

#[derive(Serialize)]
struct ErrorBody<'a> {
    code: i64,
    message: &'a str,
    #[serde(skip_serializing_if = "Option::is_none")]
    data: &'a Option<J>,
}

#[derive(Serialize)]
struct ErrorResponse<'a> {
    jsonrpc: &'static str,
    id: &'a J,
    error: ErrorBody<'a>,
}

#[derive(Serialize)]
struct Text {
    #[serde(rename = "type")]
    kind: &'static str,
    text: String,
}

/// A `tools/call` result: the operation's JSON as text (for clients that only read `content`) and
/// as `structuredContent`.
#[derive(Serialize)]
#[serde(rename_all = "camelCase")]
struct ToolResult<'a> {
    #[serde(skip_serializing_if = "Option::is_none")]
    result_type: Option<&'static str>,
    content: [Text; 1],
    structured_content: &'a ops::Output,
    is_error: bool,
    #[serde(rename = "_meta", skip_serializing_if = "Option::is_none")]
    meta: Option<J>,
}

fn server_info() -> J {
    json!({"name": "qal", "title": "QAL", "version": env!("CARGO_PKG_VERSION")})
}

fn to_line<T: Serialize>(v: &T) -> String {
    serde_json::to_string(v).unwrap_or_else(|e| {
        format!("{{\"jsonrpc\":\"2.0\",\"id\":null,\"error\":{{\"code\":{INTERNAL_ERROR},\"message\":\"cannot serialize the response: {}\"}}}}", e.to_string().replace(['"', '\\'], "'"))
    })
}

fn error_line(id: &J, e: &RpcError) -> String {
    to_line(&ErrorResponse { jsonrpc: "2.0", id, error: ErrorBody { code: e.code, message: &e.message, data: &e.data } })
}

impl Server {
    pub fn new(root: &Path) -> std::io::Result<Server> {
        let root = root.canonicalize()?;
        if !root.is_dir() {
            return Err(std::io::Error::other(format!("{} is not a directory", root.display())));
        }
        Ok(Server { root, client: None })
    }

    pub fn root(&self) -> &Path {
        &self.root
    }

    /// Handles one message; returns the response line, or None for notifications and responses.
    pub fn handle(&mut self, line: &[u8]) -> Option<String> {
        match catch_unwind(AssertUnwindSafe(|| self.handle_inner(line))) {
            Ok(r) => r,
            Err(p) => Some(error_line(&J::Null, &rpc(INTERNAL_ERROR, format!("internal error: {}", panic_message(&p))))),
        }
    }

    fn handle_inner(&mut self, line: &[u8]) -> Option<String> {
        let msg: J = match serde_json::from_slice(line) {
            Ok(m) => m,
            Err(e) => return Some(error_line(&J::Null, &rpc(PARSE_ERROR, format!("parse error: {e}")))),
        };
        let Some(obj) = msg.as_object() else {
            let what = if msg.is_array() { "batches are not supported" } else { "a message must be a JSON object" };
            return Some(error_line(&J::Null, &rpc(INVALID_REQUEST, what)));
        };
        // MCP ids are strings or integers; other numbers could not be echoed exactly.
        let id = match obj.get("id") {
            None => None,
            Some(id @ J::String(_)) => Some(id.clone()),
            Some(id @ J::Number(n)) if n.is_i64() || n.is_u64() => Some(id.clone()),
            Some(_) => return Some(error_line(&J::Null, &rpc(INVALID_REQUEST, "`id` must be a string or an integer"))),
        };
        if obj.get("jsonrpc").and_then(J::as_str) != Some("2.0") {
            return Some(error_line(id.as_ref().unwrap_or(&J::Null), &rpc(INVALID_REQUEST, "`jsonrpc` must be \"2.0\"")));
        }
        let Some(method) = obj.get("method").and_then(J::as_str) else {
            // A response to a request we never sent (this server sends none): ignore it.
            if obj.contains_key("result") || obj.contains_key("error") {
                return None;
            }
            return Some(error_line(id.as_ref().unwrap_or(&J::Null), &rpc(INVALID_REQUEST, "`method` must be a string")));
        };
        let empty = Map::new();
        let params = match obj.get("params") {
            None => &empty,
            Some(J::Object(p)) => p,
            Some(_) => return id.map(|id| error_line(&id, &rpc(INVALID_PARAMS, "`params` must be an object"))),
        };
        // Notifications (`initialized`, `cancelled`, ...) need no answer; requests run to completion.
        let id = id?;
        Some(match self.request(method, params) {
            Ok(line) => line(&id),
            Err(e) => error_line(&id, &e),
        })
    }

    /// The era of a request from its `_meta`, validating the modern fields.
    fn era(params: &Map<String, J>) -> Result<Era, RpcError> {
        let meta = params.get("_meta").and_then(J::as_object);
        let Some(version) = meta.and_then(|m| m.get(META_VERSION)) else {
            return Ok(Era::Legacy);
        };
        let supported = || {
            let mut all = vec![MODERN_VERSION];
            all.extend(LEGACY_VERSIONS);
            all
        };
        match version.as_str() {
            Some(MODERN_VERSION) => {}
            Some(v) if LEGACY_VERSIONS.contains(&v) => return Ok(Era::Legacy),
            _ => {
                let mut e = rpc(UNSUPPORTED_VERSION, "Unsupported protocol version");
                e.data = Some(json!({"supported": supported(), "requested": version}));
                return Err(e);
            }
        }
        if !meta.is_some_and(|m| m.get(META_CAPABILITIES).is_some_and(J::is_object)) {
            return Err(rpc(INVALID_PARAMS, format!("`_meta` must contain `{META_CAPABILITIES}` (an object)")));
        }
        Ok(Era::Modern)
    }

    /// Dispatches a request; the result is a function from the id to the response line.
    #[allow(clippy::type_complexity)]
    fn request(&mut self, method: &str, params: &Map<String, J>) -> Result<Box<dyn FnOnce(&J) -> String>, RpcError> {
        let era = Self::era(params)?;
        let finish = move |mut result: Map<String, J>| -> Box<dyn FnOnce(&J) -> String> {
            if era == Era::Modern {
                result.insert("resultType".into(), J::from("complete"));
                result.insert("_meta".into(), json!({ META_SERVER: server_info() }));
            }
            Box::new(move |id: &J| to_line(&Response { jsonrpc: "2.0", id, result: J::Object(result) }))
        };
        let object = |v: J| match v {
            J::Object(m) => m,
            _ => Map::new(),
        };
        match method {
            "initialize" => {
                let requested = params.get("protocolVersion").and_then(J::as_str).unwrap_or("");
                let version = if LEGACY_VERSIONS.contains(&requested) { requested } else { LEGACY_VERSIONS[0] };
                self.client = params.get("clientInfo").and_then(|c| c.get("name")).and_then(J::as_str).map(str::to_string);
                Ok(finish(object(json!({
                    "protocolVersion": version,
                    "capabilities": {"tools": {"listChanged": false}},
                    "serverInfo": server_info(),
                    "instructions": INSTRUCTIONS,
                }))))
            }
            "server/discover" => {
                if era != Era::Modern {
                    return Err(rpc(INVALID_PARAMS, format!("`server/discover` needs `_meta` with `{META_VERSION}` and `{META_CAPABILITIES}`")));
                }
                let mut versions = vec![MODERN_VERSION];
                versions.extend(LEGACY_VERSIONS);
                Ok(finish(object(json!({
                    "supportedVersions": versions,
                    "capabilities": {"tools": {"listChanged": false}},
                    "instructions": INSTRUCTIONS,
                }))))
            }
            "ping" => Ok(finish(Map::new())),
            "tools/list" => Ok(finish(object(json!({ "tools": tools() })))),
            "tools/call" => {
                let Some(name) = params.get("name").and_then(J::as_str) else {
                    return Err(rpc(INVALID_PARAMS, "`name` must be a string"));
                };
                let empty = Map::new();
                let args = match params.get("arguments") {
                    None | Some(J::Null) => &empty,
                    Some(J::Object(a)) => a,
                    Some(_) => return Err(rpc(INVALID_PARAMS, "`arguments` must be an object")),
                };
                if !TOOL_NAMES.contains(&name) {
                    return Err(rpc(INVALID_PARAMS, format!("Unknown tool: {name}")));
                }
                let client = match era {
                    Era::Modern => params.get("_meta").and_then(|m| m.get(META_CLIENT)).and_then(|c| c.get("name")).and_then(J::as_str).map(str::to_string),
                    Era::Legacy => self.client.clone(),
                };
                let mut reply = match catch_unwind(AssertUnwindSafe(|| self.call_tool(name, args, client.as_deref()))) {
                    Ok(r) => r,
                    Err(p) => return Err(rpc(INTERNAL_ERROR, format!("internal error in {name}: {}", panic_message(&p)))),
                };
                let modern = era == Era::Modern;
                let line = move |id: &J, reply: &Reply| {
                    let result = ToolResult {
                        result_type: modern.then_some("complete"),
                        content: [Text { kind: "text", text: to_line(&reply.out) }],
                        structured_content: &reply.out,
                        is_error: reply.is_error(),
                        meta: modern.then(|| json!({ META_SERVER: server_info() })),
                    };
                    to_line(&Response { jsonrpc: "2.0", id, result })
                };
                // The whole response counts: the text and the structured copy of the same JSON.
                let size = line(&J::Null, &reply).len();
                if size > MAX_RESULT_BYTES {
                    let d = Diagnostic::new("E0702", "result_too_large", "", "", format!("the result of {name} is {size} bytes of JSON, more than {MAX_RESULT_BYTES}"))
                        .hint("return or print less data, e.g. a summary or a prefix");
                    reply = Reply::diagnostics(vec![d]);
                }
                Ok(Box::new(move |id: &J| line(id, &reply)))
            }
            _ => Err(rpc(METHOD_NOT_FOUND, format!("method not found: {method}"))),
        }
    }

    fn ctx(&self, stdin: Option<String>) -> Ctx {
        Ctx {
            store: StoreAt::Root(self.root.clone()),
            // Never the process's stdin: that is the protocol channel.
            stdin: Some(stdin.unwrap_or_default().into_bytes()),
            timeout: Some(RUN_TIMEOUT),
            test_budget: Some(TEST_BUDGET),
            max_stdout: Some(MAX_STDOUT_BYTES),
        }
    }

    fn call_tool(&self, name: &str, args: &Map<String, J>, client: Option<&str>) -> Reply {
        let mut reply = match self.tool(name, args, client) {
            Ok(r) => r,
            Err(message) => Reply::diagnostics(vec![Diagnostic::new("E0701", "bad_arguments", "", "", message).hint(format!("see the input schema of `{name}` in tools/list"))]),
        };
        if let Some(e) = &mut reply.out.error {
            for h in &mut e.hints {
                *h = allow_hint(h);
            }
        }
        reply
    }

    fn tool(&self, name: &str, args: &Map<String, J>, client: Option<&str>) -> Result<Reply, String> {
        let a = Args::new(name, args)?;
        let agent = |a: &Args| -> Result<String, String> {
            Ok(match a.string("agent")? {
                Some(s) if s.is_empty() || s.chars().count() > 64 || s.chars().any(invisible) => return Err("`agent` must be 1 to 64 characters without control or formatting characters".into()),
                Some(s) => s,
                None => match client {
                    Some(c) => format!("mcp:{}", c.chars().filter(|c| !invisible(*c)).take(48).collect::<String>()),
                    None => "mcp".into(),
                },
            })
        };
        let ctx = self.ctx(a.string("stdin")?);
        let perms = |a: &Args| -> Result<Permissions, String> { Permissions::parse_in(&a.strings("allow")?.unwrap_or_default(), &self.root) };
        Ok(match name {
            "qal_define" => {
                let src = a.required("source")?;
                if src.len() > MAX_SOURCE_BYTES {
                    return Err(format!("`source` is longer than {MAX_SOURCE_BYTES} bytes; define the code in several calls"));
                }
                ops::define(&ctx, &src, &agent(&a)?)
            }
            "qal_view" => {
                let names = a.strings("names")?.unwrap_or_default();
                if names.is_empty() {
                    return Err("`names` must list at least one name or `#<hash>`".into());
                }
                ops::view(&ctx, &names)
            }
            "qal_query" => ops::query(&ctx, &Query { name: a.string("name")?, type_pattern: a.string("type")?, uses: a.string("uses")? }),
            "qal_test" => ops::test(&ctx, &Source::Store, Permissions::default(), &a.strings("names")?.unwrap_or_default()),
            "qal_run" => {
                let entry = a.string("entry")?.unwrap_or_else(|| "main".into());
                let perms = perms(&a)?;
                ops::run(&ctx, &Source::Store, perms, &entry, &a.strings("args")?.unwrap_or_default())
            }
            "qal_call" => {
                let f = a.required("fn")?;
                let perms = perms(&a)?;
                let values = match a.get("args") {
                    None => Vec::new(),
                    Some(J::Array(xs)) => xs.clone(),
                    Some(_) => return Err("`args` must be an array of JSON values".into()),
                };
                ops::call(&ctx, &Source::Store, perms, &f, CallArgs::Json(&values))
            }
            "qal_build" => ops::build(&ctx, &a.required("entry")?),
            "qal_rename" => ops::rename(&ctx, &a.required("old")?, &a.required("new")?, &agent(&a)?),
            "qal_history" => ops::history(&ctx, &a.required("name")?),
            other => return Err(format!("unknown tool `{other}`")),
        })
    }
}

/// Characters that do not show (controls, zero-width and bidirectional formatting): they could make a
/// recorded agent name display as something else.
fn invisible(c: char) -> bool {
    // Controls plus the Unicode format characters (general category Cf, Unicode 15).
    c.is_control()
        || matches!(
            c,
            '\u{AD}'
                | '\u{600}'..='\u{605}'
                | '\u{61C}'
                | '\u{6DD}'
                | '\u{70F}'
                | '\u{890}'..='\u{891}'
                | '\u{8E2}'
                | '\u{180E}'
                | '\u{200B}'..='\u{200F}'
                | '\u{202A}'..='\u{202E}'
                | '\u{2060}'..='\u{2064}'
                | '\u{2066}'..='\u{206F}'
                | '\u{FEFF}'
                | '\u{FFF9}'..='\u{FFFB}'
                | '\u{110BD}'
                | '\u{110CD}'
                | '\u{13430}'..='\u{1343F}'
                | '\u{1BCA0}'..='\u{1BCA3}'
                | '\u{1D173}'..='\u{1D17A}'
                | '\u{E0001}'
                | '\u{E0020}'..='\u{E007F}'
        )
}

/// The runtime's permission hint names the CLI flag (`grant them with `--allow io,fs:<dir>``); an
/// agent grants effects with the `allow` argument instead.
fn allow_hint(hint: &str) -> String {
    for prefix in ["grant them with `--allow ", "grant it with `--allow "] {
        if let Some(rest) = hint.strip_prefix(prefix) {
            let spec = rest.trim_end_matches('`');
            let items: Vec<String> = spec.split(',').map(|e| format!("\"{e}\"")).collect();
            return format!("pass `\"allow\": [{}]` to qal_run or qal_call", items.join(", "));
        }
    }
    hint.to_string()
}

/// Tool arguments with schema checks: unknown keys and wrong types are errors.
struct Args<'a> {
    map: &'a Map<String, J>,
}

impl<'a> Args<'a> {
    fn new(tool: &str, map: &'a Map<String, J>) -> Result<Args<'a>, String> {
        let known = tool_params(tool);
        if let Some(k) = map.keys().find(|k| !known.contains(&k.as_str())) {
            return Err(format!("unknown argument `{k}` (`{tool}` takes: {})", known.join(", ")));
        }
        Ok(Args { map })
    }

    fn get(&self, key: &str) -> Option<&J> {
        self.map.get(key).filter(|v| !v.is_null())
    }

    fn string(&self, key: &str) -> Result<Option<String>, String> {
        match self.get(key) {
            None => Ok(None),
            Some(J::String(s)) => Ok(Some(s.clone())),
            Some(_) => Err(format!("`{key}` must be a string")),
        }
    }

    fn required(&self, key: &str) -> Result<String, String> {
        self.string(key)?.ok_or_else(|| format!("`{key}` is required"))
    }

    fn strings(&self, key: &str) -> Result<Option<Vec<String>>, String> {
        match self.get(key) {
            None => Ok(None),
            Some(J::Array(xs)) => xs.iter().map(|x| x.as_str().map(str::to_string).ok_or_else(|| format!("`{key}` must be an array of strings"))).collect::<Result<_, _>>().map(Some),
            Some(_) => Err(format!("`{key}` must be an array of strings")),
        }
    }
}

const TOOL_NAMES: [&str; 9] = ["qal_define", "qal_test", "qal_run", "qal_call", "qal_view", "qal_query", "qal_rename", "qal_history", "qal_build"];

fn tool_params(tool: &str) -> &'static [&'static str] {
    match tool {
        "qal_define" => &["source", "agent"],
        "qal_view" => &["names"],
        "qal_query" => &["name", "type", "uses"],
        "qal_test" => &["names"],
        "qal_run" => &["entry", "args", "stdin", "allow"],
        "qal_call" => &["fn", "args", "stdin", "allow"],
        "qal_build" => &["entry"],
        "qal_rename" => &["old", "new", "agent"],
        "qal_history" => &["name"],
        _ => &[],
    }
}

/// The tool list (deterministic order).
pub fn tools() -> J {
    let s = |d: &str| json!({"type": "string", "description": d});
    let list = |d: &str| json!({"type": "array", "items": {"type": "string"}, "description": d});
    let allow = list("Effects to grant: \"io\", \"time\", \"rand\", \"fs:<dir>\" (a directory inside the project, relative to its root; hidden entries like .git are never reachable). Default: none.");
    let stdin = s("Text that read_line() reads (default: empty).");
    let agent = s("Who makes the change, recorded in the history (default: the MCP client's name).");
    let read_only = json!({"readOnlyHint": true, "openWorldHint": false});
    let writes = json!({"readOnlyHint": false, "destructiveHint": false, "idempotentHint": true, "openWorldHint": false});
    let define = format!(
        "Add or replace QAL definitions (types, functions, tests) in the project's store. Nothing is stored unless all of them parse and type-check together with the stored code; then the result lists each name with its hash and status (added, replaced, unchanged, relinked). Otherwise `diagnostics` say what to fix.\n\n{REFERENCE}"
    );
    json!([
        {"name": "qal_define", "title": "Define QAL code", "description": define, "annotations": writes,
         "inputSchema": {"type": "object", "properties": {"source": s("QAL source text with one or more definitions."), "agent": agent}, "required": ["source"], "additionalProperties": false}},
        {"name": "qal_test", "title": "Run QAL tests", "annotations": read_only,
         "description": "Run the stored tests (all, or the named ones). Result: each test with passed true/false and the runtime error of a failing one, plus passed/failed counts.",
         "inputSchema": {"type": "object", "properties": {"names": list("Test names (default: all tests).")}, "additionalProperties": false}},
        {"name": "qal_run", "title": "Run a QAL program", "annotations": {"readOnlyHint": false, "destructiveHint": false, "openWorldHint": false},
         "description": "Run a stored entry point `fn(List[Str]) -> Int` (default `main`) with string arguments. Result: exit_code and stdout, or a runtime `error` (contract violation, overflow, timeout after 10 s, ...). Effects the program declares must be granted with `allow`.",

/// One message read from the input.
enum Message {
    Line(Vec<u8>),
    /// Longer than the limit; its bytes were skipped up to the next newline.
    TooLong,
    Eof,
}

/// Reads up to the next newline without ever buffering more than `max` bytes.
fn read_message(input: &mut impl BufRead, max: usize) -> std::io::Result<Message> {
    let mut buf = Vec::new();
    let mut too_long = false;
    loop {
        let chunk = match input.fill_buf() {
            Ok(c) => c,
            Err(e) if e.kind() == std::io::ErrorKind::Interrupted => continue,
            Err(e) => return Err(e),
        };
        if chunk.is_empty() {
            return Ok(if too_long {
                Message::TooLong
            } else if buf.is_empty() {
                Message::Eof
            } else {
                Message::Line(buf)
            });
        }
        let (part, done) = match chunk.iter().position(|b| *b == b'\n') {
            Some(i) => (&chunk[..i], Some(i + 1)),
            None => (chunk, None),
        };
        if !too_long && buf.len() + part.len() <= max {
            buf.extend_from_slice(part);
        } else {
            too_long = true;
            buf = Vec::new();
        }
        let used = done.unwrap_or(part.len());
        input.consume(used);
        if done.is_some() {
            return Ok(if too_long { Message::TooLong } else { Message::Line(buf) });
        }
    }
}

/// Serves requests from `input` until it ends, writing one response line per request.
pub fn serve(root: &Path, mut input: impl BufRead, mut output: impl Write) -> std::io::Result<()> {
    let mut server = Server::new(root)?;
    loop {
        let reply = match read_message(&mut input, MAX_MESSAGE_BYTES)? {
            Message::Eof => return Ok(()),
            Message::TooLong => Some(error_line(&J::Null, &rpc(INVALID_REQUEST, format!("message longer than {MAX_MESSAGE_BYTES} bytes")))),
            Message::Line(line) if line.iter().all(u8::is_ascii_whitespace) => None,
            Message::Line(line) => server.handle(&line),
        };
        if let Some(r) = reply {
            output.write_all(r.as_bytes())?;
            output.write_all(b"\n")?;
            output.flush()?;
        }
    }
}

/// `qal mcp`: serves stdin/stdout on a thread with a large stack (the checker and code generator
/// recurse over expressions up to the parser's nesting limit).
pub fn serve_stdio(root: &Path) -> std::io::Result<()> {
    let root = root.to_path_buf();
    let worker = std::thread::Builder::new().name("qal-mcp".into()).stack_size(256 << 20).spawn(move || {
        let stdin = std::io::stdin();
        let stdout = std::io::stdout();
        serve(&root, stdin.lock(), stdout.lock())
    })?;
    match worker.join() {
        Ok(r) => r,
        Err(p) => Err(std::io::Error::other(format!("the server stopped: {}", panic_message(&p)))),
    }
}
