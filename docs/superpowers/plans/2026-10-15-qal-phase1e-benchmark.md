# QAL Phase 1e — Benchmark: Agents in QAL (MCP) vs. Rust Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. **Tasks 1 and 2 are implementer tasks. Task 3 is executed by the controller itself** (the session that runs this plan), because it dispatches the benchmark agents and implementer subagents may not dispatch subagents.

**Goal:** Measure the thesis of spec §1 — an AI-native language makes agents more effective, measured as tokens and iterations per verified-correct solution — with 20 CLI tasks solved by Claude Code subagents in QAL (through the MCP server) and in Rust (files + cargo), verified against hidden tests, and reported in `bench/report.md`.

**Architecture:** Task 1 adds the built-ins the roadmap requires before 1e (`read_all`, Str ordering and `sort_str`, `char_code`/`from_char_code`, `to_upper`/`to_lower`/`replace`/`index_of`) to checker, wasm runtime and host. Task 2 adds `bench/`: a deterministic generator that writes 20 task statements and their hidden tests from Python oracles, reference solutions in QAL and Rust that pass them, `check.py` (verifies either arm the same way), `qalc.py` (the MCP stdio client the QAL agent uses), equal prompts for both arms, `run.py` (schedule, work dirs, check + transcript audit, results) and `report.py`. Task 3 is the measurement procedure the controller follows.

**Tech Stack:** Rust 1.97 (edition 2021) workspace `qal/` (no dependency changes; `qal/Cargo.lock` unchanged); Python 3.11 standard library only for `bench/`; Rust solutions use std only and build `--offline`.

**Spec:** `docs/superpowers/specs/2026-10-15-qal-design.md` §1 (thesis and metric), §11 (benchmark), §12 (success criteria 1, 3, 6). Roadmap: `docs/superpowers/specs/2026-10-15-qal-roadmap.md` (row 1e, "Pflicht vor 1e"). Previous sub-plan: `docs/superpowers/plans/2026-10-15-qal-phase1d-mcp-server.md`.

**Sub-plan context:** Phase 1 is delivered as five sub-plans: 1a core pipeline, 1b data and effects, 1c store, 1d MCP server (all done), **1e benchmark (this plan)**. Spec §11 says the agent loop uses the Claude API; the roadmap replaced that with Claude Code subagents ("Keine API-Schlüssel nötig"), which this plan follows.

**How this plan was made:** every file below was first implemented in a scratch copy of the repository with TDD (249 tests passing, zero warnings, clippy restriction lints clean); all 40 reference solutions were verified with `bench/check.py`; a pilot dispatched one subagent per arm on one task with the real prompts and confirmed that dispatch results, transcript audit, check and report capture everything (see Pilot); an independent reviewer attacked the built-ins (bounds, UTF-8, overflow) and the benchmark (fairness, leakage, ambiguity), and the confirmed findings are fixed (see Review). ## Global Constraints

- Workspace `qland/qal/`, branch `Mac`. No dependency changes: `git diff --stat qal/Cargo.lock` stays empty.
- No panic on reachable paths (as in 1d): the clippy restriction-lint command of Task 1 reports nothing. Builds and tests are warning-free.
- Every string in guest memory is valid UTF-8; every runtime helper bounds its memory accesses by the lengths it reads; lengths that could exceed `i32` are computed in `i64` and fail as `out_of_memory`.
- `bench/` uses only the Python 3 standard library and works from any current directory. It never writes into the repository except `bench/tasks/*` (generator), `bench/schedule.json`, `bench/workdirs.json`, `bench/results.jsonl`, `bench/report.md` and `bench/discussion.md` (and Python's `__pycache__`, ignored by `.gitignore`).
- Benchmark agents never see `bench/` (hidden tests, oracles, reference solutions): their work directories are outside the repository, their prompts contain only the task statement, the rules and the tool description, and every transcript is audited.
- Stage only the paths named in each commit step (never `git add -A`; the user's uncommitted `qlang/web/index.html` stays untouched). Do not push.

## Design Decisions

Decided here (the user delegates design decisions); each is reflected in the code below.

1. **Built-in semantics.** `read_all() -> Str !io` returns all remaining standard input unchanged (CR bytes included, invalid UTF-8 replaced by U+FFFD like `read_line`; `""` at the end; after it `read_line` returns `None`). `< <= > >=` accept Int, Float and Str; Str compares bytes, which for UTF-8 is the order of Unicode code points (`"B" < "a" < "é"`). `sort_str(xs)` sorts ascending in that order. `char_code(s) -> Int` is the code point of the first character and requires `s != ""`; `from_char_code(n) -> Str` requires a Unicode scalar value (`0 <= n <= 0x10FFFF`, no surrogate). Violated preconditions are `contract_violation` with the values, like `split(s, "")` — not `Option`, because they are programming errors and the common use (over `chars(s)`) never violates them. `to_upper`/`to_lower` map only ASCII letters (no Unicode case tables in the hand-written runtime; byte length is preserved). `replace(s, from, to)` replaces every non-overlapping occurrence left to right and requires `from != ""`. `index_of(s, sub) -> Option[Int]` is the character index of the first occurrence (`Some(0)` for `""`).
2. **Where they live.** Everything except `read_all` is hand-written WebAssembly in `qal-wasm/src/rt.rs` (fuel-metered, no host trust, same pattern as `split`/`join`); `sort_str` reuses the heapsort of `sort_int` with a `StrCmp` comparator (`Rt::Sift(bool)`, `Rt::ListSort(bool)`). `read_all` is a host function `io.read_all`, appended to `EFFECT_FNS` (the index is reported for a denied call, so existing indices stay). The new names are reserved for built-ins; a store that already defines some of them reports "`replace` is the name of a built-in function" with a `qal_rename` hint, and they can be renamed one at a time (hashes unchanged).
3. **Benchmark tasks are CLI programs.** Both arms solve the same contract: arguments, standard input and (task 10) files in, standard output and exit code out. QAL `test` definitions cannot be the hidden-test interface because Rust has no equivalent, and `qal_call` takes only scalars and lists; so the QAL entry point is `main(args: List[Str]) -> Int`, run with `qal_run` exactly as an agent can (roadmap "Pflicht vor 1e").
4. **Tasks and limits.** 20 tasks covering the spec's list (word count, Roman numerals, CSV sum, binary search, bracket check, bank state machine, tokenizer, evaluator, run-length encoding, file statistics) plus prime factors, unique sorted words, word frequencies, binary search tree, Caesar cipher, anagram groups, word wrap, date difference, base conversion and INI queries. Every statement names its input limits, chosen so that the output always fits in 64 KiB and idiomatic code in either language meets them within QAL's budgets (2·10⁹ instructions, 256 MiB, 10 s; quadratic `push`/`++` around 8 000 elements; recursion around 100 000). Every task has a hidden case at its stated limit, `gen_tests.py` asserts every hidden input against the limits, and the QAL references also pass their large cases at twice the size where the format allows (each runs in well under a second). No task needs anything only one language has.
5. **Hidden tests come from an oracle.** `bench/gen/` holds the statements, the inputs (fixed seeds) and Python oracles; `gen_tests.py` writes `tasks/<id>/task.md` (statement, limits, public examples rendered from the cases marked public, so examples and tests cannot disagree) and `tasks/<id>/tests.json` (all cases with expected stdout and exit code). Three independent implementations (oracle, QAL reference, Rust reference) agree on all 193 cases.
6. **Equal checking.** `check.py` runs both arms on the same cases with a 10 s limit: QAL through `qal_run` on a copy of the agent's store (`--root`) or on a fresh root (`--source`) with `allow ["io"]` (plus `"fs:data"` in task 10, files below the root's `data/`); Rust built with `cargo build --release --offline` in a copy of the project, run in a fresh directory holding the case's files. A case passes on equal exit code and exactly equal stdout (every printed line ends with a newline, as the rules say); truncated QAL output, runtime errors and Rust output over 64 KiB fail.
7. **Equal information.** Both prompts share one "Rules" section byte for byte (`run.py` refuses to prepare a prompt otherwise) and the same task statement. The QAL prompt adds what an MCP client gets from the server (instructions and the nine tool descriptions, including the language reference); the Rust prompt names the toolchain, and its work dir holds only `Cargo.toml` and an empty `src/` (an existing `main.rs` would have to be read before the agent may overwrite it). The QAL prompt also names QAL's instruction and memory budgets. That asymmetry is inherent: the model knows Rust and must learn QAL from the tools; the report counts it.
8. **Transport.** The QAL agent reaches the server through `qalc.py` in its work dir (a copy with the server binary and project root fixed), via its Bash tool: a subagent cannot get a newly registered MCP server without a session restart and the user's approval (see 1d), and Bash is what the Rust agent uses for cargo, so both arms pay a shell round trip per tool use. `qalc.py define` takes source from a heredoc so no source files are needed.
9. **Isolation.** Every dispatch gets a fresh directory with a random name in `$BENCH_WORK` (default `/tmp/qal-bench`), outside the repository (`workdirs.json` maps entries to directories); the QAL server is copied to `$BENCH_WORK/bin`, so nothing an agent sees names the repository. The prompts forbid reading anything outside the work dir, web tools, skills and subagents; `run.py audit` reads the agent's transcript (`~/.claude/projects/**/agent-<id>.jsonl`) and marks a run invalid if it used a tool outside the allowlist (Bash, Read, Write, Edit, MultiEdit, Glob, Grep, TodoWrite, ToolSearch), gave a file tool a path outside its work dir, or named in a Bash command the repository or an absolute, `~`/`$HOME` or `..` path outside its work dir (toolchain prefixes excepted). Heredoc bodies and quoted text with whitespace are not judged: QAL source and test data travel there, and Rust code travels in Write calls that are not judged either. An invalid run is repeated once with a fresh agent and otherwise reported as invalid, never counted.
10. **Measurement.** Per dispatch and per continuation the controller records `subagent_tokens`, `tool_uses` and `duration_ms` from the result's `<usage>` block (the pilot showed they are cumulative per agent: `subagent_tokens` is its final context size, the others count from its start). The audit adds what the transcript knows: API calls, processed tokens (input + cache creation + cache reads + output over all calls), work tool calls by tool, and failed tool calls — any error the toolchain reported: tool errors, `isError: true` from `qalc.py` (diagnostics, runtime errors, failing tests), Rust compile errors, panics and failing `cargo test` — plus whether the agent exceeded the 60-call budget (reported, not invalidating). The transcript's `output_tokens` are those of the first streamed chunk only, so they are not reported.
11. **Iterations.** A run has at most 3 attempts with the same agent: after a failed check the controller continues the agent (SendMessage) with the same message in both arms — how many of how many hidden cases failed, plus a build/define error if any, never case names or inputs. A `GAVE UP` reply gets the same message while attempts remain.
12. **Protocol.** Model `sonnet` for every benchmark agent; 2 runs per task and arm (80 dispatches) in an order shuffled with the fixed seed `qal-1e` (`bench/schedule.json`), so drift over time hits both arms alike; at most 2 agents run at the same time, always one of each arm or of different tasks.
13. **Metrics and winner.** Primary metric: tokens per verified solution = all `subagent_tokens` an arm spent on valid runs (solved or not) / its solved runs; secondary: processed tokens per verified solution, solved runs, first-attempt solves, attempts, tool calls, failed tool calls, wall time. Per task, the arm with the higher share of solved runs wins; at equal shares above zero, fewer mean tokens over solved runs wins unless within 10% (tie); if neither solved a run, there is no winner. The report states threats to validity, and the controller adds `bench/discussion.md` with the interpretation. Spec §12.6: the outcome is a measurement, not a success criterion.

Carried-over items ("Pflicht vor 1e", roadmap) and where they are done: the built-ins (Task 1, Decisions 1–2); hidden tests via `main` + stdin (Task 2, Decision 3); task sizes within the limits (Task 2, Decision 4).

## Review

An independent reviewer (opus) attacked the scratch implementation: out-of-bounds accesses and UTF-8 validity of the hand-written runtime (empty strings, every encoding length, surrogates, huge replacement counts), sorting, `read_all` limits and permissions; and the benchmark for fairness (equal information, leakage of hidden tests or reference solutions, statements that admit a different reading than the oracle, sizes favouring one arm, checking, audit, retry protocol and metrics). Confirmed findings, fixed in the code below:

1. **(major) A store from before 1e that defines two of the new names (e.g. its own `replace` and `to_upper`) was stuck:** every define and test failed with "`replace` is defined more than once", and `qal_rename` refused because the other collision remained (there is no delete). → The diagnostic now says "`replace` is the name of a built-in function" with a hint to `qal_rename` it (`Diagnostic::builtin_name`), and `Store::rename` ignores the other definitions' built-in collisions, so they are renamed one at a time; hashes do not change (Task 1 `definitions_named_like_new_builtins_can_be_renamed_one_by_one`).
2. **(minor) `x < "a"` was rejected when `x`'s type was still unknown** (the left operand defaulted to Int; `"a" < x` worked). → An unknown left operand takes the right operand's type (Task 1 `strings_are_ordered_and_text_builtins_type_check`).
3. **(minor) Reference gaps:** the preconditions of `from_char_code`, `index_of(s, "") == Some(0)`, and that `read_all` replaces invalid UTF-8 → documented in `reference.md` (44 lines).
4. **(major) The checker accepted wrong output:** "missing final newline tolerated" also accepted output lacking a whole final empty line (e.g. an INI value that is empty, or an empty tokenizer line), and contradicted the rule that every printed line ends with a newline. → Output must match exactly (Decision 6; `test_bench.py` `test_output_must_match_exactly`).
5. **(major) The audit invalidated QAL runs for words in their payload:** QAL source and test data travel inside Bash heredocs, so a comment like `# count all solutions` or input `the bench is long` made a run invalid (Rust code goes through Write and was not scanned) — discarding QAL runs biases the totals. → The audit judges only path-like words of a command outside heredocs and whitespace-containing quotes, plus the repository path (Decision 9; `test_payloads_in_heredocs_and_quotes_are_not_violations`).
6. **(major) Reading another run's solution went unnoticed:** work dirs of one run were siblings with predictable names (`run1/06-bank-rust`), `cat ../06-bank-rust/src/main.rs` was not flagged, and the agent's `qalc.py` named the server binary inside the repository. → Every dispatch gets a fresh random directory (`workdirs.json` maps entries to them), the server binary is copied to `$BENCH_WORK/bin`, and any absolute, `~`/`$HOME` or `..` path outside the work dir (except toolchain prefixes) and any tool outside an allowlist is a violation (`test_paths_outside_the_work_dir_are_violations`).
7. **(major, fairness) Stated limits exceeded what the hidden tests checked** and, for some tasks, what idiomatic QAL could meet (brackets at 500 × 3000 characters, expressions of 1000 characters, 200 factorizations near 10^12, 100 KB with 16 000 distinct words), while some allowed outputs beyond 64 KiB. → The limits were restated to sizes both arms can meet and whose output fits (`statements.py`), every task got a hidden case at its stated limit (`limit*` in `cases.py`), `gen_tests.py` asserts every hidden input against the stated limits, the QAL references for brackets (recursive descent instead of a string stack) and word wrap (no quadratic concatenation) were rewritten, every QAL reference also passes its large cases at twice the size except where the format forbids it, and the QAL prompt names the instruction and memory budget.
8. **(minor) `check.py --root` copied only `store.db`** although the store uses WAL → `-wal`/`-shm` are copied too.
9. **(minor) `report.py` carried `first_pass` from an invalid run into the fresh agent's redo** → a record with attempt 1 starts a new summary (`test_last_attempt_counts_and_a_redo_starts_fresh`).
10. **(minor) Failed tool calls were counted asymmetrically** (QAL counted failing tests, Rust did not) → Rust also counts `test result: FAILED`; the audit uses a tool allowlist and flags runs over the 60-call budget (reported, not invalidated) (`test_rust_failures_are_compile_errors_panics_and_failed_tests_only`).
11. **(minor) 08-expr-eval said whitespace may appear "between tokens"** while a hidden case has leading and trailing blanks → "anywhere except inside a number".
12. **(opinion, adopted) Winner rule:** "none" whenever neither arm solved every run lost information → the higher share of solved runs wins, then fewer tokens over solved runs (Decision 13).

Not adopted: making processed tokens the primary metric (the user's protocol names `subagent_tokens`; processed tokens are reported next to it); sandboxing Rust programs at check time (listed as a threat to validity).

def expr_eval():

        op = r.choice(["+", "-", "*", "/", "%", "+", "-"])

        return f"({e})" if r.random() < 0.5 else e

    from oracles import expr_eval as oracle

def parse_atom(t, p):
    if p >= len(t):
        raise Syntax()
    if isinstance(t[p], int):
        return ("num", t[p]), p + 1
    if t[p] == "(":
        v, p = parse_expr(t, p + 1)
        if p >= len(t) or t[p] != ")":
            raise Syntax()
        return v, p + 1

    assert -(2 ** 63) <= v < 2 ** 63, "the tests stay within 64-bit integers"
    return v

def evaluate(e):
    if e[0] == "num":
        return fits(e[1])
    if e[0] == "neg":
        return fits(-evaluate(e[1]))
    _, op, l, r = e
    a, b = evaluate(l), evaluate(r)
    if op == "+":
        return fits(a + b)
    if op == "-":
        return fits(a - b)
    if op == "*":
        return fits(a * b)
    if b == 0:
        raise DivZero()
    return fits(tdiv(a, b) if op == "/" else a - b * tdiv(a, b))

def bst(args, stdin, files):

    root = None  # node = [value, left, right]

    def insert(node, v):
        if node is None:
            return [v, None, None]
        if v < node[0]:
            node[1] = insert(node[1], v)
        elif v > node[0]:
            node[2] = insert(node[2], v)
        return node

    import sys
    sys.setrecursionlimit(100000)
    for v in nums:
        root = insert(root, v)

    def walk(n, order):
        if n is None:
            return []
        l, r = walk(n[1], order), walk(n[2], order)
        return {"in": l + [n[0]] + r, "pre": [n[0]] + l + r, "post": l + r + [n[0]]}[order]

    def height(n):
        return 0 if n is None else 1 + max(height(n[1]), height(n[2]))

    def line(name, xs):
        return " ".join([name] + [str(x) for x in xs])

    ino = walk(root, "in")
    return out([f"size {len(ino)}", f"height {height(root)}", line("inorder", ino), line("preorder", walk(root, "pre")), line("postorder", walk(root, "post"))]), 0

def days_from_civil(y, m, d):
    y -= m <= 2
    era = (y if y >= 0 else y - 399) // 400
    yoe = y - era * 400
    doy = (153 * (m + (-3 if m > 2 else 9)) + 2) // 5 + d - 1

    return era * 146097 + doe

#!/usr/bin/env python3
"""Minimal MCP stdio client for the QAL server (`qal mcp`), used by the benchmark harness and, as a
copy in its work directory, by the agent of the QAL arm.

Usage:
  python3 qalc.py tools                     # server instructions and every tool with its description
  python3 qalc.py call <tool> '<json-args>' # call one tool; prints `isError: ...` and the result JSON
  python3 qalc.py call <tool> -             # the same, JSON arguments read from stdin
  python3 qalc.py define [<file>]           # qal_define with QAL source from <file> or stdin

Each invocation starts a fresh server (`qal mcp --root ROOT`). The project root ROOT (where
.qal/store.db lives) is $QAL_ROOT, else the current directory; the server binary is $QAL_BIN, else
the release build of this repository (`cargo build --release -p qal-cli` in qal/). `run.py prepare`
gives an agent a copy with both fixed.
"""

import json
import os
import subprocess
import sys

HERE = os.path.dirname(os.path.abspath(__file__))
BIN = os.environ.get("QAL_BIN") or os.path.join(os.path.dirname(HERE), "qal", "target", "release", "qal")
ROOT = os.environ.get("QAL_ROOT") or os.getcwd()

class Client:
    """One `qal mcp` server process speaking MCP (initialize handshake, then tools/*)."""

    def __init__(self, root=ROOT, binary=BIN):
        self.p = subprocess.Popen([binary, "mcp", "--root", root], stdin=subprocess.PIPE, stdout=subprocess.PIPE,
                                  stderr=subprocess.DEVNULL, text=True, encoding="utf-8")
        self.next_id = 0
        init = self.request("initialize", {"protocolVersion": "2025-06-18", "capabilities": {},
                                           "clientInfo": {"name": "qal-bench", "version": "1"}})
        self.instructions = init.get("result", {}).get("instructions", "")
        self.send({"jsonrpc": "2.0", "method": "notifications/initialized"})

    def send(self, msg):
        self.p.stdin.write(json.dumps(msg) + "\n")
        self.p.stdin.flush()

    def request(self, method, params):
        self.next_id += 1
        self.send({"jsonrpc": "2.0", "id": self.next_id, "method": method, "params": params})
        line = self.p.stdout.readline()
        if not line:
            raise RuntimeError("the QAL server exited without answering")
        return json.loads(line)

    def tools(self):
        return self.request("tools/list", {})["result"]["tools"]

    def call(self, tool, args):
        """Returns (is_error, result text, structured result) of one tool call."""
        r = self.request("tools/call", {"name": tool, "arguments": args})
        if "error" in r:
            return True, "PROTOCOL ERROR: " + json.dumps(r["error"]), None
        res = r["result"]
        text = "\n".join(c.get("text", "") for c in res.get("content", []))
        return bool(res.get("isError", False)), text, res.get("structuredContent")

    def close(self):
        self.p.stdin.close()
        self.p.wait(timeout=30)

def describe_tools(c):
    out = [f"Server instructions: {c.instructions}\n"]
    for t in c.tools():
        out.append(f"## {t['name']}\n{t.get('description', '')}\ninputSchema: {json.dumps(t.get('inputSchema'))}\n")
    return "\n".join(out)

def main(argv):
    if len(argv) < 2 or argv[1] not in ("tools", "call", "define"):
        print(__doc__.split("\n\n")[1], file=sys.stderr)
        return 2
    c = Client()
    try:
        if argv[1] == "tools":
            print(describe_tools(c))
            return 0
        if argv[1] == "define":
            src = open(argv[2], encoding="utf-8").read() if len(argv) > 2 else sys.stdin.read()
            tool, args = "qal_define", {"source": src}
        else:
            if len(argv) != 4:
                print("usage: qalc.py call <tool> '<json-args>' | -", file=sys.stderr)
                return 2
            tool, raw = argv[2], (sys.stdin.read() if argv[3] == "-" else argv[3])
            try:
                args = json.loads(raw)
            except json.JSONDecodeError as e:
                print(f"invalid JSON arguments: {e}", file=sys.stderr)
                return 2
        is_error, text, _ = c.call(tool, args)
        print("isError:", str(is_error).lower())
        print(text)
        return 0
    finally:
        c.close()

if __name__ == "__main__":
    sys.exit(main(sys.argv))

#!/usr/bin/env python3
"""Verifies a benchmark solution against the hidden tests of its task (bench/tasks/<id>/tests.json).

  python3 bench/check.py qal <task> --root <dir>     # the QAL store of an agent's project root
  python3 bench/check.py qal <task> --source <file>  # QAL source, defined into a fresh project root
  python3 bench/check.py rust <task> <cargo-dir>     # a cargo project (built with --release --offline)
  python3 bench/check.py refs [<task>...]            # every reference solution in both arms
Add --json for one JSON object per check on stdout.

Both arms run the same cases: arguments, standard input, and for file tasks the files created
below a fresh directory (the QAL project root, or the Rust program's working directory). A case
passes if the exit code and stdout are exactly equal (every printed line ends with a newline). Each
run has a 10 s wall-clock limit; the QAL arm runs `main` via the MCP tool `qal_run` with
allow ["io"] (plus "fs:data" for file tasks), exactly as an agent can.
"""

import json
import os
import re
import shutil
import subprocess
import sys
import tempfile

BENCH = os.path.dirname(os.path.abspath(__file__))
REPO = os.path.dirname(BENCH)
sys.path.insert(0, BENCH)
import qalc  # noqa: E402

TIMEOUT = 10
MAX_OUTPUT = 64 << 10

def task_ids():
    return sorted(d for d in os.listdir(os.path.join(BENCH, "tasks")) if re.fullmatch(r"\d\d-[a-z-]+", d))

def load(task):
    path = os.path.join(BENCH, "tasks", task, "tests.json")
    if not os.path.exists(path):
        raise SystemExit(f"unknown task `{task}` (tasks: {', '.join(task_ids())})")
    with open(path, encoding="utf-8") as f:
        return json.load(f)

def write_files(base, files):
    for rel, content in files.items():
        path = os.path.join(base, rel)
        os.makedirs(os.path.dirname(path), exist_ok=True)
        with open(path, "w", encoding="utf-8", newline="") as f:
            f.write(content)

def ensure_qal_binary():
    """Builds the release server unless $QAL_BIN names another one (a no-op when up to date)."""
    if os.environ.get("QAL_BIN"):
        return
    env = {k: v for k, v in os.environ.items() if k != "CARGO_TARGET_DIR"}
    r = subprocess.run(["cargo", "build", "--release", "--quiet", "-p", "qal-cli"], cwd=os.path.join(REPO, "qal"), env=env, capture_output=True, text=True)
    if r.returncode != 0:
        raise SystemExit("building the QAL server failed:\n" + r.stderr[-3000:])

def result(task, arm, cases, failed, error=None):
    return {"task": task, "arm": arm, "passed": len(cases) - len(failed) if error is None else 0, "total": len(cases),
            "failed": failed, "error": error}

def check_qal(task, root=None, source=None):
    spec = load(task)
    cases = spec["cases"]
    fs = "fs" in spec["effects"]
    with tempfile.TemporaryDirectory(prefix="qal-check-") as tmp:
        if root is not None:
            store = os.path.join(root, ".qal", "store.db")
            if not os.path.exists(store):
                return result(task, "qal", cases, [], f"no QAL store in {root}")
            os.makedirs(os.path.join(tmp, ".qal"))
            # The store runs in WAL mode: copy the log too, in case a server did not checkpoint it.
            for suffix in ("", "-wal", "-shm"):
                if os.path.exists(store + suffix):
                    shutil.copy(store + suffix, os.path.join(tmp, ".qal", "store.db" + suffix))
        c = qalc.Client(root=tmp)
        try:
            if source is not None:
                with open(source, encoding="utf-8") as f:
                    is_error, text, _ = c.call("qal_define", {"source": f.read()})
                if is_error:
                    return result(task, "qal", cases, [], "qal_define failed: " + text[:2000])
            failed = []
            for case in cases:
                data = os.path.join(tmp, "data")
                shutil.rmtree(data, ignore_errors=True)
                if fs:
                    os.makedirs(data)
                write_files(tmp, case["files"])
                allow = ["io", "fs:data"] if fs else ["io"]
                _, text, out = c.call("qal_run", {"entry": "main", "args": case["args"], "stdin": case["stdin"], "allow": allow})
                ok = (isinstance(out, dict) and "error" not in out and "diagnostics" not in out and "stdout_truncated" not in out
                      and out.get("exit_code") == case["exit_code"] and out.get("stdout") == case["stdout"])
                if not ok:
                    failed.append(case["name"])
            return result(task, "qal", cases, failed)
        finally:
            c.close()

def check_rust(task, project):
    spec = load(task)
    cases = spec["cases"]
    with tempfile.TemporaryDirectory(prefix="rust-check-") as tmp:
        src = os.path.join(tmp, "project")
        shutil.copytree(project, src, ignore=shutil.ignore_patterns("target", ".git"))
        env = dict(os.environ, CARGO_TARGET_DIR=os.path.join(tmp, "target"), CARGO_TERM_COLOR="never")
        r = subprocess.run(["cargo", "build", "--release", "--offline", "--quiet"], cwd=src, env=env, capture_output=True, text=True)
        if r.returncode != 0:
            return result(task, "rust", cases, [], "cargo build failed: " + r.stderr[-2000:])
        exes = [p for p in os.listdir(os.path.join(tmp, "target", "release")) if os.access(os.path.join(tmp, "target", "release", p), os.X_OK)
                and os.path.isfile(os.path.join(tmp, "target", "release", p))]
        if len(exes) != 1:
            return result(task, "rust", cases, [], f"expected one binary, found {exes}")
        exe = os.path.join(tmp, "target", "release", exes[0])
        failed = []
        for case in cases:
            cwd = os.path.join(tmp, "run")
            shutil.rmtree(cwd, ignore_errors=True)
            os.makedirs(cwd)
            write_files(cwd, case["files"])
            try:
                p = subprocess.run([exe] + case["args"], cwd=cwd, input=case["stdin"].encode(), capture_output=True, timeout=TIMEOUT)
                stdout = p.stdout[:MAX_OUTPUT + 1].decode("utf-8", errors="replace")
                ok = len(p.stdout) <= MAX_OUTPUT and p.returncode == case["exit_code"] and stdout == case["stdout"]
            except subprocess.TimeoutExpired:
                ok = False
            if not ok:
                failed.append(case["name"])
        return result(task, "rust", cases, failed)

def show(res, as_json):
    if as_json:
        print(json.dumps(res))
        return
    status = "PASS" if res["error"] is None and not res["failed"] else "FAIL"
    detail = f" ({res['error']})" if res["error"] else (f": {', '.join(res['failed'])}" if res["failed"] else "")
    print(f"{status} {res['arm']} {res['task']} {res['passed']}/{res['total']}{detail}")

def main(argv):
    as_json = "--json" in argv
    argv = [a for a in argv if a != "--json"]
    if len(argv) >= 2 and argv[1] == "refs":
        ensure_qal_binary()
        ok = True
        for task in argv[2:] or task_ids():
            for res in (check_qal(task, source=os.path.join(BENCH, "solutions", "qal", f"{task}.qal")),
                        check_rust(task, os.path.join(BENCH, "solutions", "rust", task))):
                show(res, as_json)
                ok = ok and res["error"] is None and not res["failed"]
        return 0 if ok else 1
    if len(argv) == 5 and argv[1] == "qal" and argv[3] in ("--root", "--source"):
        ensure_qal_binary()
        res = check_qal(argv[2], **{argv[3][2:]: os.path.abspath(argv[4])})
    elif len(argv) == 4 and argv[1] == "rust":
        res = check_rust(argv[2], os.path.abspath(argv[3]))
    else:
        print(__doc__.split("\n\n")[1], file=sys.stderr)
        return 2
    show(res, as_json)
    return 0 if res["error"] is None and not res["failed"] else 1

if __name__ == "__main__":
    sys.exit(main(sys.argv))

type Sym = { value: Int, text: Str }

fn symbols() -> List[Sym] = [
  Sym { value: 1000, text: "M" }, Sym { value: 900, text: "CM" }, Sym { value: 500, text: "D" }, Sym { value: 400, text: "CD" },
  Sym { value: 100, text: "C" }, Sym { value: 90, text: "XC" }, Sym { value: 50, text: "L" }, Sym { value: 40, text: "XL" },
  Sym { value: 10, text: "X" }, Sym { value: 9, text: "IX" }, Sym { value: 5, text: "V" }, Sym { value: 4, text: "IV" },
  Sym { value: 1, text: "I" }
]

fn roman_from(n: Int, i: Int, acc: Str) -> Str =
  match get(symbols(), i) {
    None => acc,
    Some(s) => if n >= s.value then roman_from(n - s.value, i, acc ++ s.text) else roman_from(n, i + 1, acc),
  }

fn to_roman(n: Int) -> Str req n >= 1 && n <= 3999 = roman_from(n, 0, "")

fn letter_value(c: Str) -> Int =
  match c { "I" => 1, "V" => 5, "X" => 10, "L" => 50, "C" => 100, "D" => 500, "M" => 1000, _ => 0 }

# Value read with the subtractive rule; canonical form is checked by converting back.
fn value_at(cs: List[Str], i: Int, acc: Int) -> Int =
  match get(cs, i) {
    None => acc,
    Some(c) =>
      let v = letter_value(c) in
      let next = match get(cs, i + 1) { Some(d) => letter_value(d), None => 0 } in
      if v == 0 then -1 else if v < next then value_at(cs, i + 1, acc - v) else value_at(cs, i + 1, acc + v),
  }

fn from_roman(s: Str) -> Option[Int] =
  let v = value_at(chars(s), 0, 0) in
  if v >= 1 && v <= 3999 && to_roman(v) == s then Some(v) else None

fn is_digit(c: Str) -> Bool = c >= "0" && c <= "9"

fn all_digits(s: Str) -> Bool = s != "" && len(filter(chars(s), is_digit)) == len(s)

fn convert(line: Str) -> Str =
  let t = trim(line) in
  let as_number = if all_digits(t) then to_int(t) else None in
  match as_number {
    Some(n) if n >= 1 && n <= 3999 => to_roman(n),
    _ => match from_roman(t) { Some(v) => from_int(v), None => "error" },
  }

type Fields = { done: List[Str], cur: Str, quoted: Bool }

fn step(st: Fields, c: Str) -> Fields =
  if c == "\"" then Fields { done: st.done, cur: st.cur, quoted: !st.quoted }
  else if c == "," && !st.quoted then Fields { done: push(st.done, st.cur), cur: "", quoted: false }
  else Fields { done: st.done, cur: st.cur ++ c, quoted: st.quoted }

fn rstrip(s: Str) -> Str = let n = len(s) in if n > 0 && slice(s, n - 1, n) == " " then rstrip(slice(s, 0, n - 1)) else s

    Some(name) if len(args) == 1 =>

      else if is_digit(c) then let e = digits_end(cs, i) in lex(cs, e, push(acc, Num(digits(cs, i, e, 0))))

  let op = sym_at(ts, left.pos) in
  if op == "*" || op == "/" || op == "%" then
    match unary(ts, left.pos + 1) { None => None, Some(r) => term_rest(ts, Parsed { e: Bin(op, left.e, r.e), pos: r.pos }) }

    _ => None,

    Lit(n) => Ok(n),
    Neg(x) => match eval(x) { Ok(v) => Ok(0 - v), Err(m) => Err(m) },
    Bin(op, l, r) => match eval(l) {
      Err(m) => Err(m),
      Ok(a) => match eval(r) {
        Err(m) => Err(m),
        Ok(b) => apply(op, a, b),

fn tokenize(line: &str) -> String {
    let cs: Vec<char> = line.chars().collect();
    let mut toks = Vec::new();
    let mut i = 0;
    while i < cs.len() {
        let c = cs[i];
        let run = |i: usize, ok: &dyn Fn(char) -> bool| {
            let mut j = i;
            while j < cs.len() && ok(cs[j]) {
                j += 1;
            }
            j
        };
        if c == ' ' || c == '\t' {
            i += 1;
        } else if c.is_ascii_digit() {
            let j = run(i, &|c| c.is_ascii_digit());
            toks.push(format!("NUM({})", cs[i..j].iter().collect::<String>()));
            i = j;
        } else if c.is_ascii_alphabetic() || c == '_' {
            let j = run(i, &|c| c.is_ascii_alphanumeric() || c == '_');
            toks.push(format!("ID({})", cs[i..j].iter().collect::<String>()));
            i = j;
        } else if "+-*/%".contains(c) {
            toks.push(format!("OP({c})"));
            i += 1;
        } else if c == '(' || c == ')' {
            toks.push(if c == '(' { "LP" } else { "RP" }.to_string());
            i += 1;
        } else {
            return format!("error at {}: '{}'", i + 1, c);
        }
    }
    toks.join(" ")
}

use std::io::BufRead;

#[derive(Clone, Copy, PartialEq)]
enum Tok {
    Num(i64),
    Sym(char),
}

enum E {
    Lit(i64),
    Neg(Box<E>),
    Bin(char, Box<E>, Box<E>),
}

fn lex(line: &str) -> Option<Vec<Tok>> {
    let cs: Vec<char> = line.chars().collect();
    let (mut out, mut i) = (Vec::new(), 0);
    while i < cs.len() {
        let c = cs[i];
        if c == ' ' || c == '\t' {
            i += 1;
        } else if c.is_ascii_digit() {
            let mut n = 0i64;
            while i < cs.len() && cs[i].is_ascii_digit() {
                n = n * 10 + (cs[i] as i64 - '0' as i64);
                i += 1;
            }
            out.push(Tok::Num(n));
        } else if "+-*/%()".contains(c) {
            out.push(Tok::Sym(c));
            i += 1;
        } else {
            return None;
        }
    }
    Some(out)
}

struct P<'a> {
    t: &'a [Tok],
    i: usize,
}

impl P<'_> {
    fn sym(&self) -> Option<char> {
        match self.t.get(self.i) {
            Some(Tok::Sym(c)) => Some(*c),
            _ => None,
        }
    }
    fn expr(&mut self) -> Option<E> {
        let mut v = self.term()?;
        while let Some(op @ ('+' | '-')) = self.sym() {
            self.i += 1;
            v = E::Bin(op, Box::new(v), Box::new(self.term()?));
        }
        Some(v)
    }
    fn term(&mut self) -> Option<E> {
        let mut v = self.unary()?;
        while let Some(op @ ('*' | '/' | '%')) = self.sym() {
            self.i += 1;
            v = E::Bin(op, Box::new(v), Box::new(self.unary()?));
        }
        Some(v)
    }
    fn unary(&mut self) -> Option<E> {
        if self.sym() == Some('-') {
            self.i += 1;
            return Some(E::Neg(Box::new(self.unary()?)));
        }
        self.atom()
    }
    fn atom(&mut self) -> Option<E> {
        match self.t.get(self.i).copied() {
            Some(Tok::Num(n)) => {
                self.i += 1;
                Some(E::Lit(n))
            }
            Some(Tok::Sym('(')) => {
                self.i += 1;
                let e = self.expr()?;
                if self.sym() != Some(')') {
                    return None;
                }
                self.i += 1;
                Some(e)
            }
            _ => None,
        }
    }
}

fn eval(e: &E) -> Result<i64, ()> {
    Ok(match e {
        E::Lit(n) => *n,
        E::Neg(x) => -eval(x)?,
        E::Bin(op, l, r) => {
            let (a, b) = (eval(l)?, eval(r)?);
            match op {
                '+' => a + b,
                '-' => a - b,
                '*' => a * b,
                _ if b == 0 => return Err(()),
                '/' => a / b,
                _ => a % b,
            }
        }
    })
}

fn calc(line: &str) -> String {
    let Some(t) = lex(line) else { return "error: syntax".into() };
    let mut p = P { t: &t, i: 0 };
    match p.expr() {
        Some(e) if p.i == t.len() => eval(&e).map_or("error: division by zero".into(), |v| v.to_string()),
        _ => "error: syntax".into(),
    }
}

fn main() {
    for line in std::io::stdin().lock().lines() {
        println!("{}", calc(&line.unwrap()));
    }
}

        if n == 0 {

        i += 1;
    }
    Some(out)

#[derive(Default)]
struct Tree(Option<Box<(Tree, i64, Tree)>>);

impl Tree {
    fn insert(&mut self, v: i64) {
        match &mut self.0 {
            None => self.0 = Some(Box::new((Tree::default(), v, Tree::default()))),
            Some(n) if v < n.1 => n.0.insert(v),
            Some(n) if v > n.1 => n.2.insert(v),
            Some(_) => {}
        }
    }
    fn height(&self) -> usize {
        self.0.as_ref().map_or(0, |n| 1 + n.0.height().max(n.2.height()))
    }
    fn walk(&self, order: u8, out: &mut Vec<i64>) {
        if let Some(n) = &self.0 {
            if order == 0 { out.push(n.1) }
            n.0.walk(order, out);
            if order == 1 { out.push(n.1) }
            n.2.walk(order, out);
            if order == 2 { out.push(n.1) }
        }
    }
}

fn line(name: &str, t: &Tree, order: u8) -> String {
    let mut xs = Vec::new();
    t.walk(order, &mut xs);
    std::iter::once(name.to_string()).chain(xs.iter().map(|x| x.to_string())).collect::<Vec<_>>().join(" ")
}

fn convert(line: &str) -> Option<String> {
    let t: Vec<&str> = line.split(' ').collect();
    if t.len() != 3 {
        return None;
    }
    let base = |s: &str| if !s.is_empty() && s.bytes().all(|b| b.is_ascii_digit()) { s.parse::<u32>().ok().filter(|b| (2..=36).contains(b)) } else { None };
    let (from, to) = (base(t[0])?, base(t[1])?);
    let (neg, digits) = match t[2].strip_prefix('-') {
        Some(d) => (true, d),
        None => (false, t[2]),
    };
    if digits.is_empty() {
        return None;
    }
    let mut v: i64 = 0;
    for c in digits.chars() {
        v = v * from as i64 + c.to_digit(from)? as i64;
    }
    let mut out = Vec::new();
    loop {
        out.push(std::char::from_digit((v % to as i64) as u32, to)?);
        v /= to as i64;
        if v == 0 {
            break;
        }
    }
    if neg && !(out.len() == 1 && out[0] == '0') {
        out.push('-');
    }
    Some(out.iter().rev().collect())
}

"""Benchmark driver for the controlling Claude Code session (Phase 1e, Task 3).

  python3 bench/run.py prepare <task> <arm> <run>     # fresh work dir; prints the agent prompt

    return f"{task}-{arm}-run{run}"

def workdirs():
    return json.load(open(WORKDIRS, encoding="utf-8")) if os.path.exists(WORKDIRS) else {}

def workdir(task, arm, run):
    wd = workdirs().get(entry_key(task, arm, run))
    if wd is None:
        raise SystemExit(f"{entry_key(task, arm, run)} was not prepared")

def new_workdir(task, arm, run):
    """A fresh directory under a random name; replaces the entry's previous one (a repeated dispatch)."""
    dirs = workdirs()
    old = dirs.get(entry_key(task, arm, run))

        shutil.rmtree(old, ignore_errors=True)
    wd = os.path.join(os.path.realpath(WORK) if os.path.exists(WORK) else WORK, secrets.token_hex(8))
    os.makedirs(wd)
    wd = os.path.realpath(wd)

    with open(WORKDIRS, "w", encoding="utf-8") as f:
        json.dump(dirs, f, indent=1)
        f.write("\n")

def transcript_path(agent_id):
    hits = glob.glob(os.path.expanduser(f"~/.claude/projects/**/agent-{agent_id}.jsonl"), recursive=True)
    return max(hits, key=os.path.getmtime) if hits else None

def outside(path, wd):
    p = os.path.realpath(os.path.join(wd, os.path.expanduser(path)))
    return not (p == wd or p.startswith(wd + os.sep))

def command_paths(cmd):
    """Path-like words of a shell command, ignoring heredoc bodies and quoted text with whitespace
    (QAL source, JSON arguments and test data travel there); quoted words without whitespace count."""
    cmd = re.sub(r"<<-?\s*(['\"]?)(\w+)\1[^\n]*\n.*?\n\s*\2[ \t]*(?=\n|$)", "<<HEREDOC", cmd, flags=re.S)
    cmd = re.sub(r"'([^']*)'|\"((?:\\.|[^\"\\])*)\"", lambda m: (m.group(1) if m.group(1) is not None else m.group(2)) if not re.search(r"\s", m.group(0)) else "''", cmd)
    words = re.split(r"[\s;|&<>()=`]+", cmd)
    return [w for w in words if w.startswith(("/", "~", "$HOME", "${HOME}")) or w == ".." or w.startswith("../") or "/../" in w or w.endswith("/..")]

def audit(agent_id, wd, arm):
    """Statistics of a subagent transcript: API calls and usage (deduplicated per message; the
    transcript's output_tokens are only those of the first streamed chunk, so the dispatch result's
    subagent_tokens stay the primary token measure), work tool calls (without the final
    SubagentHandback), failed tool calls (any error the toolchain reported: a tool error, `isError:
    true` from qalc.py, a Rust compile error, panic or failed `cargo test`), and rule violations (a
    tool outside ALLOWED_TOOLS, a path outside the work dir, the repository path)."""
    path = transcript_path(agent_id)
    if path is None:
        return {"found": False}
    wd = os.path.realpath(wd)
    usage, calls, results = {}, {}, {}
    with open(path, encoding="utf-8") as f:
        lines = f.readlines()
    for line in lines:
        try:
            d = json.loads(line)
        except json.JSONDecodeError:
            continue
        msg = d.get("message") or {}
        if d.get("type") == "assistant":
            if msg.get("id") and msg.get("usage"):
                usage[msg["id"]] = msg["usage"]
            for b in msg.get("content") or []:
                if isinstance(b, dict) and b.get("type") == "tool_use":
                    calls[b["id"]] = (b.get("name"), b.get("input") or {})
        elif d.get("type") == "user" and isinstance(msg.get("content"), list):
            for b in msg["content"]:
                if isinstance(b, dict) and b.get("type") == "tool_result":
                    c = b.get("content")
                    text = c if isinstance(c, str) else "\n".join(x.get("text", "") for x in c or [] if isinstance(x, dict))
                    results[b.get("tool_use_id")] = (bool(b.get("is_error")), text)
    tokens = {k: sum(u.get(k, 0) or 0 for u in usage.values()) for k in ("input_tokens", "cache_creation_input_tokens", "cache_read_input_tokens", "output_tokens")}
    by_tool, failed, violations = {}, 0, []
    repo = os.path.realpath(REPO)
    allowed_paths = (os.path.realpath(os.path.join(WORK, "bin")) + os.sep,)
    for name, _ in calls.values():
        if name not in ALLOWED_TOOLS:
            violations.append(f"used tool {name}")
    calls = {k: v for k, v in calls.items() if v[0] != "SubagentHandback"}
    for cid, (name, inp) in calls.items():
        by_tool[name] = by_tool.get(name, 0) + 1
        is_error, text = results.get(cid, (False, ""))
        cmd = str(inp.get("command", ""))
        if arm == "qal" and name == "Bash" and "qalc.py" in cmd:
            is_error = is_error or "isError: true" in text
        if arm == "rust" and name == "Bash" and "cargo" in cmd:
            is_error = is_error or re.search(r"^error\[E\d+\]|^error: could not compile|panicked at|^test result: FAILED", text, re.M) is not None
        failed += is_error
        for key in ("file_path", "path", "notebook_path"):
            if isinstance(inp.get(key), str) and outside(inp[key], wd):
                violations.append(f"{name} {key}={inp[key]}")
        if name == "Bash":
            if repo in cmd.replace(wd, "<wd>"):
                violations.append(f"Bash command names the repository: {cmd[:200]}")
            for w in command_paths(cmd):
                p = os.path.realpath(os.path.join(wd, os.path.expanduser(w.replace("${HOME}", "~").replace("$HOME", "~"))))
                if outside(w.replace("${HOME}", "~").replace("$HOME", "~"), wd) and not (p + os.sep).startswith(SYSTEM_PREFIXES + allowed_paths) and not p.startswith(allowed_paths):
                    violations.append(f"Bash command names a path outside the work dir: {w}")
    return {"found": True, "path": path, "api_calls": len(usage), "tokens": tokens, "total_tokens": sum(tokens.values()),
            "tool_calls": len(calls), "over_budget": len(calls) > TOOL_BUDGET, "by_tool": by_tool, "failed_tool_calls": failed,
            "violations": violations}

def retry_message(res):
    detail = f" ({res['error'][:1000]})" if res["error"] else ""
    failed = res["total"] if res["error"] else len(res["failed"])
    return (f"The checker ran your solution against the hidden tests: {failed} of {res['total']} cases failed{detail}. "
            "Find and fix the problem (re-read the task statement and test more inputs), then reply DONE again, or GAVE UP: <reason>.")

def finish(task, arm, run, opts):
    wd = workdir(task, arm, run)
    res = check.check_qal(task, root=wd) if arm == "qal" else check.check_rust(task, wd)
    passed = res["error"] is None and not res["failed"]
    a = audit(opts["agent-id"], wd, arm)
    rec = {"task": task, "arm": arm, "run": run, "attempt": int(opts["attempt"]), "agent_id": opts["agent-id"], "reply": opts["reply"],
           "dispatch": {"total_tokens": int(opts["subagent-tokens"]), "tool_uses": int(opts["tool-uses"]), "duration_ms": int(opts["duration-ms"])},
           "check": res, "passed": passed, "transcript": a, "valid": a.get("found", False) and not a.get("violations")}
    with open(RESULTS, "a", encoding="utf-8") as f:
        f.write(json.dumps(rec) + "\n")
    check.show(res, False)
    if not rec["valid"]:
        why = "transcript not found" if not a.get("found") else "; ".join(a["violations"][:5])
        print(f"NEXT: invalid run ({why}); dispatch a fresh agent for this entry once (prepare again), else record it as invalid")
    elif passed:
        print("NEXT: solved")
    elif rec["attempt"] < MAX_ATTEMPTS:
        print("NEXT: retry with SendMessage to the same agent:\n" + retry_message(res))
    else:
        print("NEXT: final, not solved")

def records():
    if not os.path.exists(RESULTS):
        return []
    return [json.loads(l) for l in open(RESULTS, encoding="utf-8") if l.strip()]

def status():
    sched = json.load(open(SCHEDULE, encoding="utf-8"))
    recs = records()
    for i, e in enumerate(sched["entries"], 1):
        rs = [r for r in recs if (r["task"], r["arm"], r["run"]) == (e["task"], e["arm"], e["run"])]
        last = rs[-1] if rs else None
        state = "pending" if last is None else ("solved" if last["passed"] and last["valid"] else f"attempt {last['attempt']} {'passed' if last['passed'] else 'failed'}{'' if last['valid'] else ' INVALID'}")
        print(f"{i:3} run{e['run']} {e['task']:18} {e['arm']:4} {state}")

def options(argv):
    opts = {}
    for k, v in zip(argv[::2], argv[1::2]):
        if not k.startswith("--"):
            raise SystemExit(f"expected an option, got {k}")
        opts[k[2:]] = v
    return opts

def main(argv):
    cmd = argv[1] if len(argv) > 1 else ""
    if cmd == "plan":
        o = options(argv[2:])
        plan(int(o.get("runs", 2)), o.get("seed", "qal-1e"))
    elif cmd == "prepare" and len(argv) == 5 and argv[3] in ARMS:
        prepare(argv[2], argv[3], int(argv[4]))
    elif cmd == "finish" and len(argv) >= 5 and argv[3] in ARMS:
        o = options(argv[5:])
        missing = {"attempt", "agent-id", "subagent-tokens", "tool-uses", "duration-ms", "reply"} - set(o)
        if missing:
            raise SystemExit(f"finish needs --{' --'.join(sorted(missing))}")
        finish(argv[2], argv[3], int(argv[4]), o)
    elif cmd == "status":
        status()
    elif cmd == "audit" and len(argv) == 5:
        print(json.dumps(audit(argv[2], argv[3], argv[4]), indent=1))
    else:
        print(__doc__.split("\n\n")[1], file=sys.stderr)
        return 2
    return 0

if __name__ == "__main__":
    sys.exit(main(sys.argv))

#!/usr/bin/env python3
"""Generates bench/report.md from bench/results.jsonl (and bench/discussion.md, if present).

One result line is one attempt of one (task, arm, run); a run's attempts share one agent, and a
retry continues it (SendMessage). The numbers of a dispatch or continuation result are cumulative
for the agent (`subagent_tokens` is the agent's final context size, `tool_uses` and `duration_ms`
count from its start), so a run's cost is that of its last attempt; `processed` tokens are the sum
over all API calls in the transcript (input + cache creation + cache reads + output). A run is
solved if an attempt passed every hidden test. Invalid runs (rule violation or missing
transcript) are listed but not counted. Tokens per verified solution = all tokens an arm spent on
valid runs (solved or not) / the number of solved runs.
"""

import json
import os
import statistics
import sys

BENCH = os.path.dirname(os.path.abspath(__file__))

def runs_of(recs):
    """(task, arm, run) -> summary of its attempts, in the order they were recorded."""
    out = {}
    for r in recs:
        key = (r["task"], r["arm"], r["run"])
        if r["attempt"] == 1:
            out.pop(key, None)  # a fresh agent for the entry (after an invalid run) starts a new summary
        s = out.setdefault(key, {"attempts": 0, "passed": False, "valid": True, "failed_calls": 0, "violations": []})
        s["attempts"] = r["attempt"]
        s["tokens"] = r["dispatch"]["total_tokens"]
        s["tool_uses"] = r["dispatch"]["tool_uses"]
        s["ms"] = r["dispatch"]["duration_ms"]
        s["passed"] = r["passed"]
        s["valid"] = r["valid"]
        t = r.get("transcript") or {}
        s["failed_calls"] = t.get("failed_tool_calls", 0)
        s["processed"] = t.get("total_tokens", 0)
        s["over_budget"] = t.get("over_budget", False)
        s["violations"] = t.get("violations", [])
        s["first_pass"] = s.get("first_pass") or (r["passed"] and r["attempt"] == 1)
    return out

def fmt_k(n):
    return f"{n / 1000:.1f}k"

def cell(rs):
    if not rs:
        return "–"
    solved = sum(r["passed"] for r in rs)
    att = "/".join(str(r["attempts"]) if r["passed"] else "✗" for r in rs)
    return f"{solved}/{len(rs)} ({att}) · {fmt_k(statistics.mean(r['tokens'] for r in rs))} tok · {statistics.mean(r['tool_uses'] for r in rs):.0f} calls · {statistics.mean(r['failed_calls'] for r in rs):.0f} failed"

def winner(q, r):
    """Per task: the arm with the higher share of solved runs wins; at equal shares (above zero) the
    one with fewer mean tokens over its solved runs wins, unless within 10% (tie); if neither solved
    any run, there is no winner."""
    sq, sr = sum(x["passed"] for x in q) / len(q), sum(x["passed"] for x in r) / len(r)
    if sq != sr:
        return "QAL" if sq > sr else "Rust"
    if sq == 0:
        return "none"
    a = statistics.mean(x["tokens"] for x in q if x["passed"])
    b = statistics.mean(x["tokens"] for x in r if x["passed"])
    if abs(a - b) <= TIE * max(a, b):
        return "tie"
    return "QAL" if a < b else "Rust"

def transcript(calls):
    """A minimal subagent transcript: one assistant message per (tool, input, result text, is_error)."""
    lines = []
    for k, (tool, inp, text, err) in enumerate(calls):
        lines.append({"type": "assistant", "message": {"id": f"m{k}", "usage": {"input_tokens": 1, "cache_creation_input_tokens": 10, "cache_read_input_tokens": 100, "output_tokens": 2},

class ReferenceRoundTrip(unittest.TestCase):
    """Spec §12.3: parse(print(g)) == g for every QAL reference solution — the canonical print of a
    solution reprints identically and defines definitions with the same hashes."""

    def hashes(self, source):
        with tempfile.TemporaryDirectory() as root:
            c = qalc.Client(root=root)
            try:
                is_error, text, _ = c.call("qal_define", {"source": source})
                self.assertFalse(is_error, text)
                _, _, out = c.call("qal_query", {})
                return sorted((d["name"], d["hash"]) for d in out["results"])
            finally:
                c.close()

    def test_reference_solutions_round_trip(self):
        check.ensure_qal_binary()
        for task in check.task_ids():
            path = os.path.join(BENCH, "solutions", "qal", f"{task}.qal")
            printed = subprocess.run([qalc.BIN, "fmt", path], capture_output=True, text=True, check=True).stdout
            with tempfile.NamedTemporaryFile("w", suffix=".qal", delete=False) as f:
                f.write(printed)
            try:
                again = subprocess.run([qalc.BIN, "fmt", f.name], capture_output=True, text=True, check=True).stdout
            finally:
                os.unlink(f.name)
            self.assertEqual(again, printed, task)
            with open(path, encoding="utf-8") as f:
                self.assertEqual(self.hashes(printed), self.hashes(f.read()), task)
