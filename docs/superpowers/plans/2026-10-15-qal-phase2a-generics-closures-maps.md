# QAL Phase 2a — Generics, Closures, Map and Bytes Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** QAL gets user-defined generic functions and types (type arguments inferred, compiled by monomorphisation), closures that capture locals and carry their effects in their type, `Map[K, V]` (a persistent AVL tree ordered by a structural total key order) and `Bytes` — end to end: syntax, checking, canonical form and hashes, WebAssembly, runtime values, store, and JSON arguments for `qal_call`.

**Architecture:** The AST gains `Type::{App, Param, Map, Bytes}`, `Expr::Lambda` and type parameters on `fn`/`type`; the typed form gains `TKind::{Lambda, CallG, FnRefG}`, `TProgram::generics` and `TFn::instance`. The checker checks a generic function once with rigid type parameters and then generates every reachable instance (`qal-check/src/mono.rs`), so code generation only sees monomorphic code. Every function value becomes a pointer to a closure block `[table slot][pad][captures]` with one calling convention `(env, args…)`; maps are 32-byte AVL nodes built by hand-written WebAssembly helpers (`qal-wasm/src/rt.rs`). The canonical form writes version 2 only for forms that use a Phase 2 construct, so every Phase 1 hash stays valid.

**Spec:** `docs/superpowers/specs/2026-10-15-qal-phase2-design.md` §3 (generics), §4 (closures), §5 (Map, Bytes), §6 (canonical form v2), §9 (diagnostics), §10 (`qal_call`). ## Design Decisions

Decided in the spec (`docs/superpowers/specs/2026-10-15-qal-phase2-design.md`, §2 lists all of them with reasons); in short:

1. **Generics** `fn f[T](x: T) -> T`, `type Pair[A, B] = …`, applied as `Pair[Int, Str]`; type arguments are never written, always inferred (also for constructors and patterns of generic types). Type parameters are rigid inside the definition, unique, not the name of a type (E0202) and must occur in a parameter or the result type (E0211). `main` is not generic.
2. **Monomorphisation** after checking: one instance per distinct type-argument list, named `f[Int, Str]`, appended to `TProgram::fns`; generic functions stay in `TProgram::generics`. Limits: 1000 instances, type arguments of at most 4096 nodes, 500 000 expression nodes copied into instances, each weighed by `1 +` the size of the type arguments (E0214); checking stops after E0212 and every type walk expands at most 256 distinct types; recursive calls inside a group of generic functions only at the group's own type parameters (E0213); recursive generic types only regular (E0212).
3. **`==` on a type parameter** is allowed and checked per instance (a function type there is a `type_mismatch`): without type classes, `contains[T]` would otherwise be impossible.
4. **Closures** `fn(x, y: T) => body`, capturing the locals the body uses by value (values are immutable). Parameter types come from an expected function type (parameters, annotations, built-in arguments) or are inferred.
5. **Effects of closures** are part of their type and are checked where the closure is called, never where it is created; there is no effect polymorphism (built-ins `map`/`filter`/`fold` take on the effects of their function argument). Effect subtyping is covariant through `List`/`Option`/`Result`/`Map`, contravariant in parameters, and **invariant** in the arguments of user generic types (`Sink[fn() -> Unit]` must not pass as `Sink[fn() -> Unit !io]`).
6. **Function values** are closure pointers everywhere: `[table slot: i32][pad][captured slots]`, called as `call_indirect(env, args…)`; a named function used as a value gets one static block and a wrapper that ignores `env`.
7. **Map[K, V]** is a persistent AVL tree (`0` = empty; node `[size][height][key][value][left][right]`, 32 bytes): `map_put`/`map_del` copy one path (O(log n) time and memory under the bump allocator), `map_get`/`map_has` O(log n), `map_size` O(1). Keys are ordered structurally (Int/Bool numerically, Float by IEEE total order, Str/Bytes bytewise, lists and maps lexicographically, variants by tag then payload, records by fields); keys cannot contain functions. Equality and comparison of maps go through their entries in key order (`MapEntries`), because equal maps may have different trees.
8. **`compare(a, b) -> Int`** (-1/0/1) exposes the key order for every type without functions (added after the agent trial; it orders lists, records and variants too, and agrees with `<` on Int and Str; on Float it is the IEEE total order).
9. **Bytes** have the layout of `Str` (`to_bytes` is free); `bytes_from` is a contract violation for elements outside `0..=255`, `bytes_slice` out of range is `index`, `bytes_to_str` validates UTF-8 in the host.
10. **Canonical form version 2** per form: new tags `T_APP T_PARAM T_MAP T_BYTES E_LAMBDA`, member kinds 3/4 (generic type/function); type parameters are bound like locals (renaming changes no hash); function type parameters are ordered by first occurrence (their written order has no meaning), type parameters of types keep their order (it is meaningful). The decoder rejects a v1 form with a v2 construct and a v2 form without one.
11. **JSON values** (results and `qal_call` arguments) have one form for every data type: records as objects, variants `"None"` / `{"Some": [3]}`, maps as `[[key, value], …]` (sorted by the host, duplicate keys rejected), bytes as number arrays, non-finite floats as `"NaN"`, `"inf"`, `"-inf"`.
12. **Test stacks:** the checker's unit tests run on a 64 MiB thread (`check_src`): the checker recurses along the expression nesting, test threads have 2 MiB, the CLI's main thread 8 MiB and the MCP worker 256 MiB.

## Review Focus

The scratch implementation was attacked by an independent reviewer (≈ 7 800 random functions in two fuzz campaigns plus hand-written probes). Attacks that held up, each pinned by tests that must keep passing:

1. **Effects escaping through closures** (closures in records, lists, maps, `Option`, generic containers, generic `id`/`apply`, `map`/`filter`/`fold`, returned closures, inference-order tricks, contracts, tests): none escape — Task 1 `closures_capture_locals_and_carry_their_effects`, `effects_cannot_be_laundered_through_generic_types`; Task 2 `effectful_closures_run_with_their_effects`.
2. **Hashes under renaming** (type parameters, value, closure and `let` names; function type-parameter order) stay equal; swapped parameters of a generic *type* differ; `view` → `define` reproduces every hash; Phase 1 definitions keep their version 1 bytes; mutated canonical bytes never decode — Task 1 `generic_hashes_ignore_type_parameter_names_and_order`, `versions_are_strict_both_ways`; Task 3 `renaming_type_parameters_and_closure_parameters_changes_no_hash`, `phase1_definitions_keep_their_hashes`.
3. **AVL maps** against a reference model (3 000 operations, structured keys, maps as keys, host JSON maps) — Task 2 `maps_agree_with_a_reference_map`, `maps_stay_balanced_under_ordered_inserts_and_deletes` (fails with a stack overflow if rotations are removed), `maps_of_maps_and_structured_arguments`.
4. **Functions compared or used as map keys**, also through instances — Task 1 `functions_cannot_be_compared`, `compare_needs_a_comparable_type`.

Confirmed findings, fixed in the code below and pinned by tests:

1. **Critical — `==` on an irregular generic type crashed the checker** (`type T[A] = L | N(T[List[A]])` plus `test t = L == L`: stack overflow in the CLI, a hanging MCP server): the walk that asks "can this type contain a function" expanded `T[Int] → T[List[Int]] → …` forever. Fix: `check` stops after `irregular_recursion` (E0212), and every type walk (`contains_fn`, `bad_map_key`, `has_float`) stops after 256 distinct types (map keys are resolved before E0212 is known). Pinned: Task 1 `irregular_types_are_rejected_without_expanding_them`.
2. **Important — monomorphisation cost grew with the size of type arguments** (32 instances of a 150-`let` body at types of ≈ 2 000 nodes: 48 s and 2 GB): the copied-node limit did not count the types substituted into every node. Fix: copied nodes are weighed by `1 + size of the type arguments`. Pinned: Task 1 `instances_at_large_types_are_bounded`.
3. **Minor — `qal_call` could not take back the non-finite floats it returns** (`"NaN"`, `"inf"`, `"-inf"`). Fix: `from_json` accepts exactly those strings for `Float`. Pinned: Task 2 `non_finite_floats_round_trip_through_json`.

Known and kept (documented in the spec, §5.1): map keys use the IEEE *total* order (−0.0 and 0.0 are different keys, a NaN key is found again), while `==` on floats stays IEEE equality everywhere (so a map with a NaN key is not `==` to itself).

Not changed (wording only, noted for later): a contract that calls an effectful closure gets the hint "add `!io` to the signature" even when the function declares it (contracts are pure; the hint should say so), and a closure parameter whose type is not known yet is reported as "a local value of type Unit" when it is called.

/// The type parameters of a generic function in canonical order: by first occurrence in the
/// parameter types, then the result type (then any others, in written order). Type arguments of a
/// function are always inferred, never written, so their order carries no meaning.
pub fn fn_tparams(f: &FnDef) -> Vec<String> {
    fn walk(t: &Type, tps: &[String], out: &mut Vec<String>) {
        match t {
            Type::Named(n) | Type::Param(n) => {
                if tps.contains(n) && !out.contains(n) {
                    out.push(n.clone());
                }
            }
            Type::List(x) | Type::Option(x) => walk(x, tps, out),
            Type::Result(a, b) | Type::Map(a, b) => {
                walk(a, tps, out);
                walk(b, tps, out);
            }
            Type::App(_, args) => args.iter().for_each(|a| walk(a, tps, out)),
            Type::Fn(ps, r, _) => {
                ps.iter().for_each(|p| walk(p, tps, out));
                walk(r, tps, out);
            }
            _ => {}
        }
    }
    let mut out = Vec::new();
    for p in &f.params {
        walk(&p.ty, &f.tparams, &mut out);
    }
    walk(&f.ret, &f.tparams, &mut out);
    for p in &f.tparams {
        if !out.contains(p) {
            out.push(p.clone());
        }
    }
    out
}

    pub variants: HashMap<String, (String, u32, Vec<Type>)>,
}

/// Checks a whole program. An empty result means the program may be compiled.
pub fn check_program(p: &Program) -> Vec<Diagnostic> {
    match check(p) {
        Ok(_) => Vec::new(),
        Err(d) => d,
    }
}

/// Checks a whole program and returns its typed form, or all diagnostics.
///
/// Generic functions are checked once, with their type parameters as rigid types, and kept in
/// `TProgram::generics`; every instance reachable from a monomorphic function or a test is then
/// generated (monomorphisation), so `TProgram::fns` and the tests contain no generic calls.
pub fn check(p: &Program) -> Result<TProgram, Vec<Diagnostic>> {
    let mut diags = Vec::new();
    let g = globals(p, &mut diags);
    // An irregular recursive type has infinitely many instances: nothing below may expand it.
    if diags.iter().any(|d| d.kind == "irregular_recursion") {
        return Err(diags);
    }
    let mut out = TProgram { types: g.tp.types.clone(), ..TProgram::default() };
    for d in &p.defs {
        match d {
            Def::Type(_) => {}
            Def::Fn(f) => {
                if let Some(tf) = check_fn(f, &g, &mut diags) {
                    if f.tparams.is_empty() {
                        out.fns.push(tf);
                    } else {
                        out.generics.push(tf);
                    }
                }
            }
            Def::Test(t) => {
                let mut cx = Cx::new(&g, &t.name, &[], &mut diags);
                let body = cx.expect(&t.body, &Type::Bool, "body");
                if let Some((locals, mut exprs)) = cx.finish(vec![body]) {
                    out.tests.push(TTest { name: t.name.clone(), locals, body: exprs.remove(0) });
                }
            }
        }
    }
    if diags.is_empty() {
        mono::polymorphic_recursion(&out, &mut diags);
    }
    if diags.is_empty() {
        mono::monomorphise(&mut out, &mut diags);
    }
    if diags.is_empty() {
        mono::validate(&out, &mut diags);
    }
    if diags.is_empty() {
        Ok(out)
    } else {
        Err(diags)
    }
}

/// Type parameters of a definition: unique, and not the name of a declared or built-in type.
fn check_tparams(g: &Globals, def: &str, tps: &[String], diags: &mut Vec<Diagnostic>) {
    for (i, tp) in tps.iter().enumerate() {
        let path = format!("tparams[{i}]");
        if tps[..i].contains(tp) {
            diags.push(Diagnostic::duplicate_name(def, &path, tp));
        } else if Type::BUILTIN_NAMES.contains(&tp.as_str()) || g.tp.type_def(tp).is_some() {
            diags.push(Diagnostic::duplicate_name(def, &path, tp).hint(format!("`{tp}` is already a type; choose another type parameter name")));
        }
    }
}

fn globals(p: &Program, diags: &mut Vec<Diagnostic>) -> Globals {
    let mut g = Globals { tp: TProgram::default(), fns: HashMap::new(), variants: HashMap::new() };
    for d in &p.defs {
        let Def::Type(t) = d else { continue };
        if Type::BUILTIN_NAMES.contains(&t.name.as_str()) {
            diags.push(Diagnostic::duplicate_name(&t.name, "", &t.name).hint(format!("`{}` is a built-in type", t.name)));
            continue;
        }
        if g.tp.type_def(&t.name).is_some() {
            diags.push(Diagnostic::duplicate_name(&t.name, "", &t.name));
            continue;
        }
        match &t.body {
            TypeBody::Record(fields) => {
                let mut seen = HashSet::new();
                for (f, _) in fields {
                    if !seen.insert(f) {
                        diags.push(Diagnostic::duplicate_name(&t.name, &format!("fields.{f}"), f));
                    }
                }
            }
            TypeBody::Enum(vs) => {
                for (tag, v) in vs.iter().enumerate() {
                    if BUILTIN_VARIANTS.contains(&v.name.as_str()) || g.variants.contains_key(&v.name) {
                        let mut d = Diagnostic::duplicate_name(&t.name, &format!("variants[{tag}]"), &v.name);
                        if BUILTIN_VARIANTS.contains(&v.name.as_str()) {
                            d = d.hint(format!("`{}` belongs to the built-in Option/Result", v.name));
                        }
                        diags.push(d);
                    } else {
                        g.variants.insert(v.name.clone(), (t.name.clone(), tag as u32, v.fields.clone()));
                    }
                }
            }
        }
        g.tp.types.push(t.clone());
    }
    for k in 0..g.tp.types.len() {
        let t = g.tp.types[k].clone();
        check_tparams(&g, &t.name, &t.params, diags);
        let body = match &t.body {
            TypeBody::Record(fields) => TypeBody::Record(
                fields
                    .iter()
                    .map(|(f, ty)| (f.clone(), resolve_type(&g, ty, &t.params, &t.name, &format!("fields.{f}"), diags).unwrap_or(Type::Unit)))
                    .collect(),
            ),
            TypeBody::Enum(vs) => TypeBody::Enum(
                vs.iter()
                    .enumerate()
                    .map(|(tag, v)| Variant {
                        name: v.name.clone(),
                        fields: v
                            .fields
                            .iter()
                            .enumerate()
                            .map(|(i, ty)| resolve_type(&g, ty, &t.params, &t.name, &format!("variants[{tag}].fields[{i}]"), diags).unwrap_or(Type::Unit))
                            .collect(),
                    })
                    .collect(),
            ),
        };
        if let TypeBody::Enum(vs) = &body {
            for (tag, v) in vs.iter().enumerate() {
                if let Some(e) = g.variants.get_mut(&v.name) {
                    if e.0 == t.name && e.1 == tag as u32 {
                        e.2 = v.fields.clone();
                    }
                }
            }
        }
        g.tp.types[k].body = body;
    }
    irregular_recursion(&g.tp, diags);
    let mut seen = HashSet::new();
    let (mut index, mut generic_index) = (0, 0);
    for d in &p.defs {
        if matches!(d, Def::Type(_)) {
            continue;
        }
        if !seen.insert(d.name().to_string()) {
            diags.push(Diagnostic::duplicate_name(d.name(), "", d.name()));
        } else if Builtin::NAMES.contains(&d.name()) {
            diags.push(Diagnostic::builtin_name(d.name()));
        } else if RESERVED_EXPORTS.contains(&d.name()) {
            diags.push(Diagnostic::duplicate_name(d.name(), "", d.name()).hint(format!("`{}` is reserved by the runtime", d.name())));
        } else if d.name() == RESULT_VAR && matches!(d, Def::Fn(_)) {
            // A function named `r` could not be referred to inside `ens`, where `r` is the result.
            diags.push(Diagnostic::duplicate_name(d.name(), "", d.name()).hint("`r` names the result inside `ens`; choose another function name"));
        }
        if let Def::Fn(f) = d {
            // Signatures are resolved again (with diagnostics) when the function is checked.
            let resolve = |t: &Type| resolve_type(&g, t, &f.tparams, &f.name, "", &mut Vec::new()).unwrap_or(Type::Unit);
            let sig = Sig { tparams: f.tparams.clone(), params: f.params.iter().map(|p| resolve(&p.ty)).collect(), ret: resolve(&f.ret), effects: f.effects.clone() };
            let slot = if f.tparams.is_empty() { &mut index } else { &mut generic_index };
            let i = *slot;
            *slot += 1;
            g.fns.entry(f.name.clone()).or_insert((i, sig));
        }
    }
    g
}

/// Inside the recursive group of a generic type, uses of group members must pass plain type
/// parameters (regular recursion), so every type has finitely many instances.
fn irregular_recursion(tp: &TProgram, diags: &mut Vec<Diagnostic>) {
    fn refs(t: &Type, out: &mut Vec<(String, Type)>) {
        match t {
            Type::Named(n) => out.push((n.clone(), t.clone())),
            Type::App(n, args) => {
                out.push((n.clone(), t.clone()));
                args.iter().for_each(|a| refs(a, out));
            }
            Type::List(x) | Type::Option(x) => refs(x, out),
            Type::Result(a, b) | Type::Map(a, b) => {
                refs(a, out);
                refs(b, out);
            }
            Type::Fn(ps, r, _) => {
                ps.iter().for_each(|p| refs(p, out));
                refs(r, out);
            }
            _ => {}
        }
    }
    let field_types = |d: &TypeDef| -> Vec<Type> {
        match &d.body {
            TypeBody::Record(fs) => fs.iter().map(|(_, t)| t.clone()).collect(),
            TypeBody::Enum(vs) => vs.iter().flat_map(|v| v.fields.clone()).collect(),
        }
    };
    let n = tp.types.len();
    let index: HashMap<&str, usize> = tp.types.iter().enumerate().map(|(i, d)| (d.name.as_str(), i)).collect();
    let mut edges: Vec<Vec<(usize, Type)>> = vec![Vec::new(); n];
    for (i, d) in tp.types.iter().enumerate() {
        let mut out = Vec::new();
        for t in field_types(d) {
            refs(&t, &mut out);
        }
        edges[i] = out.into_iter().filter_map(|(m, t)| index.get(m.as_str()).map(|&j| (j, t))).collect();
    }
    // reach[i][j]: type j is reachable from type i.
    let mut reach = vec![vec![false; n]; n];
    for (i, row) in reach.iter_mut().enumerate() {
        let mut stack: Vec<usize> = edges[i].iter().map(|(j, _)| *j).collect();
        while let Some(j) = stack.pop() {
            if !row[j] {
                row[j] = true;
                stack.extend(edges[j].iter().map(|(k, _)| *k));
            }
        }
    }
    for (i, d) in tp.types.iter().enumerate() {
        for (j, t) in &edges[i] {
            let same_group = *j == i || (reach[i][*j] && reach[*j][i]);
            if let Type::App(_, args) = t {
                if same_group && !args.iter().all(|a| matches!(a, Type::Param(_))) {
                    diags.push(Diagnostic::irregular_recursion(&d.name, "", &t.to_string()));
                }
            }
        }
    }
}

/// Resolves a written type: type parameters (`tps`) become `Type::Param`, declared types must exist
/// with the right number of type arguments, effects must be known, and map keys comparable.
/// Reports every problem; None if there was one.
pub(crate) fn resolve_type(g: &Globals, t: &Type, tps: &[String], def: &str, path: &str, diags: &mut Vec<Diagnostic>) -> Option<Type> {
    let before = diags.len();
    let out = resolve_inner(g, t, tps, def, path, diags);
    (diags.len() == before).then_some(out)
}

fn resolve_inner(g: &Globals, t: &Type, tps: &[String], def: &str, path: &str, diags: &mut Vec<Diagnostic>) -> Type {
    let r = |t: &Type, diags: &mut Vec<Diagnostic>| resolve_inner(g, t, tps, def, path, diags);
    match t {
        Type::Named(n) | Type::Param(n) if tps.contains(n) => Type::Param(n.clone()),
        Type::Named(n) => match g.tp.type_def(n) {
            Some(d) if d.params.is_empty() => t.clone(),
            Some(d) => {
                diags.push(Diagnostic::arity(def, path, n, d.params.len(), 0).hint(format!("write `{n}[{}]`", vec!["..."; d.params.len()].join(", "))));
                Type::Unit
            }
            None => {
                let mut d = Diagnostic::unknown_name(def, path, n);
                if g.variants.contains_key(n) || BUILTIN_VARIANTS.contains(&n.as_str()) {
                    d = d.hint(format!("`{n}` is a variant, not a type"));
                }
                diags.push(d);
                Type::Unit
            }
        },
        Type::App(n, args) => {
            let args: Vec<Type> = args.iter().map(|a| r(a, diags)).collect();
            match g.tp.type_def(n) {
                Some(d) if d.params.len() == args.len() => Type::App(n.clone(), args),
                Some(d) => {
                    diags.push(Diagnostic::arity(def, path, n, d.params.len(), args.len()));
                    Type::Unit
                }
                None => {
                    diags.push(Diagnostic::unknown_name(def, path, n));
                    Type::Unit
                }
            }
        }
        Type::Param(n) => {
            diags.push(Diagnostic::unknown_name(def, path, n));
            Type::Unit
        }
        Type::List(x) => Type::list(r(x, diags)),
        Type::Option(x) => Type::option(r(x, diags)),
        Type::Result(a, b) => {
            let a = r(a, diags);
            Type::result(a, r(b, diags))
        }
        Type::Map(k, v) => {
            let k = r(k, diags);
            if infer::contains_fn(&g.tp, &k, &mut Vec::new()) {
                diags.push(Diagnostic::type_mismatch(def, path, "a comparable key type", &k.to_string()).hint("map keys cannot contain functions"));
            }
            Type::map(k, r(v, diags))
        }
        Type::Fn(ps, ret, effs) => {
            // No short-circuit: report every unknown name.
            let ret = r(ret, diags);
            let ps: Vec<Type> = ps.iter().map(|p| r(p, diags)).collect();
            for e in effs {
                if !KNOWN_EFFECTS.contains(&e.as_str()) {
                    diags.push(Diagnostic::unknown_name(def, path, e).hint(format!("known effects: {}", KNOWN_EFFECTS.join(", "))));
                }
            }
            Type::Fn(ps, Box::new(ret), effs.clone())
        }
        _ => t.clone(),
    }
}

fn check_fn(f: &FnDef, g: &Globals, diags: &mut Vec<Diagnostic>) -> Option<TFn> {
    let before = diags.len();
    check_tparams(g, &f.name, &f.tparams, diags);
    let mut names = HashSet::new();
    let mut ptypes = Vec::new();
    for (i, p) in f.params.iter().enumerate() {
        let path = format!("params[{i}]");
        if !names.insert(p.name.as_str()) {
            diags.push(Diagnostic::duplicate_name(&f.name, &path, &p.name));
        }
        if p.name == RESULT_VAR && !f.ens.is_empty() {
            diags.push(
                Diagnostic::duplicate_name(&f.name, &path, &p.name)
                    .hint("inside `ens`, `r` is the result; rename the parameter".to_string()),
            );
        }
        ptypes.push(resolve_type(g, &p.ty, &f.tparams, &f.name, &path, diags).unwrap_or(Type::Unit));
    }
    let ret = resolve_type(g, &f.ret, &f.tparams, &f.name, "ret", diags).unwrap_or(Type::Unit);
    for (i, tp) in f.tparams.iter().enumerate() {
        let p = Type::Param(tp.clone());
        if !ptypes.iter().chain([&ret]).any(|t| mentions(t, &p)) {
            diags.push(Diagnostic::unused_type_param(&f.name, &format!("tparams[{i}]"), tp));
        }
    }
    for (i, e) in f.effects.iter().enumerate() {
        if !KNOWN_EFFECTS.contains(&e.as_str()) {
            diags.push(
                Diagnostic::unknown_name(&f.name, &format!("effects[{i}]"), e)
                    .hint(format!("known effects: {}", KNOWN_EFFECTS.join(", "))),
            );
        }
    }
    if f.name == "main" {
        let entry_hint = "the entry point must be `fn main(args: List[Str]) -> Int` (any effects)";
        if !f.tparams.is_empty() {
            diags.push(Diagnostic::type_mismatch(&f.name, "tparams", "no type parameters", &format!("[{}]", f.tparams.join(", "))).hint(entry_hint));
        }
        if f.params.len() != 1 || f.params[0].ty != Type::list(Type::Str) {
            let found: Vec<String> = f.params.iter().map(|p| p.ty.to_string()).collect();
            diags.push(Diagnostic::type_mismatch(&f.name, "params", "(List[Str])", &format!("({})", found.join(", "))).hint(entry_hint));
        }
        if f.ret != Type::Int {
            diags.push(Diagnostic::type_mismatch(&f.name, "ret", "Int", &f.ret.to_string()).hint(entry_hint));
        }
    }

    let mut cx = Cx::new(g, &f.name, &[], diags);
    cx.start = before;
    cx.tps = &f.tparams;
    for (p, t) in f.params.iter().zip(&ptypes) {
        cx.bind(&p.name, t.clone());
    }
    let mut exprs = Vec::new();
    for (i, c) in f.req.iter().enumerate() {
        exprs.push(cx.expect(c, &Type::Bool, &format!("req[{i}]")));
    }
    let result_local = (!f.ens.is_empty()).then(|| cx.bind(RESULT_VAR, ret.clone()));
    for (i, c) in f.ens.iter().enumerate() {
        exprs.push(cx.expect(c, &Type::Bool, &format!("ens[{i}]")));
    }
    if result_local.is_some() {
        cx.unbind();
    }
    cx.effects = &f.effects;
    cx.ret = Some(&ret);
    exprs.push(cx.expect(&f.body, &ret, "body"));
    let (locals, mut exprs) = cx.finish(exprs)?;
    let body = exprs.pop()?;
    let ens = exprs.split_off(f.req.len());
    Some(TFn { def: f.clone(), locals, req: exprs, ens, result_local, body, instance: None })
}

/// True if `t` mentions the type `p`.
fn mentions(t: &Type, p: &Type) -> bool {
    t == p
        || match t {
            Type::List(x) | Type::Option(x) => mentions(x, p),
            Type::Result(a, b) | Type::Map(a, b) => mentions(a, p) || mentions(b, p),
            Type::App(_, args) => args.iter().any(|a| mentions(a, p)),
            Type::Fn(ps, r, _) => ps.iter().any(|x| mentions(x, p)) || mentions(r, p),
            _ => false,
        }
}

pub(crate) fn locals_of(e: &TExpr, used: &mut BTreeSet<u32>, bound: &mut BTreeSet<u32>) {
    fn pat(p: &TPat, bound: &mut BTreeSet<u32>) {
        match p {
            TPat::Bind(id) => {
                bound.insert(*id);
            }
            TPat::Variant(_, ps) => ps.iter().for_each(|p| pat(p, bound)),
            TPat::Record(fs) => fs.iter().for_each(|(_, p)| pat(p, bound)),
            _ => {}
        }
    }
    match &e.kind {
        TKind::Local(id) => {
            used.insert(*id);
        }
        TKind::Lambda(l) => {
            used.extend(l.captures.iter().copied());
        }
        TKind::Let(id, v, b) => {
            bound.insert(*id);
            locals_of(v, used, bound);
            locals_of(b, used, bound);
        }
        TKind::Match(s, arms) => {
            locals_of(s, used, bound);

                    locals_of(g, used, bound);
                }
                locals_of(&a.body, used, bound);
            }
        }
        _ => children(e).into_iter().for_each(|c| locals_of(c, used, bound)),
    }
}

//! into instances are capped as well ([`MAX_INSTANCES`], [`MAX_TYPE_SIZE`], [`MAX_INSTANCE_NODES`]),

/// Calls `f` on `e` and every expression inside it, closure bodies included.
fn visit<'e>(e: &'e TExpr, f: &mut dyn FnMut(&'e TExpr)) {
    f(e);
    if let TKind::Lambda(l) = &e.kind {
        visit(&l.body, f);
    }
    for c in children(e) {
        visit(c, f);
    }

/// Rejects recursive calls of generic functions with type arguments other than plain type parameters.
pub(crate) fn polymorphic_recursion(tp: &TProgram, diags: &mut Vec<Diagnostic>) {
    let n = tp.generics.len();
    let mut calls: Vec<Vec<(usize, Vec<Type>)>> = vec![Vec::new(); n];
    for (g, f) in tp.generics.iter().enumerate() {
        for e in fn_exprs(f) {
            visit(e, &mut |x| match &x.kind {
                TKind::CallG(h, targs, _) | TKind::FnRefG(h, targs) => calls[g].push((*h, targs.clone())),
                _ => {}
            });
        }
    }
    let mut reach = vec![vec![false; n]; n];
    for (g, row) in reach.iter_mut().enumerate() {
        let mut stack: Vec<usize> = calls[g].iter().map(|(h, _)| *h).collect();
        while let Some(h) = stack.pop() {
            if !row[h] {
                row[h] = true;
                stack.extend(calls[h].iter().map(|(k, _)| *k));
            }
        }
    }
    for (g, f) in tp.generics.iter().enumerate() {
        for (h, targs) in &calls[g] {
            let same_group = *h == g || (reach[g][*h] && reach[*h][g]);
            if same_group && !targs.iter().all(|t| matches!(t, Type::Param(_))) {
                diags.push(Diagnostic::polymorphic_recursion(&f.def.name, "", &tp.generics[*h].def.name, &show(targs)));
                return;
            }
        }
    }
}

/// Total expression nodes all instances may copy, each weighed by the size of the instance's type
/// arguments (bounds time and memory: an instance copies the generic body and substitutes the type
/// arguments into the type of every node, so 1000 instances of a large body, or a few at large
/// types, could otherwise take gigabytes).
pub(crate) const MAX_INSTANCE_NODES: usize = 500_000;

/// Expression nodes of a function (contracts, body, closure bodies).
fn fn_nodes(f: &TFn) -> usize {
    let mut n = 0;
    for e in fn_exprs(f) {
        visit(e, &mut |_| n += 1);
    }
    n
}

            subst_in(f, tps, targs);
        }
        TKind::Call(_, xs) | TKind::List(xs) | TKind::Variant(_, xs) | TKind::Seq(xs) | TKind::Builtin(_, xs, _) => {
            xs.iter_mut().for_each(|x| subst_in(x, tps, targs));
        }
        TKind::CallIndirect(f, xs) => {
            subst_in(f, tps, targs);
            xs.iter_mut().for_each(|x| subst_in(x, tps, targs));
        }
        TKind::Record(fs) => fs.iter_mut().for_each(|(_, x)| subst_in(x, tps, targs)),
        TKind::Match(s, arms) => {
            subst_in(s, tps, targs);
            for a in arms {
                if let Some(g) = &mut a.guard {
                    subst_in(g, tps, targs);
                }
                subst_in(&mut a.body, tps, targs);
            }
        }
        TKind::Int(_) | TKind::Float(_) | TKind::Bool(_) | TKind::Str(_) | TKind::Unit | TKind::Local(_) | TKind::FnRef(_) => {}
    }
}

pub(crate) fn monomorphise(tp: &mut TProgram, diags: &mut Vec<Diagnostic>) {
    let generics = std::mem::take(&mut tp.generics);
    let mut fns = std::mem::take(&mut tp.fns);
    let sizes = generics.iter().map(fn_nodes).collect();
    let mut m = Mono { generics: &generics, sizes, copied: 0, base: fns.len(), instances: HashMap::new(), new_fns: Vec::new(), queue: Vec::new(), failed: None };
    for f in &mut fns {
        m.rewrite_fn(f);
    }
    for t in &mut tp.tests {
        let name = t.name.clone();
        m.rewrite(&name, &mut t.body);
    }
    while let Some(k) = m.queue.pop() {
        if m.failed.is_some() {
            break;
        }
        let mut f = m.new_fns[k].clone();
        m.rewrite_fn(&mut f);
        m.new_fns[k] = f;
    }
    if let Some((def, inst)) = m.failed.take() {
        diags.push(Diagnostic::instantiation_limit(&def, "", &inst, MAX_INSTANCES));
    }
    fns.extend(m.new_fns);
    tp.fns = fns;
    tp.generics = generics;
}

/// The first map key type inside `t` that is not comparable (contains a function), if any.
fn bad_map_key(tp: &TProgram, t: &Type, seen: &mut Vec<String>) -> Option<Type> {
    if seen.len() >= crate::infer::MAX_EXPANSIONS {
        return None;
    }
    match t {
        Type::Map(k, v) => {
            if contains_fn(tp, k, &mut Vec::new()) {
                return Some((**k).clone());
            }
            bad_map_key(tp, k, seen).or_else(|| bad_map_key(tp, v, seen))
        }
        Type::List(x) | Type::Option(x) => bad_map_key(tp, x, seen),
        Type::Result(a, b) => bad_map_key(tp, a, seen).or_else(|| bad_map_key(tp, b, seen)),
        Type::Fn(ps, r, _) => ps.iter().find_map(|p| bad_map_key(tp, p, seen)).or_else(|| bad_map_key(tp, r, seen)),
        Type::Named(_) | Type::App(..) => {
            let key = t.to_string();
            if seen.contains(&key) {
                return None;
            }
            seen.push(key);
            match tp.decl(t)? {
                TypeBody::Record(fs) => fs.iter().find_map(|(_, f)| bad_map_key(tp, f, seen)),
                TypeBody::Enum(vs) => vs.iter().flat_map(|v| v.fields.iter()).find_map(|f| bad_map_key(tp, f, seen)),
            }
        }
        _ => None,
    }
}

/// Checks that need concrete types: `==` inside instances (a type parameter instantiated with a
/// function type), and map keys everywhere (a key type inferred or instantiated as a function).
pub(crate) fn validate(tp: &TProgram, diags: &mut Vec<Diagnostic>) {
    let mut check = |def: &str, locals: &[Type], exprs: Vec<&TExpr>, instance: bool| {
        let mut seen = Vec::new();
        for t in locals {
            if let Some(k) = bad_map_key(tp, t, &mut seen) {
                diags.push(Diagnostic::type_mismatch(def, "", "a comparable key type", &k.to_string()).hint("map keys cannot contain functions"));
                return;
            }
        }
        for e in exprs {
            let mut found = None;
            visit(e, &mut |x| {
                if found.is_some() {
                    return;
                }
                if let Some(k) = bad_map_key(tp, &x.ty, &mut Vec::new()) {
                    found = Some(Diagnostic::type_mismatch(def, "", "a comparable key type", &k.to_string()).hint("map keys cannot contain functions"));
                } else if let TKind::Builtin(Builtin::Compare, args, path) = &x.kind {
                    if let Some(a) = args.first().filter(|a| contains_fn(tp, &a.ty, &mut Vec::new())) {
                        found = Some(Diagnostic::type_mismatch(def, path, "a comparable type", &a.ty.to_string()).hint("`compare` orders values without functions inside"));
                    }
                } else if let TKind::Bin(BinOp::Eq | BinOp::Ne, l, _, path) = &x.kind {
                    if instance && contains_fn(tp, &l.ty, &mut Vec::new()) {
                        found = Some(
                            Diagnostic::type_mismatch(def, path, "a comparable type", &l.ty.to_string())
                                .hint("functions cannot be compared; this generic function compares values of a type parameter"),
                        );
                    }
                }
            });
            if let Some(d) = found {
                diags.push(d);
                return;
            }
        }
    };
    for f in &tp.fns {
        check(&f.def.name, &f.locals, fn_exprs(f).collect(), f.instance.is_some());
    }
    for t in &tp.tests {
        check(&t.name, &t.locals, vec![&t.body], false);
    }
}

/// The total order of map keys, as the generated code's compare functions define it: Int and Bool
/// numerically, Float by IEEE total order, Str and Bytes bytewise (a prefix first), lists and maps
/// lexicographically (maps by their entries in key order), variants by tag then payload, records
/// by their fields in declaration order. Values that do not fit `ty` compare equal.
pub fn compare(tp: &TProgram, ty: &Type, a: &Value, b: &Value) -> std::cmp::Ordering {
    use std::cmp::Ordering;
    let total = |x: f64| {
        let bits = x.to_bits() as i64;
        bits ^ (((bits >> 63) as u64) >> 1) as i64
    };
    match (ty, a, b) {
        (_, Value::Int(x), Value::Int(y)) => x.cmp(y),
        (_, Value::Bool(x), Value::Bool(y)) => x.cmp(y),
        (_, Value::Float(x), Value::Float(y)) => total(*x).cmp(&total(*y)),
        (_, Value::Str(x), Value::Str(y)) => x.as_bytes().cmp(y.as_bytes()),
        (_, Value::Bytes(x, _), Value::Bytes(y, _)) => x.cmp(y),
        (Type::List(t), Value::List(xs), Value::List(ys)) => {
            for (x, y) in xs.iter().zip(ys) {
                let c = compare(tp, t, x, y);
                if c != Ordering::Equal {
                    return c;
                }
            }
            xs.len().cmp(&ys.len())
        }
        (Type::Map(kt, vt), Value::Map(xs), Value::Map(ys)) => {
            let sorted = |es: &[(Value, Value)]| {
                let mut es: Vec<(Value, Value)> = es.to_vec();
                es.sort_by(|a, b| compare(tp, kt, &a.0, &b.0));
                es
            };
            let (xs, ys) = (sorted(xs), sorted(ys));
            for ((xk, xv), (yk, yv)) in xs.iter().zip(&ys) {
                let c = compare(tp, kt, xk, yk).then_with(|| compare(tp, vt, xv, yv));
                if c != Ordering::Equal {
                    return c;
                }
            }
            xs.len().cmp(&ys.len())
        }
        (_, Value::Record(_, xs), Value::Record(_, ys)) => {
            for (f, ft) in tp.record_fields(ty) {
                let field = |fs: &[(String, Value)]| fs.iter().find(|(g, _)| *g == f).map(|(_, v)| v.clone());
                let c = match (field(xs), field(ys)) {
                    (Some(x), Some(y)) => compare(tp, &ft, &x, &y),
                    _ => Ordering::Equal,
                };
                if c != Ordering::Equal {
                    return c;
                }
            }
            Ordering::Equal
        }
        (_, Value::Variant(x, xs), Value::Variant(y, ys)) => {
            let names = tp.variant_names(ty);
            let tag = |n: &str| names.iter().position(|m| m == n).unwrap_or(usize::MAX);
            let (tx, ty_) = (tag(x), tag(y));
            if tx != ty_ {
                return tx.cmp(&ty_);
            }
            for ((x, y), ft) in xs.iter().zip(ys).zip(tp.variant_fields(ty, tx as u32)) {
                let c = compare(tp, &ft, x, y);
                if c != Ordering::Equal {
                    return c;
                }
            }
            Ordering::Equal
        }
        _ => Ordering::Equal,
    }
}

fn json_value(ty: &Type, v: &serde_json::Value) -> Result<Value, String> {
    use serde_json::Value as J;
    Ok(match (ty, v) {
        (Type::Int, J::Number(n)) => Value::Int(n.as_i64().ok_or_else(|| format!("expected Int, got {n}"))?),
        (Type::Float, J::Number(n)) => Value::Float(n.as_f64().ok_or_else(|| format!("expected Float, got {n}"))?),
        (Type::Bool, J::Bool(b)) => Value::Bool(*b),
        (Type::Unit, J::Null) => Value::Unit,
        (Type::Str, J::String(s)) => Value::Str(s.clone()),
        (Type::List(elem), J::Array(xs)) => Value::List(xs.iter().map(|x| json_value(elem, x)).collect::<Result<_, _>>()?),
        (Type::Int | Type::Float | Type::Bool | Type::Unit | Type::Str | Type::List(_), other) => {
            let shown: String = other.to_string().chars().take(40).collect();

        }
        (t, _) => return Err(format!("has type {t}, which cannot be passed as an argument (only Int, Float, Bool, Unit, Str and lists of them)")),
    })
