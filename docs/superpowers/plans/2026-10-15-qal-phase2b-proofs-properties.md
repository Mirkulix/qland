# QAL Phase 2b — Static Contract Proofs with Z3 and Generated Property Tests Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `req`/`ens` contracts are proven statically with Z3 (64-bit Int with overflow as a trap, modelled exactly; everything else soundly approximated), with confirmed counterexamples for refuted contracts and the runtime checks kept as the fallback for everything; `qal define` rejects a function whose contract is refuted; proof results are stored per definition hash; functions with contracts get generated property tests with deterministic seeds and shrinking; `qal prove` / `qal_prove` and `qal test` / `qal_test` expose all of it.

**Architecture:** The store gets schema 3 (table `proofs`) and a verification step that runs inside the `define` transaction (`Store::define_verified`). A new crate `qal-prove` encodes each obligation into Z3 (`vc.rs`: values + "evaluation does not trap" conditions; calls through the callee's contracts), solves it in a fresh context with a fixed seed and resource limit (`lib.rs`), and confirms a model by running the function with `qal-run` before calling it `refuted`. `props.rs` generates inputs (`gen.rs`), filters them with a generated `req?f` function, runs them, and shrinks failures. `qal-cli` wires both into `define`, the new `prove` operation and `test`.

**Tech Stack:** Rust 1.97 (edition 2021); **new:** `z3 =0.21.1` (published 2026-09-23) with feature `vendored`: `z3-sys 0.13.1` builds `z3-src 501.0.1` (Z3 from C++ via CMake, about 4–5 minutes once) and links it statically; `cmake 0.1.58` is the build helper. Requires CMake and a C++17 compiler (Xcode command line tools on macOS, Visual Studio C++ on Windows).

**Spec:** `docs/superpowers/specs/2026-10-15-qal-phase2-design.md` §7 (proofs), §8 (property tests), §9 (diagnostics), §10 (CLI/MCP), §11 (Z3). Previous sub-plan: `docs/superpowers/plans/2026-10-15-qal-phase2a-generics-closures-maps.md`.

**Sub-plan context:** Phase 2 is delivered as two sub-plans: 2a generics, closures, Map, Bytes (before this plan), **2b proofs and property tests (this plan)**.

## Design Decisions

Decided in the spec (`docs/superpowers/specs/2026-10-15-qal-phase2-design.md`, §2, §7, §8); in short:

1. **Obligations:** each `ens[k]` of each function (generic functions once, instances not) — if the `req` hold and the body returns, `ens[k]` is true without trapping, assuming `ens[0..k]` —, and the callee's `req[k]` at every call in a body (also inside closures and in tests, not in contracts), assuming the callee's `req[0..k]`.
2. **Encoding** (`vc.rs`): value + `ok` ("every evaluation that does not trap satisfies it"). Int as mathematical integers with range conditions on every arithmetic result (QAL traps on overflow, so `if x < 0 then -x else x >= 0` is provable); `/` and `%` truncate, `x / 0` and `MIN / -1` trap. Exact: Int/Bool literals, operators, `if`, `let`, sequences, `&&`/`||` (short-circuit), `match` with literal/binding/wildcard patterns on Int/Bool (arms in order, guards). Calls use the callee's contracts (up to 3 calls deep inside contracts). Closure bodies are encoded where the closure is created. Everything else is a fresh, unconstrained value whose facts hold for every real evaluation (`0 <= len(s) <= 2^32-1`, `lo <= rand_int(lo, hi) <= hi`).
3. **Runtime checks stay**, proven or not: compiled code never depends on the solver, and assuming a callee's `ens` after it returns is sound.
4. **Results:** `proven` (unsat), `refuted` (model confirmed by running the function or test; parameters Z3 does not model get their smallest value; functions with effects and generic functions are not run), `unknown` with a reason (solver limit, timeout, unconfirmed candidate plus the approximated constructs).
5. **Determinism and limits:** a fresh Z3 context per obligation, on its own 256 MiB-stack thread, `random_seed = 0`, `rlimit = 10 000 000`; a 5 s wall-clock timeout as a safety net (never past the budget) and a 30 s budget per call; at most 50 000 encoded expressions per function (inlined contracts included; beyond: one `unknown` report "too large to encode"); confirming values of at most 10 000 nodes. Key `qal-prove/1 z3-<version> rlimit-<n>`; results are stored per (definition hash, key); results that depend on machine speed (budget used up, wall-clock timeout, internal error) are not stored.
6. **`define`:** inside its transaction, proves every function and test that is new, got a new hash (given or relinked) or has no stored result; a refuted **function** rejects the whole `define` (E0801 with `counterexample`), a refuted call in a **test** is reported (`warnings`) and stored. Output: `proofs` (all reports) and `warnings` (E0801/E0802 for everything not proven).
7. **Property tests:** pure functions (instances included) with generatable parameters (no functions) that have an `ens` or call a function with `req`; 100 runs whose inputs satisfy `req` (a generated `req?f`), sizes 0→30, SplitMix64 seeded by `seed XOR FNV-1a(name)`; failure = any contract violation (also a recursive call breaking `f`'s own `req`, built-in preconditions); other traps are counted as `traps`; greedy shrinking (500 candidates); 20 s budget (the MCP server: what is left of its 30 s test budget).
8. **CLI/MCP:** `qal prove [<file> | <name>…]` and the 10th MCP tool `qal_prove {names?}` (`proofs`, `proven`, `refuted`, `unknown`, `warnings`; exit 1 / `isError` if refuted); `qal test [--seed n]` / `qal_test {names?, seed?}` add `properties` and `failed_properties` (names may be functions: their property test); `passed`/`failed` keep counting the written tests.

## Review Focus

The scratch implementation was attacked by an independent reviewer. **No unsound proof was found:** two fuzz campaigns (≈ 7 800 random functions: overflow at MIN/MAX, `-x`, `/` and `%` with negatives and `/ -1`, short-circuit `&&`/`||`, `if`, `match` with literal patterns, guards and shadowing, `let`, Bool equality, helpers with `req`/`ens`, closures, self-recursion) compared every `proven` obligation with property-test runs under three seeds; hand-written probes covered evaluation order of record fields, re-checked `req` in tail recursion, `MIN % -1`, generic contracts at instances, and dependents re-proven (and correctly refuted) after a callee's contract changed. Pinned: Task 2 `overflow_traps_so_abs_is_non_negative`, `division_truncates_toward_zero`, `match_arms_are_tried_in_order`, `callee_contracts_are_assumed_after_the_call`, `obligations_inside_closures_are_checked_where_the_closure_is_created`; Task 4 `agents_get_proofs_counterexamples_and_property_tests`.

Confirmed findings, fixed in the code below and pinned by tests:

1. **Critical — contract inlining blew up the prover** (contracts calling functions whose contracts call functions…, 80 calls per level: 111 s and 3 GB for a 2 KB source; the 30 s budget was only checked between obligations). Fix: an encoding has at most 50 000 expressions (`vc::MAX_VC_NODES`; beyond it the function's obligations are one `unknown` report "too large to encode"), each obligation's wall-clock limit never reaches past the budget, and every obligation runs on its own 256 MiB-stack thread (the encoding and Z3 recurse along the nesting). Pinned: Task 2 `large_contract_inlining_is_bounded`.
2. **Critical — value generation was exponential** (nested records `R1 = { a: R0, b: R0, c: R0 }` … `R14`: 14 s and 4 GB at `define`, building the "smallest" value to confirm a counterexample; the same in `qal test`). Fix: one generated value has at most 10 000 nodes (`gen::MAX_VALUE_NODES`); without such a value the candidate is not run (`unknown`) and the property `gave_up`. Pinned: Task 2 `huge_smallest_values_are_not_built`.
3. **Minor — a refutation could name the wrong call site** (two calls of `g` in `f`; running the counterexample violated `g`'s `req` at the other call). Fix: a callee's `req` counts as confirmed only if the violation's values equal this call's modelled arguments and no other call of the same callee with the same goal matches them. Pinned: Task 2 `a_refutation_names_the_call_that_fails`.
4. **Minor — the resource limit was too low** (`f(x - 1, n - 1)` with `req x > 0` came back `unknown`, so a wrong function was stored): `rlimit` 2·10⁶ → 10⁷ (measured: a hard nonlinear goal then gives up after ≈ 3 s, the refutation takes 0.2 s). Pinned: Task 2 `simple_recursive_counterexamples_are_found`.

## Agent Trial

Before this plan was written, a subagent with no QAL knowledge got the scratch MCP server (Phase 2a and 2b complete) and a 40-line stdio client, and was told to learn QAL only from the tool list and results and to solve three tasks:

| Task | Tool calls | Unintended failures | Result |
|---|---|---|---|
| Generic binary search tree `Tree[T]` with `insert`/`contains`/`to_list` taking `less: fn(T, T) -> Bool`, tests with Int and Str, `size` with `ens r >= 0` proven | ≈ 14 (7 of them prover experiments) | 2 | solved with workarounds (see below) |
| Word frequencies with `Map[Str, Int]` and closures, top 3 printed by an entry point reading stdin | 4 | 0 | solved; output correct including ties |
| `clamp` and `abs_diff` with contracts proven (overflow!), one deliberately wrong contract | 4 | 0 | solved; both proven without extra `req` (overflow traps); the refutation came with a usable counterexample |

What it stumbled over, and what changed because of it (all pinned by tests):

- **The obvious recursive `size` over a tree was `unknown`.** Cause: the encoding of `match` did not state that one arm is always taken (exhaustive matches, falling off the end traps), so the solver could pick "no arm" and an unconstrained value. Fixed in `vc.rs` (`oks.push(Bool::or(&sels))`, sound because only trapping evaluations take no arm); `recursion_over_enums_uses_the_recursive_contract` proves `size[T]` and a sum over an `IntTree`, and refutes a wrong one.
- **No way to order strings** (the trial ran before Phase 1e added `<` on Str), so sorting `Tree[Str]` needed a hand-written byte comparison. Added the built-in `compare(a, b) -> Int` (-1/0/1) over every type without functions, using the same total order as map keys and as `<` on Str (Phase 2a; exact for Int/Bool in the prover).
- **The reason for a generic function's `unknown`** only said that it is not executed; it now says a candidate was found and why it was not run, and an empty `counterexample` is omitted.
- **A passed property test carried an `error`** (a tolerated overflow trap). Such traps are now reported as `trap`, `error` is only the failure of a failed property; the reference says traps are counted, not failures.
- **Reference gaps:** built-in names are reserved (the agent's `contains` clashed with the built-in), loops with effects via `fold(xs, (), …)`, and that a function computing its result through another function needs that function's `ens`.
- Kept as known limitations: no deletion of definitions (probes stay in the store), no list slicing / sort-with-comparator built-ins (writable in QAL with `compare`, `filter`, `fold`).

```rust
fn verification_runs_inside_define_and_can_reject_it() {

    let mut seen: Vec<Vec<String>> = Vec::new();
    let verify_with = |s: &mut Store, src: &str, reject: Option<&str>, seen: &mut Vec<Vec<String>>| {

            assert!(todo.iter().all(|(n, _)| tp.fn_index(n).is_some() || tp.tests.iter().any(|t| &t.name == n)));
```

```rust
/// Runs the verifier on the definitions that are new, got a new hash, or have no stored result for
/// its key, and stores its results — inside the `define` transaction, so diagnostics reject everything.
fn verified(tx: &Transaction, typed: &TProgram, out: &[Defined], v: &mut Verify) -> Result<(), Vec<Diagnostic>> {
    let mut todo = Vec::new();
    for d in out.iter().filter(|d| d.kind != "type") {
        let stored: Option<i64> = tx.query_row("SELECT 1 FROM proofs WHERE hash = ?1 AND prover = ?2", params![d.hash, v.key], |r| r.get(0)).optional().map_err(sql)?;
        if d.status != "unchanged" || stored.is_none() {
            todo.push((d.name.clone(), d.hash.clone()));
        }
    }
    if todo.is_empty() {
        return Ok(());
    }
    let now = now_ms();
    for (hash, results) in (v.run)(typed, &todo)? {
        tx.execute(
            "INSERT INTO proofs (hash, prover, results, at) VALUES (?1, ?2, ?3, ?4) \
             ON CONFLICT(hash, prover) DO UPDATE SET results = excluded.results, at = excluded.at",
            params![hash, v.key, results, now],
        )
        .map_err(sql)?;
    }
    Ok(())
}
```

```rust
//! Verification conditions: typed QAL expressions -> Z3 formulas.
//!
//! Every expression is encoded as a value (a Z3 `Int` for `Int`, a `Bool` for `Bool`, nothing for
//! other types) and a condition `ok` that every evaluation of the expression which does not trap
//! satisfies. Values are exact mathematical integers: QAL traps on every Int overflow, so a value
//! that exists at runtime equals its mathematical value and lies in the 64-bit range. An arithmetic
//! result therefore contributes `in_range(result)` to `ok` (never a wrapped value); division and
//! remainder truncate toward zero like `i64.div_s` / `i64.rem_s`, `x / 0` and `MIN / -1` trap,
//! `MIN % -1` is 0.
//!
//! **Soundness rule:** a construct the encoding does not model (Float, Str, lists, records, enums,
//! maps, closures and calls through function values, field access, most built-ins, payloads bound
//! by non-literal patterns) becomes a fresh, unconstrained value, and its `ok` only states facts that
//! hold for every real evaluation (e.g. `0 <= len(s) <= 2^32 - 1`). Fresh values are universally
//! quantified in every check, so the solver considers at least every real execution: a proof stays
//! a proof, and only the precision suffers (such contracts are `unknown`).
//!
//! A call `g(args)` is abstracted by g's contracts: the caller must establish g's `req` (an
//! obligation at the call site, under the path condition), and may assume g's `req` and `ens` for
//! the result after the call returns. This is sound because every contract stays checked at runtime
//! (Phase 2 removes no check): a call that returns has passed g's `req` and `ens` checks. For a
//! recursive call it is the induction hypothesis on the depth of the call tree (partial correctness:
//! termination is not proven).

use qal_core::ast::{BinOp, Type, UnOp};
use qal_core::tast::{Builtin, TArm, TExpr, TFn, TKind, TPat, TProgram, TTest};
use std::collections::BTreeSet;
use z3::ast::{Bool, Int};

/// Callee contracts are encoded this many calls deep (contracts calling functions with contracts);
/// deeper calls are fresh values.
const MAX_INLINE: usize = 3;

/// Expressions encoded per function or test, inlined contracts included. Beyond it the encoding
/// stops (`Vc::truncated`) and the function's obligations are `unknown`: contracts that call
/// functions with large contracts multiply (k calls at 3 levels are k³ encodings).
pub const MAX_VC_NODES: usize = 50_000;

#[derive(Clone, Debug)]
pub enum Term {
    I(Int),
    B(Bool),
}

impl Term {
    fn int(&self) -> Option<&Int> {
        match self {
            Term::I(i) => Some(i),
            Term::B(_) => None,
        }
    }

    fn bool(&self) -> Option<&Bool> {
        match self {
            Term::B(b) => Some(b),
            Term::I(_) => None,
        }
    }
}

/// What must hold: an `ens` of the function, or a callee's `req` at a call site.
#[derive(Debug, Clone, PartialEq)]
pub enum Goal {
    Ens(usize),
    /// (callee as the runtime names it, index of its `req`)
    Req(String, usize),
}

/// One proof obligation: whenever `pre` and `hyp` hold, `goal` must hold.
pub struct Obligation {
    pub goal: Goal,
    /// `ens[0]`, or `req[1] of g`.
    pub label: String,
    /// AST path of the contract (`ens[0]`) or of the call (`body.then`).
    pub path: String,
    /// The contract as text (`ens r >= x`).
    pub contract: String,
    pub hyp: Bool,
    pub holds: Bool,
    /// For a callee's `req`: the callee's parameter names and the encoded arguments of this call
    /// (to tell a confirmed violation at this call from one at another call of the same callee).
    pub args: Vec<(String, Option<Term>)>,
}

/// The verification conditions of one function or test.
pub struct Vc {
    /// Parameters in range and the function's `req` (true for a test).
    pub pre: Bool,
    /// Parameter names, types and their Z3 constants (None: not modelled).
    pub params: Vec<(String, Type, Option<Term>)>,
    pub obligations: Vec<Obligation>,
    /// Constructs that were approximated (become part of the reason for `unknown`).
    pub approx: BTreeSet<String>,
    /// The encoding hit `MAX_VC_NODES`; the obligations are incomplete and must not be used.
    pub truncated: bool,
}

pub fn and(xs: &[Bool]) -> Bool {
    match xs {
        [] => Bool::from_bool(true),
        [x] => x.clone(),
        _ => Bool::and(xs),
    }
}

pub fn in_range(x: &Int) -> Bool {
    Bool::and(&[x.ge(Int::from_i64(i64::MIN)), x.le(Int::from_i64(i64::MAX))])
}

fn truth() -> Bool {
    Bool::from_bool(true)
}

/// `a / b` truncated toward zero (Z3's `div` is Euclidean; for `a >= 0` both agree for either sign of `b`).
fn tdiv(a: &Int, b: &Int) -> Int {
    let zero = Int::from_i64(0);
    a.ge(&zero).ite(&a.div(b), &a.unary_minus().div(b).unary_minus())
}

/// A fresh value of a modelled type and the facts every value of the type satisfies.
fn havoc(ty: &Type) -> (Option<Term>, Bool) {
    match ty {
        Type::Int => {
            let x = Int::fresh_const("v");
            let r = in_range(&x);
            (Some(Term::I(x)), r)
        }
        Type::Bool => (Some(Term::B(Bool::fresh_const("b"))), truth()),
        _ => (None, truth()),
    }
}

struct Enc<'p> {
    tp: &'p TProgram,
    /// Collect call-site obligations (only while encoding the body being proven, not contracts).
    record: bool,
    depth: usize,
    /// Local types of the definition whose expressions are being encoded (an inlined callee last).
    locals: Vec<&'p [Type]>,
    obligations: Vec<Obligation>,
    approx: BTreeSet<String>,
    nodes: usize,
}

/// The verification conditions of a function (monomorphic or generic).
pub fn function<'p>(tp: &'p TProgram, f: &'p TFn) -> Vc {
    let mut enc = Enc { tp, record: false, depth: 0, locals: vec![&f.locals], obligations: Vec::new(), approx: BTreeSet::new(), nodes: 0 };
    let mut env: Vec<Option<Term>> = vec![None; f.locals.len()];
    let mut facts = Vec::new();
    let mut params = Vec::new();
    for (k, p) in f.def.params.iter().enumerate() {
        let ty = f.locals.get(k).cloned().unwrap_or(Type::Unit);
        let t = match ty {
            Type::Int => {
                let x = Int::new_const(p.name.as_str());
                facts.push(in_range(&x));
                Some(Term::I(x))
            }
            Type::Bool => Some(Term::B(Bool::new_const(p.name.as_str()))),
            _ => None,
        };
        params.push((p.name.clone(), ty, t.clone()));
        if let Some(slot) = env.get_mut(k) {
            *slot = t;
        }
    }
    // The `req` are checked in order: req[k] is evaluated only if the earlier ones held.
    for (k, c) in f.req.iter().enumerate() {
        let (v, ok) = enc.enc(c, &mut env, &and(&facts), &format!("req[{k}]"));
        facts.push(ok);
        facts.push(enc.as_bool(v, "a contract over values the prover does not model"));
    }
    let pre = and(&facts);
    enc.record = true;
    let (body, body_ok) = enc.enc(&f.body, &mut env, &truth(), "body");
    enc.record = false;
    if let Some(r) = f.result_local {
        if let Some(slot) = env.get_mut(r as usize) {
            *slot = body;
        }
        // Checked in order after the body returned: ens[k] may assume the earlier ones.
        let mut hyp = vec![body_ok];
        for (k, c) in f.ens.iter().enumerate() {
            let (v, ok) = enc.enc(c, &mut env, &and(&hyp), &format!("ens[{k}]"));
            let holds = and(&[ok, enc.as_bool(v, "a contract over values the prover does not model")]);
            let contract = f.def.ens.get(k).map(|e| format!("ens {}", qal_text::print_expr(e))).unwrap_or_default();
            enc.obligations.push(Obligation { goal: Goal::Ens(k), label: format!("ens[{k}]"), path: format!("ens[{k}]"), contract, hyp: and(&hyp), holds: holds.clone(), args: Vec::new() });
            hyp.push(holds);
        }
    }
    let truncated = enc.nodes > MAX_VC_NODES;
    Vc { pre, params, obligations: enc.obligations, approx: enc.approx, truncated }
}

/// The verification conditions of a test: the `req` of every function it calls.
pub fn test<'p>(tp: &'p TProgram, t: &'p TTest) -> Vc {
    let mut enc = Enc { tp, record: true, depth: 0, locals: vec![&t.locals], obligations: Vec::new(), approx: BTreeSet::new(), nodes: 0 };
    let mut env: Vec<Option<Term>> = vec![None; t.locals.len()];
    enc.enc(&t.body, &mut env, &truth(), "body");
    let truncated = enc.nodes > MAX_VC_NODES;
    Vc { pre: truth(), params: Vec::new(), obligations: enc.obligations, approx: enc.approx, truncated }
}

impl<'p> Enc<'p> {
    /// The Bool of a value (a fresh one, noted as `why`, if it is not modelled).
    fn as_bool(&mut self, v: Option<Term>, why: &str) -> Bool {
        match v {
            Some(Term::B(b)) => b,
            _ => {
                self.approx.insert(why.to_string());
                Bool::fresh_const("u")
            }
        }
    }

    /// Encodes `e` under path condition `pc`: (value, ok). A modelled type always has a value.
    fn enc(&mut self, e: &TExpr, env: &mut Vec<Option<Term>>, pc: &Bool, path: &str) -> (Option<Term>, Bool) {
        self.nodes += 1;
        if self.nodes > MAX_VC_NODES {
            // Too large: the result is discarded (`Vc::truncated`); stop encoding.
            return havoc(&e.ty);
        }
        let (v, ok) = self.enc_inner(e, env, pc, path);
        match v {
            Some(v) => (Some(v), ok),
            None => {
                let (h, facts) = havoc(&e.ty);
                (h, and(&[ok, facts]))
            }
        }
    }

    /// A fresh value of type `ty` standing for `what` (noted when the type is modelled).
    fn unknown(&mut self, ty: &Type, what: &str) -> (Option<Term>, Bool) {
        if matches!(ty, Type::Int | Type::Bool) {
            self.approx.insert(what.to_string());
        }
        havoc(ty)
    }

    /// Encodes `xs` left to right; each is evaluated only if the previous ones did not trap.
    fn seq(&mut self, xs: &[TExpr], env: &mut Vec<Option<Term>>, pc: &Bool, path: &str, item: &str) -> (Vec<Option<Term>>, Bool) {
        let mut oks = Vec::new();
        let mut vals = Vec::new();
        for (i, x) in xs.iter().enumerate() {
            let mut here = vec![pc.clone()];
            here.extend(oks.iter().cloned());
            let (v, ok) = self.enc(x, env, &and(&here), &format!("{path}.{item}[{i}]"));
            vals.push(v);
            oks.push(ok);
        }
        (vals, and(&oks))
    }

    fn enc_inner(&mut self, e: &TExpr, env: &mut Vec<Option<Term>>, pc: &Bool, path: &str) -> (Option<Term>, Bool) {
        match &e.kind {
            TKind::Int(n) => (Some(Term::I(Int::from_i64(*n))), truth()),
            TKind::Bool(b) => (Some(Term::B(Bool::from_bool(*b))), truth()),
            TKind::Float(_) | TKind::Str(_) | TKind::Unit | TKind::FnRef(_) | TKind::FnRefG(..) => (None, truth()),
            TKind::Local(id) => (env.get(*id as usize).cloned().flatten(), truth()),
            TKind::Lambda(l) => {
                // The body runs later, any number of times, with any arguments; everything it can see
                // besides its parameters is immutable and was bound when the closure was created, so
                // obligations inside are checked here under the creation's path condition.
                let mut facts = vec![pc.clone()];
                for p in &l.params {
                    let ty = self.locals.last().and_then(|ls| ls.get(*p as usize)).cloned().unwrap_or(Type::Unit);
                    let (h, f) = havoc(&ty);
                    if let Some(slot) = env.get_mut(*p as usize) {
                        *slot = h;
                    }
                    facts.push(f);
                }
                self.enc(&l.body, env, &and(&facts), &format!("{path}.body"));
                (None, truth())
            }
            TKind::Un(UnOp::Not, x, _) => {
                let (v, ok) = self.enc(x, env, pc, &format!("{path}.operand"));
                (v.as_ref().and_then(Term::bool).map(|b| Term::B(b.not())), ok)
            }
            TKind::Un(UnOp::Neg, x, _) => {
                let (v, ok) = self.enc(x, env, pc, &format!("{path}.operand"));
                match v.as_ref().and_then(Term::int) {
                    Some(i) => {
                        let r = i.unary_minus();
                        let ok = and(&[ok, in_range(&r)]);
                        (Some(Term::I(r)), ok)
                    }
                    None => {
                        let (h, f) = self.unknown(&e.ty, "Float arithmetic");
                        (h, and(&[ok, f]))
                    }
                }
            }
            TKind::Bin(op, l, r, _) => self.binary(*op, l, r, &e.ty, env, pc, path),
            TKind::If(c, a, b) => {
                let (cv, cok) = self.enc(c, env, pc, &format!("{path}.cond"));
                let cv = self.as_bool(cv, "a condition the prover does not model");
                let (av, aok) = self.enc(a, env, &and(&[pc.clone(), cok.clone(), cv.clone()]), &format!("{path}.then"));
                let (bv, bok) = self.enc(b, env, &and(&[pc.clone(), cok.clone(), cv.not()]), &format!("{path}.else"));
                let ok = and(&[cok, cv.ite(&aok, &bok)]);
                let v = match (av, bv) {
                    (Some(Term::I(x)), Some(Term::I(y))) => Some(Term::I(cv.ite(&x, &y))),
                    (Some(Term::B(x)), Some(Term::B(y))) => Some(Term::B(cv.ite(&x, &y))),
                    _ => None,
                };
                (v, ok)
            }
            TKind::Let(id, v, b) => {
                let (vv, vok) = self.enc(v, env, pc, &format!("{path}.value"));
                if let Some(slot) = env.get_mut(*id as usize) {
                    *slot = vv;
                }
                let (bv, bok) = self.enc(b, env, &and(&[pc.clone(), vok.clone()]), &format!("{path}.body"));
                (bv, and(&[vok, bok]))
            }
            TKind::Seq(items) => {
                let (mut vals, ok) = self.seq(items, env, pc, path, "items");
                (vals.pop().flatten(), ok)
            }
            TKind::List(items) => (None, self.seq(items, env, pc, path, "items").1),
            TKind::Variant(_, args) => (None, self.seq(args, env, pc, path, "args").1),
            TKind::Record(fs) => {
                let names = self.tp.record_fields(&e.ty);
                let mut oks = Vec::new();
                for (i, x) in fs {
                    let mut here = vec![pc.clone()];
                    here.extend(oks.iter().cloned());
                    let name = names.get(*i as usize).map(|(n, _)| n.clone()).unwrap_or_default();
                    oks.push(self.enc(x, env, &and(&here), &format!("{path}.fields.{name}")).1);
                }
                (None, and(&oks))
            }
            TKind::Field(x, _) => {
                let ok = self.enc(x, env, pc, &format!("{path}.target")).1;
                let (h, f) = self.unknown(&e.ty, "record fields");
                (h, and(&[ok, f]))
            }
            TKind::CallIndirect(f, args) => {
                let fok = self.enc(f, env, pc, path).1;
                let (_, aok) = self.seq(args, env, &and(&[pc.clone(), fok.clone()]), path, "args");
                let (h, facts) = self.unknown(&e.ty, "calls of function values");
                (h, and(&[fok, aok, facts]))
            }
            TKind::Builtin(b, args, _) => {
                let (vals, ok) = self.seq(args, env, pc, path, "args");
                let (v, range) = self.unknown(&e.ty, &format!("built-in `{}`", b.name()));
                let mut facts = vec![ok, range];
                if let Some(Term::I(x)) = &v {
                    match b {
                        Builtin::StrLen | Builtin::ListLen | Builtin::BytesLen | Builtin::MapSize => {
                            facts.push(x.ge(Int::from_i64(0)));
                            facts.push(x.le(Int::from_i64(u32::MAX as i64)));
                        }
                        Builtin::Compare => {
                            facts.push(x.ge(Int::from_i64(-1)));
                            facts.push(x.le(Int::from_i64(1)));
                            // Int and Bool order numerically: exact.
                            match (vals.first(), vals.get(1)) {
                                (Some(Some(Term::I(a))), Some(Some(Term::I(c)))) => facts.push(x.eq(a.lt(c).ite(&Int::from_i64(-1), &a.eq(c).ite(&Int::from_i64(0), &Int::from_i64(1))))),
                                (Some(Some(Term::B(a))), Some(Some(Term::B(c)))) => facts.push(x.eq(a.eq(c).ite(&Int::from_i64(0), &a.ite(&Int::from_i64(1), &Int::from_i64(-1))))),
                                _ => {}
                            }
                        }
                        Builtin::RandInt => {
                            // It returns only if lo <= hi (else a contract violation).
                            if let (Some(Some(Term::I(lo))), Some(Some(Term::I(hi)))) = (vals.first(), vals.get(1)) {
                                facts.push(lo.le(x));
                                facts.push(x.le(hi));
                            }
                        }
                        _ => {}
                    }
                }
                (v, and(&facts))
            }
            TKind::Call(i, args) => {
                let (vals, ok) = self.seq(args, env, pc, path, "args");
                self.call(*i, false, vals, ok, &e.ty, pc, path)
            }
            TKind::CallG(g, _, args) => {
                let (vals, ok) = self.seq(args, env, pc, path, "args");
                self.call(*g, true, vals, ok, &e.ty, pc, path)
            }
            TKind::Match(s, arms) => self.match_expr(s, arms, env, pc, path),
        }
    }

    #[allow(clippy::too_many_arguments)]
    fn binary(&mut self, op: BinOp, l: &TExpr, r: &TExpr, ty: &Type, env: &mut Vec<Option<Term>>, pc: &Bool, path: &str) -> (Option<Term>, Bool) {
        let (lp, rp) = (format!("{path}.left"), format!("{path}.right"));
        let (lv, lok) = self.enc(l, env, pc, &lp);
        if matches!(op, BinOp::And | BinOp::Or) {
            let lb = self.as_bool(lv, "a condition the prover does not model");
            // The right operand is evaluated only if the left one does not decide.
            let when = if op == BinOp::And { lb.clone() } else { lb.not() };
            let (rv, rok) = self.enc(r, env, &and(&[pc.clone(), lok.clone(), when.clone()]), &rp);
            let rb = self.as_bool(rv, "a condition the prover does not model");
            let v = if op == BinOp::And { Bool::and(&[lb, rb]) } else { Bool::or(&[lb, rb]) };
            return (Some(Term::B(v)), and(&[lok, when.implies(&rok)]));
        }
        let (rv, rok) = self.enc(r, env, &and(&[pc.clone(), lok.clone()]), &rp);
        let ok = and(&[lok, rok]);
        let ints = match (&lv, &rv) {
            (Some(Term::I(a)), Some(Term::I(b))) => Some((a.clone(), b.clone())),
            _ => None,
        };
        match (op, ints) {
            (BinOp::Add | BinOp::Sub | BinOp::Mul, Some((a, b))) => {
                let v = match op {
                    BinOp::Add => Int::add(&[a, b]),
                    BinOp::Sub => Int::sub(&[a, b]),
                    _ => Int::mul(&[a, b]),
                };
                let ok = and(&[ok, in_range(&v)]);
                (Some(Term::I(v)), ok)
            }
            (BinOp::Div, Some((a, b))) => {
                let q = tdiv(&a, &b);
                let ok = and(&[ok, b.eq(Int::from_i64(0)).not(), in_range(&q)]);
                (Some(Term::I(q)), ok)
            }
            (BinOp::Rem, Some((a, b))) => {
                // |a % b| < |b|, so the remainder is always in range (MIN % -1 = 0).
                let q = tdiv(&a, &b);
                let v = Int::sub(&[a, Int::mul(&[b.clone(), q])]);
                let ok = and(&[ok, b.eq(Int::from_i64(0)).not()]);
                (Some(Term::I(v)), ok)
            }
            (BinOp::Lt, Some((a, b))) => (Some(Term::B(a.lt(&b))), ok),
            (BinOp::Le, Some((a, b))) => (Some(Term::B(a.le(&b))), ok),
            (BinOp::Gt, Some((a, b))) => (Some(Term::B(a.gt(&b))), ok),
            (BinOp::Ge, Some((a, b))) => (Some(Term::B(a.ge(&b))), ok),
            (BinOp::Eq | BinOp::Ne, _) => {
                let eq = match (&lv, &rv) {
                    (Some(Term::I(a)), Some(Term::I(b))) => Some(a.eq(b)),
                    (Some(Term::B(a)), Some(Term::B(b))) => Some(a.eq(b)),
                    _ => None,
                };
                match eq {
                    Some(q) => (Some(Term::B(if op == BinOp::Ne { q.not() } else { q })), ok),
                    None => {
                        let (h, f) = self.unknown(ty, &format!("`{}` on {}", op.symbol(), l.ty));
                        (h, and(&[ok, f]))
                    }
                }
            }
            _ => {
                let what = if l.ty == Type::Float { "Float arithmetic".to_string() } else { format!("`{}` on {}", op.symbol(), l.ty) };
                let (h, f) = self.unknown(ty, &what);
                (h, and(&[ok, f]))
            }
        }
    }

    /// A call of `fns[i]` (or `generics[i]`): obligations for its `req`, assumptions from its contracts.
    #[allow(clippy::too_many_arguments)]
    fn call(&mut self, i: usize, generic: bool, args: Vec<Option<Term>>, args_ok: Bool, ty: &Type, pc: &Bool, path: &str) -> (Option<Term>, Bool) {
        let tp = self.tp;
        let callee = if generic { tp.generics.get(i) } else { tp.fns.get(i) };
        let Some(callee) = callee else {
            let (h, f) = self.unknown(ty, "a call the prover cannot resolve");
            return (h, and(&[args_ok, f]));
        };
        let (v, range) = havoc(ty);
        let mut facts = vec![args_ok.clone(), range];
        if self.depth >= MAX_INLINE {
            if callee.req.is_empty() && callee.ens.is_empty() {
                return (v, and(&facts));
            }
            self.approx.insert("contracts nested more than 3 calls deep".into());
            return (v, and(&facts));
        }
        if callee.ens.is_empty() && matches!(ty, Type::Int | Type::Bool) {
            self.approx.insert(format!("the result of `{}` (it has no `ens`)", callee.def.name));
        }
        let (saved, record) = (self.depth, self.record);
        self.depth += 1;
        self.record = false;
        self.locals.push(&callee.locals);
        let mut cenv: Vec<Option<Term>> = vec![None; callee.locals.len()];
        let named: Vec<(String, Option<Term>)> = callee.def.params.iter().map(|p| p.name.clone()).zip(args.iter().cloned()).collect();
        for (k, a) in args.into_iter().enumerate() {
            if let Some(slot) = cenv.get_mut(k) {
                *slot = a;
            }
        }
        // The callee checks its `req` in order: req[k] is evaluated only if the earlier ones held.
        let mut held = Vec::new();
        for (k, c) in callee.req.iter().enumerate() {
            let (cv, cok) = self.enc(c, &mut cenv, &and(&held), &format!("req[{k}]"));
            let holds = and(&[cok, self.as_bool(cv, "a contract over values the prover does not model")]);
            if record {
                let mut hyp = vec![pc.clone(), args_ok.clone()];
                hyp.extend(held.iter().cloned());
                let contract = callee.def.req.get(k).map(|e| format!("req {}", qal_text::print_expr(e))).unwrap_or_default();
                self.obligations.push(Obligation {
                    goal: Goal::Req(callee.def.name.clone(), k),
                    label: format!("req[{k}] of {}", callee.def.name),
                    path: path.to_string(),
                    contract,
                    hyp: and(&hyp),
                    holds: holds.clone(),
                    args: named.clone(),
                });
            }
            held.push(holds);
        }
        facts.extend(held);
        if let Some(r) = callee.result_local {
            if let Some(slot) = cenv.get_mut(r as usize) {
                *slot = v.clone();
            }
            for (k, c) in callee.ens.iter().enumerate() {
                let (cv, cok) = self.enc(c, &mut cenv, &and(&facts), &format!("ens[{k}]"));
                facts.push(cok);
                facts.push(self.as_bool(cv, "a contract over values the prover does not model"));
            }
        }
        self.locals.pop();
        self.depth = saved;
        self.record = record;
        (v, and(&facts))
    }

    fn match_expr(&mut self, s: &TExpr, arms: &[TArm], env: &mut Vec<Option<Term>>, pc: &Bool, path: &str) -> (Option<Term>, Bool) {
        let (sv, sok) = self.enc(s, env, pc, &format!("{path}.scrutinee"));
        let pcs = and(&[pc.clone(), sok.clone()]);
        let mut prev = Bool::from_bool(false);
        let mut oks = vec![sok];
        let mut sels = Vec::new();
        let mut vals = Vec::new();
        for (i, arm) in arms.iter().enumerate() {
            let mut facts = Vec::new();
            let pm = self.pattern(&arm.pat, sv.as_ref(), &s.ty, env, &mut facts);
            let reach = and(&[prev.not(), pm, and(&facts)]);
            let sel = match &arm.guard {
                Some(g) => {
                    let (gv, gok) = self.enc(g, env, &and(&[pcs.clone(), reach.clone()]), &format!("{path}.arms[{i}].guard"));
                    oks.push(reach.implies(&gok));
                    and(&[reach.clone(), self.as_bool(gv, "a guard the prover does not model")])
                }
                None => reach,
            };
            let (bv, bok) = self.enc(&arm.body, env, &and(&[pcs.clone(), sel.clone()]), &format!("{path}.arms[{i}].body"));
            oks.push(sel.implies(&bok));
            prev = Bool::or(&[prev, sel.clone()]);
            sels.push(sel);
            vals.push(bv);
        }
        // Exactly one arm is taken by every evaluation that does not trap (matches are exhaustive;
        // falling off the end is a trap), and its value is the match's value.
        oks.push(Bool::or(&sels));
        let mut v = vals.pop().flatten();
        for (sel, x) in sels.iter().zip(vals).rev() {
            v = match (x, v) {
                (Some(Term::I(a)), Some(Term::I(b))) => Some(Term::I(sel.ite(&a, &b))),
                (Some(Term::B(a)), Some(Term::B(b))) => Some(Term::B(sel.ite(&a, &b))),
                _ => None,
            };
        }
        (v, and(&oks))
    }

    /// The condition that `p` matches the scrutinee (exact for literal, binding and wildcard patterns
    /// on an Int or Bool, a fresh condition otherwise); binds the pattern's variables in `env` and
    /// adds the facts about fresh bindings to `facts`.
    fn pattern(&mut self, p: &TPat, s: Option<&Term>, ty: &Type, env: &mut [Option<Term>], facts: &mut Vec<Bool>) -> Bool {
        match (p, s) {
            (TPat::Wild, _) => truth(),
            (TPat::Bind(id), Some(t)) => {
                if let Some(slot) = env.get_mut(*id as usize) {
                    *slot = Some(t.clone());
                }
                truth()
            }
            (TPat::Int(n), Some(Term::I(x))) => x.eq(Int::from_i64(*n)),
            (TPat::Bool(b), Some(Term::B(x))) => x.eq(Bool::from_bool(*b)),
            _ => {
                self.bind_unknown(p, ty, env, facts);
                if matches!(ty, Type::Int | Type::Bool) || self.binds_modelled(p, ty) {
                    self.approx.insert(format!("patterns on {ty}"));
                }
                Bool::fresh_const("m")
            }
        }
    }

    /// True if `p` binds a variable of type Int or Bool inside a value of type `ty`.
    fn binds_modelled(&self, p: &TPat, ty: &Type) -> bool {
        match p {
            TPat::Bind(_) => matches!(ty, Type::Int | Type::Bool),
            TPat::Variant(tag, ps) => {
                let fields = self.tp.variant_fields(ty, *tag);
                ps.iter().zip(&fields).any(|(q, t)| self.binds_modelled(q, t))
            }
            TPat::Record(fs) => {
                let decl = self.tp.record_fields(ty);
                fs.iter().any(|(i, q)| decl.get(*i as usize).is_some_and(|(_, t)| self.binds_modelled(q, t)))
            }
            _ => false,
        }
    }

    /// Binds every variable of `p` (a pattern on a value of type `ty`) to a fresh value.
    fn bind_unknown(&mut self, p: &TPat, ty: &Type, env: &mut [Option<Term>], facts: &mut Vec<Bool>) {
        match p {
            TPat::Bind(id) => {
                let (v, f) = havoc(ty);
                facts.push(f);
                if let Some(slot) = env.get_mut(*id as usize) {
                    *slot = v;
                }
            }
            TPat::Variant(tag, ps) => {
                let fields = self.tp.variant_fields(ty, *tag);
                for (q, t) in ps.iter().zip(&fields) {
                    self.bind_unknown(q, t, env, facts);
                }
            }
            TPat::Record(fs) => {
                let decl = self.tp.record_fields(ty);
                for (i, q) in fs {
                    if let Some((_, t)) = decl.get(*i as usize) {
                        self.bind_unknown(q, t, env, facts);
                    }
                }
            }
            _ => {}
        }
    }
}
```

```rust
//! Values for executing functions: the smallest value of a type, to run a counterexample whose
//! unmodelled parameters the solver left open.

use qal_core::tast::TProgram;
use qal_core::ast::Type;
use qal_run::Value;

/// Deepest nesting of generated values (recursive types stop growing below their size anyway).
const MAX_DEPTH: usize = 24;
/// Most nodes of one generated value: nested records multiply (`R1 = { a: R0, b: R0, c: R0 }` …),
/// so even the smallest value of a small type can be exponentially large.
pub const MAX_VALUE_NODES: usize = 10_000;

/// The variant tags of `ty` ordered by how small their values are (fewest fields first).
fn variants_by_size(tp: &TProgram, ty: &Type) -> Vec<u32> {
    let n = tp.variant_names(ty).len() as u32;
    let mut tags: Vec<u32> = (0..n).collect();
    tags.sort_by_key(|t| tp.variant_fields(ty, *t).len());
    tags
}

/// The smallest value of `ty`: 0, false, "", empty collections, None, the variant with the fewest
/// fields. None if there is no finite one (functions, enums without a terminating variant).
pub fn smallest(tp: &TProgram, ty: &Type) -> Option<Value> {
    smallest_at(tp, ty, 0, &mut { MAX_VALUE_NODES })
}

fn smallest_at(tp: &TProgram, ty: &Type, depth: usize, left: &mut usize) -> Option<Value> {
    if depth > MAX_DEPTH || *left == 0 {
        return None;
    }
    *left -= 1;
    Some(match ty {
        Type::Int => Value::Int(0),
        Type::Float => Value::Float(0.0),
        Type::Bool => Value::Bool(false),
        Type::Unit => Value::Unit,
        Type::Str => Value::Str(String::new()),
        Type::Bytes => Value::Bytes(Vec::new(), 0),
        Type::List(_) => Value::List(Vec::new()),
        Type::Map(..) => Value::Map(Vec::new()),
        _ if tp.is_record(ty) => {
            let mut fields = Vec::new();
            for (f, ft) in tp.record_fields(ty) {
                fields.push((f, smallest_at(tp, &ft, depth + 1, left)?));
            }
            Value::Record(ty.to_string(), fields)
        }
        _ => {
            let names = tp.variant_names(ty);
            variants_by_size(tp, ty).into_iter().find_map(|tag| {
                let payload: Option<Vec<Value>> = tp.variant_fields(ty, tag).iter().map(|ft| smallest_at(tp, ft, depth + 1, left)).collect();
                Some(Value::Variant(names.get(tag as usize)?.clone(), payload?))
            })?
        }
    })
}
```

```rust
//! QAL static contract proofs and generated property tests (spec Phase 2).
//!
//! **Proofs** (`prove`): for every function (generic ones once, not their instances) and test, Z3
//! checks each obligation:
//! - `ens[k]`: if the `req` hold and the body returns, `ens[k]` evaluates to true without trapping;
//! - at each call of a function with `req` (in a body, also inside closures, not in contracts):
//!   the callee's `req[k]` holds whenever the call is reached.
//!
//! The result is `proven`, `refuted` (the solver found a counterexample and running the function on
//! it really violates the contract) or `unknown` (the solver gave up, or its counterexample could not
//! be confirmed: the encoding approximates what it does not model, see [`vc`]). Every contract stays
//! checked at runtime, proven or not.
//!
//! **Determinism:** each obligation is solved in a fresh Z3 context with a fixed random seed and a
//! resource limit (`rlimit`, deterministic for a given Z3 version); the wall-clock timeout is only a
//! safety net. Results are a function of the definition, its callees' contracts, the prover version,
//! the Z3 version and the resource limit — [`Options::key`] names all of them.

mod gen;
mod vc;

pub use gen::smallest;

use qal_core::ast::Type;
use qal_core::diag::Diagnostic;
use qal_core::tast::{TFn, TProgram, TTest};
use qal_run::{RunError, Runner, Value, Values};
use qal_wasm::Entry;
use serde::{Deserialize, Serialize};
use std::panic::{catch_unwind, AssertUnwindSafe};
use std::time::{Duration, Instant};
use vc::{Goal, Term, Vc};
use z3::{Config, Params, SatResult, Solver};

/// Changes whenever the encoding changes (stored results of another version are not reused).
pub const PROVER_VERSION: &str = "qal-prove/1";

/// Reasons of results that depend on the machine's speed or load, not only on the definition.
const NOT_ATTEMPTED: &str = "not attempted:";
const TIMED_OUT: &str = "the solver timed out after";
const INTERNAL: &str = "internal prover error";

#[derive(Debug, Clone, PartialEq)]
pub struct Options {
    /// Z3 resource limit per obligation (deterministic effort bound).
    pub rlimit: u32,
    /// Wall-clock limit per obligation in milliseconds (safety net).
    pub timeout_ms: u32,
    /// Wall-clock budget of one `prove` call; obligations after it are `unknown`.
    pub budget: Duration,
    /// Instruction budget for running a counterexample.
    pub confirm_fuel: u64,
}

impl Default for Options {
    fn default() -> Options {
        Options { rlimit: 10_000_000, timeout_ms: 5_000, budget: Duration::from_secs(30), confirm_fuel: 50_000_000 }
    }
}

impl Options {
    /// Identifies everything a result depends on besides the definition (and through its hash, the
    /// contracts of its callees).
    pub fn key(&self) -> String {
        format!("{PROVER_VERSION} z3-{} rlimit-{}", z3::full_version(), self.rlimit)
    }
}

#[derive(Debug, Clone, Copy, PartialEq, Eq, Serialize, Deserialize)]
#[serde(rename_all = "lowercase")]
pub enum Status {
    Proven,
    Refuted,
    Unknown,
}

/// The result of one obligation.
#[derive(Debug, Clone, PartialEq, Serialize, Deserialize)]
pub struct Report {
    /// The function or test the obligation belongs to.
    pub def: String,
    /// `ens[0]`, or `req[1] of g` for a call site.
    pub obligation: String,
    /// AST path: the contract (`ens[0]`) or the call (`body.then`).
    pub path: String,
    /// The contract as text.
    pub contract: String,
    pub status: Status,
    /// Parameter values: the confirmed counterexample (`refuted`) or an unconfirmed candidate (`unknown`).
    #[serde(skip_serializing_if = "Option::is_none", default)]
    pub counterexample: Option<serde_json::Value>,
    /// Why the result is `unknown`.
    #[serde(skip_serializing_if = "Option::is_none", default)]
    pub reason: Option<String>,
}

impl Report {
    /// False for results that another run could improve without any change (time budget used up,
    /// wall-clock timeout, internal error): those are not stored.
    pub fn is_stable(&self) -> bool {
        self.reason.as_deref().is_none_or(|r| !(r.starts_with(NOT_ATTEMPTED) || r.starts_with(TIMED_OUT) || r.starts_with(INTERNAL)))
    }

    /// `refuted` is the error `contract_refuted` (E0801); `unknown` the warning `contract_unproven` (E0802).
    pub fn diagnostic(&self) -> Option<Diagnostic> {
        let mut d = match self.status {
            Status::Proven => return None,
            Status::Refuted => Diagnostic::new("E0801", "contract_refuted", &self.def, &self.path, format!("`{}` ({}) does not hold for the counterexample", self.contract, self.obligation))
                .hint("running the function on the counterexample violates the contract: fix the body, the contract, or add a `req`"),
            Status::Unknown => Diagnostic::new("E0802", "contract_unproven", &self.def, &self.path, format!("`{}` ({}) could not be proven: {}", self.contract, self.obligation, self.reason.as_deref().unwrap_or("unknown")))
                .hint("the contract stays checked at runtime; a simpler or stronger `req`/`ens` (Int and Bool facts) may make it provable"),
        };
        d.counterexample = self.counterexample.clone();
        Some(d)
    }
}

/// What a proof is about: a function by index (monomorphic or generic), or a test.
#[derive(Debug, Clone, Copy)]
enum Which {
    Fn(usize),
    Generic(usize),
    Test(usize),
}

/// The definitions whose obligations are proven, in order: monomorphic functions (not instances),
/// generic functions, tests. `only` restricts them by name.
fn targets(tp: &TProgram, only: Option<&[String]>) -> Vec<(String, Which)> {
    let keep = |n: &str| only.is_none_or(|ns| ns.iter().any(|m| m == n));
    let mut out = Vec::new();
    for (i, f) in tp.fns.iter().enumerate().filter(|(_, f)| f.instance.is_none() && keep(&f.def.name)) {
        out.push((f.def.name.clone(), Which::Fn(i)));
    }
    for (i, f) in tp.generics.iter().enumerate().filter(|(_, f)| keep(&f.def.name)) {
        out.push((f.def.name.clone(), Which::Generic(i)));
    }
    for (i, t) in tp.tests.iter().enumerate().filter(|(_, t)| keep(&t.name)) {
        out.push((t.name.clone(), Which::Test(i)));
    }
    out
}

fn encode(tp: &TProgram, which: Which) -> Option<Vc> {
    Some(match which {
        Which::Fn(i) => vc::function(tp, tp.fns.get(i)?),
        Which::Generic(i) => vc::function(tp, tp.generics.get(i)?),
        Which::Test(i) => vc::test(tp, tp.tests.get(i)?),
    })
}

/// What the solver said about one obligation (plain data: Z3 terms do not leave their context).
enum Solved {
    Proven,
    /// A model: parameter values (None: not modelled by the solver), and for a callee's `req` the
    /// callee's arguments at this call.
    /// The arguments at the other calls with the same goal follow (in the same model).
    Model(Vec<(String, Type, Option<Value>)>, Vec<(String, Option<Value>)>, Vec<Vec<(String, Option<Value>)>>),
    Unknown(String),
}

/// Metadata of an obligation, outside any Z3 context.
struct Meta {
    goal: Goal,
    label: String,
    path: String,
    contract: String,
}

/// Proves the obligations of the definitions named `only` (all if None) of a checked program.
pub fn prove(tp: &TProgram, only: Option<&[String]>, opts: &Options) -> Vec<Report> {
    let start = Instant::now();
    let mut runner: Option<Option<Runner>> = None;
    let mut out = Vec::new();
    for (name, which) in targets(tp, only) {
        let Some((metas, approx, truncated)) = in_context(opts, || encode(tp, which).map(|v| (v.obligations.iter().map(|o| Meta { goal: o.goal.clone(), label: o.label.clone(), path: o.path.clone(), contract: o.contract.clone() }).collect::<Vec<_>>(), v.approx, v.truncated))).flatten() else {
            continue;
        };
        if truncated {
            let reason = format!("{name} and the contracts it uses are too large to encode (more than {} expressions); its contracts stay checked at run time", vc::MAX_VC_NODES);
            out.push(Report { def: name.clone(), obligation: "all".into(), path: String::new(), contract: String::new(), status: Status::Unknown, counterexample: None, reason: Some(reason) });
            continue;
        }
        for (k, m) in metas.into_iter().enumerate() {
            let mut r = Report { def: name.clone(), obligation: m.label, path: m.path, contract: m.contract, status: Status::Unknown, counterexample: None, reason: None };
            if start.elapsed() > opts.budget {
                r.reason = Some(format!("{NOT_ATTEMPTED} the prover's time budget of {} s was used up", opts.budget.as_secs()));
                out.push(r);
                continue;
            }
            // The wall-clock limit of one obligation never reaches past the budget.
            let left = opts.budget.saturating_sub(start.elapsed()).as_millis().max(1) as u32;
            let local = Options { timeout_ms: opts.timeout_ms.min(left), ..opts.clone() };
            match in_context(&local, || solve(tp, which, k, &local)).unwrap_or_else(|| Solved::Unknown(INTERNAL.into())) {
                Solved::Proven => r.status = Status::Proven,
                Solved::Unknown(why) => r.reason = Some(why),
                Solved::Model(params, call, others) => {
                    let shown: Vec<(String, Value)> = params.iter().filter_map(|(n, _, v)| v.clone().map(|v| (n.clone(), v))).collect();
                    r.counterexample = (!shown.is_empty()).then(|| serde_json::to_value(Values(shown)).ok()).flatten();
                    let runner = runner.get_or_insert_with(|| qal_wasm::compile(tp, &Entry::All).ok().and_then(|m| Runner::new(m).ok()).map(|r| r.with_fuel(opts.confirm_fuel).with_timeout(Duration::from_secs(5))));
                    match confirm(tp, which, &m.goal, &params, &call, &others, runner.as_ref()) {
                        Ok(values) => {
                            r.status = Status::Refuted;
                            r.counterexample = (!values.is_empty()).then(|| serde_json::to_value(Values(values)).ok()).flatten();
                        }
                        Err(why) => {
                            let approx: Vec<&str> = approx.iter().map(String::as_str).collect();
                            let ignores = if approx.is_empty() { String::new() } else { format!(" (the prover approximates {})", approx.join(", ")) };
                            r.reason = Some(format!("{why}{ignores}"));
                        }
                    }
                }
            }
            out.push(r);
        }
    }
    out
}

/// Stack of the thread each obligation is encoded and solved on: the encoding and Z3 recurse along
/// the nesting of expressions and inlined contracts, whatever thread `prove` is called from.
const PROVER_STACK: usize = 256 << 20;

/// Runs `f` with a fresh Z3 context on its own large-stack thread; None if Z3 (or the encoding)
/// panicked or the thread could not be started.
fn in_context<R: Send + Sync>(opts: &Options, f: impl FnOnce() -> R + Send + Sync) -> Option<R> {
    let timeout = opts.timeout_ms as u64;
    std::thread::scope(|scope| {
        let run = move || {
            let mut cfg = Config::new();
            cfg.set_timeout_msec(timeout);
            catch_unwind(AssertUnwindSafe(|| z3::with_z3_config(&cfg, f))).ok()
        };
        let worker = std::thread::Builder::new().name("qal-prove".into()).stack_size(PROVER_STACK).spawn_scoped(scope, run);
        worker.ok()?.join().ok().flatten()
    })
}

/// Solves obligation `k` of `which` (inside a fresh context).
fn solve(tp: &TProgram, which: Which, k: usize, opts: &Options) -> Solved {
    let Some(vc) = encode(tp, which) else { return Solved::Unknown(INTERNAL.into()) };
    let Some(o) = vc.obligations.get(k) else { return Solved::Unknown(INTERNAL.into()) };
    let s = Solver::new();
    let mut p = Params::new();
    p.set_u32("rlimit", opts.rlimit);
    p.set_u32("timeout", opts.timeout_ms);
    p.set_u32("random_seed", 0);
    s.set_params(&p);
    s.assert(&vc.pre);
    s.assert(&o.hyp);
    s.assert(o.holds.not());
    match s.check() {
        SatResult::Unsat => Solved::Proven,
        SatResult::Unknown => match s.get_reason_unknown() {
            Some(r) if r.contains("timeout") => Solved::Unknown(format!("{TIMED_OUT} {} ms", opts.timeout_ms)),
            r => Solved::Unknown(format!("the solver gave up within its resource limit (rlimit {}): {}", opts.rlimit, r.unwrap_or_else(|| "unknown".into()))),
        },
        SatResult::Sat => {
            let Some(model) = s.get_model() else { return Solved::Unknown("the solver found no model".into()) };
            let eval = |t: &Option<Term>| match t {
                Some(Term::I(x)) => model.eval(x, true).and_then(|v| v.as_i64()).map(Value::Int),
                Some(Term::B(b)) => model.eval(b, true).and_then(|v| v.as_bool()).map(Value::Bool),
                None => None,
            };
            let call = o.args.iter().map(|(n, t)| (n.clone(), eval(t))).collect();
            let others = vc.obligations.iter().enumerate().filter(|(j, p)| *j != k && p.goal == o.goal).map(|(_, p)| p.args.iter().map(|(n, t)| (n.clone(), eval(t))).collect()).collect();
            let params = vc
                .params
                .iter()
                .map(|(n, ty, t)| {
                    let v = match t {
                        Some(Term::I(x)) => model.eval(x, true).and_then(|v| v.as_i64()).map(Value::Int),
                        Some(Term::B(b)) => model.eval(b, true).and_then(|v| v.as_bool()).map(Value::Bool),
                        None => None,
                    };
                    (n.clone(), ty.clone(), v)
                })
                .collect();
            Solved::Model(params, call, others)
        }
    }
}

/// Runs the definition on the counterexample (unmodelled parameters get their smallest value):
/// Ok(arguments) if the expected contract really fails.
#[allow(clippy::too_many_arguments)]
fn confirm(tp: &TProgram, which: Which, goal: &Goal, params: &[(String, Type, Option<Value>)], call: &[(String, Option<Value>)], others: &[Vec<(String, Option<Value>)>], runner: Option<&Runner>) -> Result<Vec<(String, Value)>, String> {
    let (export, f): (String, Option<&TFn>) = match which {
        Which::Fn(i) => {
            let f = tp.fns.get(i).ok_or("internal prover error")?;
            (f.def.name.clone(), Some(f))
        }
        Which::Generic(_) => return Err("a counterexample candidate was found, but generic functions are not executed to confirm it".into()),
        Which::Test(i) => {
            let t: &TTest = tp.tests.get(i).ok_or("internal prover error")?;
            (format!("test:{}", t.name), None)
        }
    };
    if f.is_some_and(|f| !f.def.effects.is_empty()) {
        return Err("a counterexample candidate was found, but the function has effects, so it was not executed".into());
    }
    let mut args = Vec::new();
    for (n, ty, v) in params {
        match v.clone().or_else(|| smallest(tp, ty)) {
            Some(v) => args.push((n.clone(), v)),
            None => return Err(format!("a counterexample candidate was found, but parameter `{n}` has no value of at most {} nodes to run it with", gen::MAX_VALUE_NODES)),
        }
    }
    let runner = runner.ok_or("a counterexample candidate was found, but the program could not be compiled to run it")?;
    let values: Vec<Value> = args.iter().map(|(_, v)| v.clone()).collect();
    let (def, label) = match goal {
        Goal::Ens(k) => (f.map_or(export.as_str(), |f| f.def.name.as_str()), format!("ens[{k}]")),
        Goal::Req(g, k) => (g.as_str(), format!("req[{k}]")),
    };
    match runner.call(&export, &values) {
        // A callee's `req` must fail with this call's arguments (as far as the solver modelled them):
        // the same contract failing at another call of the callee is not this obligation.
        Err(e) if violates(&e, def, &label) && matches(&e, call) && !others.iter().any(|o| matches(&e, o)) => Ok(args),
        Err(e) if violates(&e, def, &label) => Err("a counterexample candidate was not confirmed: running it violated the same contract, maybe at another call".into()),
        Err(e) => Err(format!("a counterexample candidate was not confirmed: running it ended with `{}` instead", e.kind)),
        Ok(_) => Err("a counterexample candidate was not confirmed: running it satisfied the contract".into()),
    }
}

/// True if the values of a contract violation agree with a call's modelled arguments.
fn matches(e: &RunError, call: &[(String, Option<Value>)]) -> bool {
    call.iter().all(|(n, v)| v.as_ref().is_none_or(|v| e.values.0.iter().any(|(m, w)| m == n && w == v)))
}

/// True if `e` is the failure of contract `label` (`req[0]`, `ens[1]`) of `def`: the contract was
/// false, or evaluating it trapped.
fn violates(e: &RunError, def: &str, label: &str) -> bool {
    e.def == def && (e.contract.as_deref().is_some_and(|c| c.starts_with(&format!("{label}:"))) || e.path == label || e.path.starts_with(&format!("{label}.")))
}
```

```rust
//! Values for executing functions: the smallest value of a type (to run a counterexample whose
//! unmodelled parameters the solver left open), random values of a size, and shrinking.
//!
//! Generation is deterministic: a SplitMix64 generator seeded per function.

use qal_core::ast::{Type, TypeBody};
use qal_core::tast::TProgram;
use qal_run::{compare_values, Value};

/// Deepest nesting of generated values (recursive types stop growing below their size anyway).
const MAX_DEPTH: usize = 24;
/// Most nodes of one generated value: nested records multiply (`R1 = { a: R0, b: R0, c: R0 }` …),
/// so even the smallest value of a small type can be exponentially large.
pub const MAX_VALUE_NODES: usize = 10_000;

/// SplitMix64 (deterministic, platform-independent).
#[derive(Debug, Clone)]
pub struct Rng(u64);

impl Rng {
    pub fn new(seed: u64) -> Rng {
        Rng(seed)
    }

    pub fn next(&mut self) -> u64 {
        self.0 = self.0.wrapping_add(0x9E37_79B9_7F4A_7C15);
        let mut z = self.0;
        z = (z ^ (z >> 30)).wrapping_mul(0xBF58_476D_1CE4_E5B9);
        z = (z ^ (z >> 27)).wrapping_mul(0x94D0_49BB_1331_11EB);
        z ^ (z >> 31)
    }

    /// Uniform in `0..n` (n > 0).
    pub fn below(&mut self, n: u64) -> u64 {
        self.next() % n.max(1)
    }

    /// Uniform in `lo..=hi`.
    pub fn range(&mut self, lo: i64, hi: i64) -> i64 {
        let span = (hi as i128 - lo as i128 + 1) as u128;
        (lo as i128 + (self.next() as u128 % span) as i128) as i64
    }

    fn chance(&mut self, one_in: u64) -> bool {
        self.below(one_in) == 0
    }
}

/// FNV-1a of `s` (seeds per function name).
pub fn fnv(s: &str) -> u64 {
    s.bytes().fold(0xcbf2_9ce4_8422_2325, |h, b| (h ^ b as u64).wrapping_mul(0x100_0000_01b3))
}

/// True if values of `ty` can be generated (no function inside, no unresolved type).
pub fn generatable(tp: &TProgram, ty: &Type) -> bool {
    fn walk(tp: &TProgram, ty: &Type, seen: &mut Vec<String>) -> bool {
        if seen.len() >= 256 {
            return false;
        }
        match ty {
            Type::Int | Type::Float | Type::Bool | Type::Unit | Type::Str | Type::Bytes => true,
            Type::List(x) | Type::Option(x) => walk(tp, x, seen),
            Type::Result(a, b) | Type::Map(a, b) => walk(tp, a, seen) && walk(tp, b, seen),
            Type::Named(_) | Type::App(..) => {
                let key = ty.to_string();
                if seen.contains(&key) {
                    return true;
                }
                seen.push(key);
                match tp.decl(ty) {
                    Some(TypeBody::Record(fs)) => fs.iter().all(|(_, t)| walk(tp, t, seen)),
                    // An enum without variants has no values.
                    Some(TypeBody::Enum(vs)) => !vs.is_empty() && vs.iter().all(|v| v.fields.iter().all(|t| walk(tp, t, seen))),
                    None => false,
                }
            }
            Type::Fn(..) | Type::Param(_) | Type::Var(_) => false,
        }
    }
    walk(tp, ty, &mut Vec::new())
}

/// The variant tags of `ty` ordered by how small their values are (fewest fields first).
fn variants_by_size(tp: &TProgram, ty: &Type) -> Vec<u32> {
    let n = tp.variant_names(ty).len() as u32;
    let mut tags: Vec<u32> = (0..n).collect();
    tags.sort_by_key(|t| tp.variant_fields(ty, *t).len());
    tags
}

/// The smallest value of `ty`: 0, false, "", empty collections, None, the variant with the fewest
/// fields. None if there is no finite one (functions, enums without a terminating variant).
pub fn smallest(tp: &TProgram, ty: &Type) -> Option<Value> {
    smallest_at(tp, ty, 0, &mut { MAX_VALUE_NODES })
}

fn smallest_at(tp: &TProgram, ty: &Type, depth: usize, left: &mut usize) -> Option<Value> {
    if depth > MAX_DEPTH || *left == 0 {
        return None;
    }
    *left -= 1;
    Some(match ty {
        Type::Int => Value::Int(0),
        Type::Float => Value::Float(0.0),
        Type::Bool => Value::Bool(false),
        Type::Unit => Value::Unit,
        Type::Str => Value::Str(String::new()),
        Type::Bytes => Value::Bytes(Vec::new(), 0),
        Type::List(_) => Value::List(Vec::new()),
        Type::Map(..) => Value::Map(Vec::new()),
        _ if tp.is_record(ty) => {
            let mut fields = Vec::new();
            for (f, ft) in tp.record_fields(ty) {
                fields.push((f, smallest_at(tp, &ft, depth + 1, left)?));
            }
            Value::Record(ty.to_string(), fields)
        }
        _ => {
            let names = tp.variant_names(ty);
            variants_by_size(tp, ty).into_iter().find_map(|tag| {
                let payload: Option<Vec<Value>> = tp.variant_fields(ty, tag).iter().map(|ft| smallest_at(tp, ft, depth + 1, left)).collect();
                Some(Value::Variant(names.get(tag as usize)?.clone(), payload?))
            })?
        }
    })
}

const EDGE_INTS: [i64; 7] = [0, 1, -1, i64::MAX, i64::MIN, i64::MAX - 1, i64::MIN + 1];
const EDGE_FLOATS: [f64; 9] = [0.0, -0.0, 1.0, -1.0, f64::NAN, f64::INFINITY, f64::NEG_INFINITY, f64::MIN_POSITIVE, f64::MAX];
const CHARS: &[char] = &['a', 'b', 'c', 'x', 'y', 'z', 'A', 'Z', '0', '1', '9', ' ', ',', '-', '.', '\n', 'é', 'ß', '中', '🙂'];

/// A random value of `ty` of about `size` (collection lengths and Int magnitudes up to `size`).
/// None if `ty` has no value within `MAX_VALUE_NODES`.
pub fn random(tp: &TProgram, ty: &Type, size: u64, rng: &mut Rng) -> Option<Value> {
    random_at(tp, ty, size, rng, 0, &mut { MAX_VALUE_NODES })
}

fn random_at(tp: &TProgram, ty: &Type, size: u64, rng: &mut Rng, depth: usize, left: &mut usize) -> Option<Value> {
    if depth > MAX_DEPTH {
        return smallest_at(tp, ty, 0, left);
    }
    if *left == 0 {
        return None;
    }
    *left -= 1;
    let s = size as i64;
    Some(match ty {
        Type::Int if rng.chance(10) => Value::Int(EDGE_INTS[rng.below(EDGE_INTS.len() as u64) as usize]),
        Type::Int => Value::Int(rng.range(-s, s)),
        Type::Float if rng.chance(10) => Value::Float(EDGE_FLOATS[rng.below(EDGE_FLOATS.len() as u64) as usize]),
        Type::Float => Value::Float(rng.range(-s * 100, s * 100) as f64 / 100.0),
        Type::Bool => Value::Bool(rng.chance(2)),
        Type::Unit => Value::Unit,
        Type::Str => {
            let n = rng.below(size + 1);
            Value::Str((0..n).map(|_| CHARS[rng.below(CHARS.len() as u64) as usize]).collect())
        }
        Type::Bytes => {
            let n = rng.below(size + 1);
            Value::Bytes((0..n).map(|_| rng.below(256) as u8).collect(), 0)
        }
        Type::List(x) => {
            let n = rng.below(size + 1);
            Value::List((0..n).map(|_| random_at(tp, x, size / 2, rng, depth + 1, left)).collect::<Option<_>>()?)
        }
        Type::Map(k, v) => {
            let n = rng.below(size / 2 + 1);
            let mut entries: Vec<(Value, Value)> = Vec::new();
            for _ in 0..n {
                let key = random_at(tp, k, size / 2, rng, depth + 1, left)?;
                let val = random_at(tp, v, size / 2, rng, depth + 1, left)?;
                if !entries.iter().any(|(e, _)| compare_values(tp, k, e, &key).is_eq()) {
                    entries.push((key, val));
                }
            }
            Value::Map(entries)
        }
        _ if tp.is_record(ty) => {
            let mut fields = Vec::new();
            for (f, ft) in tp.record_fields(ty) {
                fields.push((f, random_at(tp, &ft, size, rng, depth + 1, left)?));
            }
            Value::Record(ty.to_string(), fields)
        }
        _ => {
            let names = tp.variant_names(ty);
            if names.is_empty() {
                return None;
            }
            // At size 0 the smallest variants only, so recursive types terminate.
            let tag = if size == 0 {
                return smallest_at(tp, ty, 0, left);
            } else {
                rng.below(names.len() as u64) as u32
            };
            let fields = tp.variant_fields(ty, tag);
            let sub = size / (fields.len() as u64 + 1);
            let payload = fields.iter().map(|ft| random_at(tp, ft, sub, rng, depth + 1, left)).collect::<Option<Vec<_>>>()?;
            Value::Variant(names.get(tag as usize)?.clone(), payload)
        }
    })
}

/// Candidates tried per nested value (list element, field, payload) in one shrinking step.
const NESTED: usize = 16;

/// Simpler values than `v` (of type `ty`), most promising first.
pub fn shrink(tp: &TProgram, ty: &Type, v: &Value) -> Vec<Value> {
    let mut out = Vec::new();
    match (ty, v) {
        (_, Value::Int(x)) => {
            for c in [0, x / 2, x - x.signum()] {
                if c != *x && !out.contains(&Value::Int(c)) {
                    out.push(Value::Int(c));
                }
            }
            if *x < 0 && *x != i64::MIN {
                out.push(Value::Int(-x));
            }
        }
        (_, Value::Bool(true)) => out.push(Value::Bool(false)),
        (_, Value::Float(x)) => {
            for c in [0.0, x.trunc(), x / 2.0] {
                if c.to_bits() != x.to_bits() && c.is_finite() {
                    out.push(Value::Float(c));
                }
            }
        }
        (_, Value::Str(s)) => {
            let chars: Vec<char> = s.chars().collect();
            for part in shrink_seq(&chars) {
                out.push(Value::Str(part.into_iter().collect()));
            }
            for (i, c) in chars.iter().enumerate().take(8) {
                if *c != 'a' {
                    let mut t = chars.clone();
                    t[i] = 'a';
                    out.push(Value::Str(t.into_iter().collect()));
                }
            }
        }
        (_, Value::Bytes(b, _)) => {
            for part in shrink_seq(b) {
                out.push(Value::Bytes(part, 0));
            }
        }
        (Type::List(t), Value::List(xs)) => {
            for part in shrink_seq(xs) {
                out.push(Value::List(part));
            }
            for (i, x) in xs.iter().enumerate().take(8) {
                for c in shrink(tp, t, x).into_iter().take(NESTED) {
                    let mut ys = xs.clone();
                    ys[i] = c;
                    out.push(Value::List(ys));
                }
            }
        }
        (Type::Map(_, vt), Value::Map(es)) => {
            for part in shrink_seq(es) {
                out.push(Value::Map(part));
            }
            for (i, (_, x)) in es.iter().enumerate().take(8) {
                for c in shrink(tp, vt, x).into_iter().take(NESTED) {
                    let mut ys = es.clone();
                    ys[i].1 = c;
                    out.push(Value::Map(ys));
                }
            }
        }
        (_, Value::Record(name, fields)) => {
            let decl = tp.record_fields(ty);
            for (i, (f, x)) in fields.iter().enumerate() {
                let Some((_, ft)) = decl.iter().find(|(g, _)| g == f) else { continue };
                for c in shrink(tp, ft, x).into_iter().take(NESTED) {
                    let mut fs = fields.clone();
                    fs[i].1 = c;
                    out.push(Value::Record(name.clone(), fs));
                }
            }
        }
        (_, Value::Variant(name, payload)) => {
            let names = tp.variant_names(ty);
            let tag = names.iter().position(|n| n == name).unwrap_or(0) as u32;
            let fields = tp.variant_fields(ty, tag);
            // A smaller variant first, then a payload value of the same type (a subtree), then
            // smaller payloads.
            if let Some(Value::Variant(small, sp)) = smallest(tp, ty) {
                if (small != *name || sp != *payload) && !payload.is_empty() {
                    out.push(Value::Variant(small, sp));
                }
            }
            for (x, ft) in payload.iter().zip(&fields) {
                if ft == ty {
                    out.push(x.clone());
                }
            }
            for (i, (x, ft)) in payload.iter().zip(&fields).enumerate() {
                for c in shrink(tp, ft, x).into_iter().take(NESTED) {
                    let mut ps = payload.clone();
                    ps[i] = c;
                    out.push(Value::Variant(name.clone(), ps));
                }
            }
        }
        _ => {}
    }
    out
}

/// Shorter versions of a sequence: empty, each half, without one element (at most 8 positions).
fn shrink_seq<T: Clone>(xs: &[T]) -> Vec<Vec<T>> {
    let n = xs.len();
    if n == 0 {
        return Vec::new();
    }
    let mut out = vec![Vec::new()];
    if n > 1 {
        out.push(xs[..n / 2].to_vec());
        out.push(xs[n / 2..].to_vec());
    }
    for i in (0..n).take(8) {
        let mut ys = xs.to_vec();
        ys.remove(i);
        if !ys.is_empty() && n > 2 {
            out.push(ys);
        } else if n == 2 {
            out.push(ys);
        }
    }
    out
}
```

```rust
//! Generated property tests: every pure function with an `ens`, or that calls a function with a
//! `req`, is run on random inputs that satisfy its own `req`; the property is "no contract is
//! violated". A failure is shrunk to a smallest input that still violates the same contract.
//!
//! - Inputs satisfying `req` are found by rejection: a generated helper `req?<f>` evaluates f's `req`
//!   on the input (an input for which it is false or traps is discarded).
//! - A run that violates any contract (f's `ens`, a callee's `req` or `ens`, also f's own `req` at a
//!   recursive call, a built-in's precondition) fails the property. Other traps (Int overflow,
//!   division by zero, index, stack, memory, time) are counted as `traps`, not failures: like the
//!   proofs, properties are about contracts (partial correctness).
//! - Deterministic: the inputs follow from the seed and the function's name; sizes grow from 0 to
//!   `max_size` over the runs.

use crate::gen::{fnv, generatable, random, shrink, Rng};
use qal_core::ast::{BinOp, FnDef, Type};
use qal_core::tast::{TExpr, TFn, TKind, TProgram};
use qal_run::{RunError, Runner, Value, Values};
use qal_wasm::Entry;
use serde::Serialize;
use std::time::{Duration, Instant};

#[derive(Debug, Clone, PartialEq)]
pub struct PropOptions {
    /// Runs (inputs that satisfy `req`) per function.
    pub runs: u32,
    pub seed: u64,
    /// Size of the last inputs (Int magnitude, collection length).
    pub max_size: u64,
    /// Candidate inputs tried while shrinking a failure.
    pub shrink_steps: u32,
    /// Instruction budget per run.
    pub fuel: u64,
    /// Wall-clock limit per run.
    pub timeout: Duration,
    /// Wall-clock budget of all properties; functions after it are `skipped`.
    pub budget: Duration,
}

impl Default for PropOptions {
    fn default() -> PropOptions {
        PropOptions { runs: 100, seed: 0, max_size: 30, shrink_steps: 500, fuel: 20_000_000, timeout: Duration::from_secs(2), budget: Duration::from_secs(20) }
    }
}

#[derive(Debug, Clone, Copy, PartialEq, Eq, Serialize)]
#[serde(rename_all = "snake_case")]
pub enum PropStatus {
    Passed,
    Failed,
    /// Too few generated inputs satisfied `req`.
    GaveUp,
    /// Not run (time budget used up).
    Skipped,
}

#[derive(Debug, Clone, PartialEq, Serialize)]
pub struct PropReport {
    /// The function.
    pub def: String,
    pub status: PropStatus,
    /// Inputs that satisfied `req` and were run.
    pub runs: u32,
    /// Generated inputs that did not satisfy `req`.
    pub discarded: u32,
    /// Runs that ended in a trap other than a contract violation.
    pub traps: u32,
    pub seed: u64,
    /// For `failed`: the shrunk input (parameter name -> value).
    #[serde(skip_serializing_if = "Option::is_none")]
    pub counterexample: Option<Values>,
    /// For `failed`: the contract violation on the counterexample.
    #[serde(skip_serializing_if = "Option::is_none")]
    pub error: Option<RunError>,
    /// The first trap that is not a contract violation (counted in `traps`, not a failure).
    #[serde(skip_serializing_if = "Option::is_none")]
    pub trap: Option<RunError>,
}

/// Name of the generated function that evaluates the `req` of `f`.
fn req_name(f: &str) -> String {
    format!("req?{f}")
}

/// True if `f` can violate a contract on its own: it has an `ens`, or calls a function with `req`.
fn has_obligations(tp: &TProgram, f: &TFn) -> bool {
    fn calls_req(tp: &TProgram, e: &TExpr) -> bool {
        if let TKind::Call(i, _) = &e.kind {
            if tp.fns.get(*i).is_some_and(|g| !g.req.is_empty()) {
                return true;
            }
        }
        children(e).into_iter().any(|c| calls_req(tp, c))
    }
    !f.ens.is_empty() || calls_req(tp, &f.body)
}

/// The functions with properties, by index into `tp.fns`: pure, generatable parameters, obligations.
pub fn candidates(tp: &TProgram) -> Vec<usize> {
    (0..tp.fns.len())
        .filter(|&i| {
            let f = &tp.fns[i];
            f.def.effects.is_empty() && f.def.params.iter().all(|p| generatable(tp, &p.ty)) && has_obligations(tp, f)
        })
        .collect()
}

/// A copy of `tp` with a function `req?f` (the conjunction of f's `req`, true if none) for every
/// candidate `f`, compiled with all functions and tests.
fn with_req_checks(tp: &TProgram, fns: &[usize]) -> TProgram {
    let mut out = tp.clone();
    for &i in fns {
        let f = &tp.fns[i];
        let truth = TExpr { ty: Type::Bool, kind: TKind::Bool(true) };
        let body = f.req.iter().cloned().reduce(|a, b| TExpr { ty: Type::Bool, kind: TKind::Bin(BinOp::And, Box::new(a), Box::new(b), "req".into()) }).unwrap_or(truth);
        let def = FnDef { name: req_name(&f.def.name), tparams: vec![], params: f.def.params.clone(), ret: Type::Bool, effects: vec![], req: vec![], ens: vec![], body: f.def.body.clone() };
        out.fns.push(TFn { def, locals: f.locals.clone(), req: vec![], ens: vec![], result_local: None, body, instance: None });
    }
    out
}

/// What one run on an input showed.
#[derive(Debug, Clone, PartialEq)]
enum Run {
    /// The input does not satisfy `req`.
    Discard,
    Pass,
    Trap(RunError),
    /// A contract violation.
    Fail(RunError),
}

fn run_one(runner: &Runner, f: &str, args: &[Value]) -> Run {
    match runner.call(&req_name(f), args) {
        Ok(Value::Bool(true)) => {}
        _ => return Run::Discard,
    }
    match runner.call(f, args) {
        Ok(_) => Run::Pass,
        Err(e) if e.kind == "contract_violation" => Run::Fail(e),
        Err(e) => Run::Trap(e),
    }
}

/// The same contract failed (definition and contract, not the values).
fn same_failure(a: &RunError, b: &RunError) -> bool {
    a.def == b.def && a.contract == b.contract && a.path == b.path
}

/// Runs the properties of the candidate functions named `only` (all if None). `runner` must have
/// been compiled from `with_req_checks` — use [`check_properties`].
fn run_properties(tp: &TProgram, runner: &Runner, fns: &[usize], opts: &PropOptions) -> Vec<PropReport> {
    let start = Instant::now();
    let mut out = Vec::new();
    for &i in fns {
        let f = &tp.fns[i];
        let name = &f.def.name;
        let seed = opts.seed ^ fnv(name);
        let mut report = PropReport { def: name.clone(), status: PropStatus::Passed, runs: 0, discarded: 0, traps: 0, seed: opts.seed, counterexample: None, error: None, trap: None };
        if start.elapsed() > opts.budget {
            report.status = PropStatus::Skipped;
            out.push(report);
            continue;
        }
        let mut rng = Rng::new(seed);
        let types: Vec<Type> = f.def.params.iter().map(|p| p.ty.clone()).collect();
        let max_tries = opts.runs.saturating_mul(10).max(1);
        let mut tries = 0;
        while report.runs < opts.runs && tries < max_tries {
            if start.elapsed() > opts.budget {
                break;
            }
            // Sizes grow with every attempt (not only with successful runs), so a `req` that small
            // inputs never satisfy does not stall generation at size 0.
            let size = (opts.max_size * tries as u64 / opts.runs.max(1) as u64).min(opts.max_size);
            tries += 1;
            let Some(args) = types.iter().map(|t| random(tp, t, size, &mut rng)).collect::<Option<Vec<Value>>>() else { break };
            match run_one(runner, name, &args) {
                Run::Discard => report.discarded += 1,
                Run::Pass => report.runs += 1,
                Run::Trap(e) => {
                    report.runs += 1;
                    report.traps += 1;
                    report.trap.get_or_insert(e);
                }
                Run::Fail(e) => {
                    report.runs += 1;
                    let (args, e) = shrink_failure(tp, runner, name, &types, args, e, opts);
                    report.status = PropStatus::Failed;
                    report.counterexample = Some(Values(f.def.params.iter().map(|p| p.name.clone()).zip(args).collect()));
                    report.error = Some(e);
                    break;
                }
            }
        }
        if report.status == PropStatus::Passed && report.runs < opts.runs / 2 {
            report.status = PropStatus::GaveUp;
        }
        out.push(report);
    }
    out
}

/// Greedily replaces one argument at a time by a simpler one that still fails the same way.
#[allow(clippy::too_many_arguments)]
fn shrink_failure(tp: &TProgram, runner: &Runner, f: &str, types: &[Type], mut args: Vec<Value>, mut err: RunError, opts: &PropOptions) -> (Vec<Value>, RunError) {
    let mut steps = 0;
    'outer: loop {
        for k in 0..args.len() {
            for c in shrink(tp, &types[k], &args[k]) {
                if steps >= opts.shrink_steps {
                    break 'outer;
                }
                steps += 1;
                let mut cand = args.clone();
                cand[k] = c;
                if let Run::Fail(e) = run_one(runner, f, &cand) {
                    if same_failure(&e, &err) {
                        args = cand;
                        err = e;
                        continue 'outer;
                    }
                }
            }
        }
        break;
    }
    (args, err)
}

/// Runs the properties of the functions named `only` (every candidate if None) of a checked
/// program; names that are not candidates are left out.
pub fn check_properties(tp: &TProgram, only: Option<&[String]>, opts: &PropOptions) -> Result<Vec<PropReport>, RunError> {
    let fns: Vec<usize> = candidates(tp).into_iter().filter(|&i| only.is_none_or(|ns| ns.iter().any(|n| *n == tp.fns[i].def.name))).collect();
    if fns.is_empty() {
        return Ok(Vec::new());
    }
    let program = with_req_checks(tp, &fns);
    let module = qal_wasm::compile(&program, &Entry::All).map_err(|m| RunError::new("compile_error", "", format!("the program cannot be compiled to WebAssembly: {m}")))?;
    let runner = Runner::new(module).map_err(|m| RunError::new("compile_error", "", m))?.with_fuel(opts.fuel).with_timeout(opts.timeout);
    Ok(run_properties(&program, &runner, &fns, opts))
}

/// The direct subexpressions of `e` (closure bodies included).
fn children(e: &TExpr) -> Vec<&TExpr> {
    match &e.kind {
        TKind::Int(_) | TKind::Float(_) | TKind::Bool(_) | TKind::Str(_) | TKind::Unit | TKind::Local(_) | TKind::FnRef(_) | TKind::FnRefG(..) => vec![],
        TKind::Lambda(l) => vec![&l.body],
        TKind::Un(_, x, _) | TKind::Field(x, _) => vec![x],
        TKind::Bin(_, l, r, _) | TKind::Let(_, l, r) => vec![l, r],
        TKind::If(c, t, f) => vec![c, t, f],
        TKind::Call(_, xs) | TKind::CallG(_, _, xs) | TKind::List(xs) | TKind::Variant(_, xs) | TKind::Seq(xs) | TKind::Builtin(_, xs, _) => xs.iter().collect(),
        TKind::CallIndirect(f, xs) => std::iter::once(&**f).chain(xs.iter()).collect(),
        TKind::Record(fs) => fs.iter().map(|(_, x)| x).collect(),
        TKind::Match(s, arms) => std::iter::once(&**s).chain(arms.iter().flat_map(|a| a.guard.iter().chain([&a.body]))).collect(),
    }
}
```

```rust
/// Proves the contracts of the named functions and tests (all if `names` is empty). From the
/// store, results stored for the same definition and prover settings are reused; new ones are stored.
pub fn prove(ctx: &Ctx, source: &Source, names: &[String]) -> Reply {
    let loaded = match ctx.load(source) {
        Ok(l) => l,
        Err(d) => return Reply::diagnostics(d),
    };
    let tp = &loaded.typed;
    let known = |n: &str| tp.fns.iter().any(|f| f.def.name == n && f.instance.is_none()) || tp.generics.iter().any(|f| f.def.name == n) || tp.tests.iter().any(|t| t.name == n);
    let unknown: Vec<Diagnostic> = names
        .iter()
        .filter(|n| !known(n))
        .map(|n| {
            let d = Diagnostic::unknown_name(n, "", n);
            match ctx.renamed_hint(source, n) {
                Some(h) => d.hint(h),
                None if tp.type_def(n).is_some() => d.hint(format!("`{n}` is a type; only functions and tests have contracts to prove")),
                None => d,
            }
        })
        .collect();
    if !unknown.is_empty() {
        return Reply::diagnostics(unknown);
    }
    let opts = qal_prove::Options::default();
    let only = (!names.is_empty()).then_some(names);
    let reports = match source {
        Source::Text(_) => qal_prove::prove(tp, only, &opts),
        Source::Store => match stored_proofs(ctx, tp, only, &opts) {
            Ok(r) => r,
            Err(d) => return Reply::diagnostics(d),
        },
    };
    let count = |st: Status| reports.iter().filter(|r| r.status == st).count();
    let (proven, refuted, unknown) = (count(Status::Proven), count(Status::Refuted), count(Status::Unknown));
    let out = Output { warnings: warnings(&reports), proofs: Some(reports), proven: Some(proven), refuted: Some(refuted), unknown: Some(unknown), ..Output::default() };
    Reply::new(out, u8::from(refuted > 0))
}

/// Proof results of the stored definitions: reused per (hash, prover key), computed and stored if missing.
fn stored_proofs(ctx: &Ctx, tp: &TProgram, only: Option<&[String]>, opts: &qal_prove::Options) -> Result<Vec<Report>, Vec<Diagnostic>> {
    let mut store = ctx.open()?;
    let hashes: std::collections::HashMap<String, String> = store.query(&Query::default())?.into_iter().map(|e| (e.name, e.hash)).collect();
    let key = opts.key();
    let targets: Vec<String> = tp
        .fns
        .iter()
        .filter(|f| f.instance.is_none())
        .map(|f| &f.def.name)
        .chain(tp.generics.iter().map(|f| &f.def.name))
        .chain(tp.tests.iter().map(|t| &t.name))
        .filter(|n| only.is_none_or(|ns| ns.contains(n)))
        .cloned()
        .collect();
    let mut cached: std::collections::HashMap<String, Vec<Report>> = std::collections::HashMap::new();
    let mut missing = Vec::new();
    for n in &targets {
        let stored = match hashes.get(n) {
            Some(h) => store.proofs(h, &key)?.and_then(|j| serde_json::from_str::<Vec<Report>>(&j).ok()),
            None => None,
        };
        match stored {
            Some(rs) => {
                cached.insert(n.clone(), rs);
            }
            None => missing.push(n.clone()),
        }
    }
    if !missing.is_empty() {
        let fresh = qal_prove::prove(tp, Some(&missing), opts);
        for n in &missing {
            let rs: Vec<Report> = fresh.iter().filter(|r| r.def == *n).cloned().collect();
            if let Some(h) = hashes.get(n).filter(|_| rs.iter().all(Report::is_stable)) {
                store.save_proofs(h, &key, &proofs_json(rs.iter()))?;
            }
            cached.insert(n.clone(), rs);
        }
    }
    Ok(targets.iter().flat_map(|n| cached.remove(n).unwrap_or_default()).collect())
}
```
