Autonome Multi-Agenten-Entwicklung

Herkömmliche Programmiersprachen sind dateibasiert: Wenn mehrere KI-Agenten denselben Code bearbeiten, entstehen zeilenbasierte Git-Merge-Konflikte und riesige Kontextkosten. QAL löst dies durch atomare Definitionen im SQLite-Graphstore und 3-Wege-AST-Merges.

  • ✓ Keine Zeilen-Merge-Konflikte: Disjunkte Definitionen fusionieren immer fehlerfrei.
  • ✓ Surgical MCP Tools: Agenten fragen via qal_view & qal_query nur relevante Signaturen ab (enorme Token-Ersparnis).
  • ✓ Kryptografische Signaturkette: Ed25519-Signaturen belegen die Urheberschaft jedes Agenten.

Missionskritische Software mit Z3-Beweisen

Für Fintech, Luftfahrt, Kryptographie und Systemsoftware: QAL prüft Vorbedingungen (req) und Nachbedingungen (ens) statisch mit dem Z3 SMT-Solver. Logische Edge-Cases werden noch vor der Codeausführung mathematisch widerlegt oder garantiert.

  • ✓ Statische Beweisgarantie: Partielle Korrektheit für lineare Ganzzahlarithmetik.
  • ✓ Konkrete Gegenbeispiele: Bei Widerlegung liefert Z3 die exakten Variablenwerte, die den Vertrag brechen.
  • ✓ Deterministischer Cache: Beweise werden mit confirm_fuel-Budget gecacht.

Zero-Trust KI-Sandbox & Effekt-Isolation

Wenn KI-Agenten Code generieren, darf dieser nicht unbemerkt Festplatten löschen oder Daten ins Netzwerk funken. QAL besitzt ein striktes algebraisches Effektsystem: Funktionen deklarieren ihre Effekte (!io, !fs, !net, !db) explizit in der Signatur.

  • ✓ Physische Abwesenheit: Ein Modul ohne !net hat keine Netzwerk-Imports im WebAssembly-Bytecode.
  • ✓ TOCTOU-Schutz: Dateisystemzugriffe werden über verankerte openat(O_NOFOLLOW)-Deskriptoren sandbox-gesichert.
  • ✓ Fuel-Limits: Endlosschleifen werden durch Instruktionszähler garantiert gestoppt.

Inhaltsadressierter Store & Instant Rollback

Code in QAL wird nicht als flüchtiger Text in Dateien gespeichert, sondern als kanonischer Merkle-Graph im SQLite-Store. Jede Definition besitzt einen kryptografischen SHA-256-Hash ihrer AST-Struktur.

  • ✓ Refactoring ohne Hash-Churn: Umbenennen oder Whitespace-Formatierung ändert null Hashes.
  • ✓ Bit-identische Pakete: qal export bündelt Codebases in verifizierte .qalpkg-Archive.
  • ✓ Instant Rollback: Definitionen lassen sich ohne Nebeneffekte sofort auf frühere Hashes zurückrollen.
